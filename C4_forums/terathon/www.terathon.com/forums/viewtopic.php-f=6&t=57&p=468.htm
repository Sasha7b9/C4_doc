Audio Features

by Frank Skilton » 10 May 2006, 12:44

I'm not sure what this technique is called and if I can do a good enough job of explaining it...

Ability for a sound to be attached to a moving object, and as the object moves past the player the sound dynamically changes. IE a jet, as it approaches, flys overhead, and into the distance the player would hear those three different sound states. I'm sure hl2 has something like this & I think bf2 does something similar.

Another simple but possibly useful feature would be the ability to randomly alter any given sounds pitch. This would be handy for melee type weapons which are swung like a crowbar etc. You could use one audio file but each swing would sound slightly different due to a slight change in pitch.

Ability to pause, seek and resume within any given audio file would also be handy. As well as ability to stretch an audio file or alter the playback rate, as in speeding up and slowing down like a doppler effect.

This forum's been empty too long and not many feature requests have been made for sound.
