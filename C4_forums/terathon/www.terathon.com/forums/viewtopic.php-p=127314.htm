Game Programming Patterns (GOF for games)

by Davaris » 20 Apr 2013, 21:24

I thought some might be interested in this, as it has the best explanation I have seen of my favorite design pattern, the Component

http://gameprogrammingpatterns.com/component.html

This is where I found out about it:

http://scientificninja.com/blog/nystrom ... g-patterns

The site is the online counterpart to a book that Nystrom, a lead engineer at EA Tiburon, is in the process of writing. The book itself sounds like it will shape up to be a modern, game-oriented version of the classic Gang of Four patterns book, and while the website is still relatively sparsely populated, the content that is available makes for good reading.

Re: Game Programming Patterns (GOF for games)

by caedes » 22 Dec 2014, 13:04

Thanks for the link, this is a very good book
So far, I've read until the "Bytecode" chapter and it has been very interesting and fun to read. In fact, this is the first text about design patterns that I could stand to read for more than 5 minutes

The examples are very descriptive and I like how he discusses when and, more importantly, when not to use the specific patterns, as well as patterns in general (don't make code generic if you don't know yet that you will need that flexibility).
This discussion is very important and other works on design patterns seem to miss it, otherwise some horrible over-engineered code that gives design patterns a bad reputation wouldn't exist.
