Re: "Btr" Havok contest 3d prize winner - GDC 2009 Interview

by rijkaard » 28 May 2009, 17:38

atlury wrote:congrats rijkaard!! Can you please throw some information on how you achieve that blending you were talking off in your interview. You were even talking about teleporting based on annotations of havok? How to did you achieve that blending of ragdoll and character animation?

Eric, are u planning on annotations in upcoming c4 1.6 physics?


well, i simply applied the capabilities of the middleware to my own game concept.
if you download the sdk from http://www.havok.com/tryhavok
there are several built in examples of how to do a dynamic blending between keyframed data and ragdoll.

Same thing for the annotations, many peoples uses them for trigger events (sounds etc... ) i use them for teleport punchs to target ( using also IK in that case ).
Limit is only imagination.

You can integrate the whole stuff easily in a rendering engine ( C4 in that case ), paying only attention to don't mix Havok physic and animation system with engine's equivalent. ( i mean, you should use engine OR middleware, never both )
