Official Roadmap Updated

by Eric Lengyel » 10 Sep 2008, 18:25

The Official Roadmap has been updated with more information about what will appear in version 1.5. We've decided to pack a few more features into version 1.5 so that we can release the best terrain system possible. The good news is that, in addition to the voxel terrain features, dynamic shadow mapping and built-in physics will be included in version 1.5. The bad news is that it will take more time for version 1.5 to be released, but it will definitely be worth the wait.

Re: Official Roadmap Updated

by Eric Lengyel » 11 Sep 2008, 00:06

jwatte wrote:I'm looking forward to reading the intersection test code. Are you doing mesh/mesh? If so, GJK or something else?


I am doing mesh/mesh, but I'm doing CCD under the assumption that there's no initial intersection, so I hope to avoid a general intersection test. No GJK.

jwatte wrote:Btw: compared to a few years ago, there's been a trend towards fewer, bigger releases. If we remember back before GDC this year, you were supposed to release two released before then, then it became one, then it's been a slippery slope of more, but later. Are all the changes so interconnected that they can't be released separately?


It's true that the release frequency has gone down somewhat, but that saves us some time that can be used to get more done for bigger releases. Making a release takes a lot of effort. In the case of version 1.5, the three big features, terrain, dynamic shadow maps, and physics, sort of all tie together to make the full experience with terrain better. I wanted shadows to update as you edit the terrain, and I needed to get rid of the character collision issues.

Re: Official Roadmap Updated

by Eric Lengyel » 11 Sep 2008, 03:15

Optime wrote:What time frame are we looking at here? Is it safeto assume that 1.5 will be finished this year?


Definitely this year. Most likely in October.

Optime wrote:
built-in physics wrote:built-in physics


Do you still plan to make this somewhat pluggable?


Yes. You won't be forced to use the C4 physics.

Optime wrote:Is this going to introduce new node type(s) or (base) controllers?


I don't know for sure yet. It's possible that the number of controller base classes will even decrease.

Optime wrote:Shouldn't this also give us the "mover support"?


Yes.

Road map wrote:# Dynamic shadow mapping for outdoor areas.


What are "outdoor areas"? Does that mean the terrain is the only thing that can receive a dynamic shadow map?[/quote]

What I meant by this is that only the infinite light will support dynamic shadow maps initially. It is applicable to any geometry, not just terrain. It's possible to use an infinite light indoors if you wanted to, but it will of course have parallel rays.

by Eric Lengyel » 11 Sep 2008, 03:17

archanger wrote:
Optime wrote:
Road map wrote:# Dynamic shadow mapping for outdoor areas.


What are "outdoor areas"? Does that mean the terrain is the only thing that can receive a dynamic shadow map?


This also concerns me, will there be soft shadows also for indoor areas? (of some sort, of any sort )


Shadows maps != soft shadows. We will eventually support shadow maps for point lights, but it probably won't be in version 1.5 because it's harder to do on the full range of hardware that the engine supports compared to the infinite light. A separate type of soft penumbral shadow lighting will also be available in the future.
