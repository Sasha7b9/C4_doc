Version 2.7 Beta Now Available

by Eric Lengyel » 28 Sep 2011, 06:15

A beta release of C4 Engine version 2.7 is now available to almost everybody other than basic edition users.

Release notes can be found at the following location. It is important to note that the animation resource format has changed, and you need to type "convert" in the console before using any model animations. Backup your Data folder first.

http://www.terathon.com/wiki/index.php/ ... ersion_2.7
