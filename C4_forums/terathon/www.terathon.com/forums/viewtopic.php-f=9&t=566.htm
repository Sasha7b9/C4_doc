by Eric Lengyel » 07 Jul 2006, 03:08

Hi --

If you run the engine in windowed mode, then you can Alt-Tab in and out without problems. Just uncheck the fullscreen box in the Graphics Options dialog. It's okay to run in windowed mode even at the same resolution as your monitor, but you might see a piece of the task bar at the bottom of the screen.

As for everything else you mentioned, it's definitely being worked on. Right-click menus are coming, and a lot of tool rearrangement and customizability is being done. Personally, I don't think the current interface is unintuitive at all, but it might take some acclimation if you're used to some of the bad interfaces employed by many of the other art programs out there.

We're not going to make the editor a separate application because it needs to be cross-platform. The nice thing about it now is that it's identical on PC and Mac, and if we port to another platform, the editor will "just work".
