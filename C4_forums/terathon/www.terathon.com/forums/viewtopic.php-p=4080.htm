I am new to C4 and just downloaded the sources and tried to compile:
I have xcode preferences set for the build products and intermediate build directories. With my changed preferences C4 doesn't build out of the box.

1) the bundle loader setting in the project currently is hardcoded, so for all configurations I changed it to:
$BUILT_PRODUCTS_DIR/C4.app/Contents/MacOS/C4

2) the final script in the C4 target needed some quotes added:
mkdir "$BUILT_PRODUCTS_DIR/C4.app/Contents/Resources"
mkdir "$BUILT_PRODUCTS_DIR/C4.app/Contents/Resources/Tools"
ln -s -f "`pwd`/../../Data" "$BUILT_PRODUCTS_DIR/C4.app/Contents/Resources"
ln -s -f "`pwd`/../../Import" "$BUILT_PRODUCTS_DIR/C4.app/Contents/Resources"
ln -s -f "`pwd`/../../Save" "$BUILT_PRODUCTS_DIR/C4.app/Contents/Resources"

Could you make those changes in your project as well, please?

by Eric Lengyel » 28 Jun 2006, 15:18

Thanks for the tip.

As for the screen resolution, the engine requests a list of supported resolutions from the OS, so if 1920x1200 isn't there, then the OS isn't reporting it. The engine currently uses an old way of getting these -- if we upgrade to Apple's API du jour, we might see more resolutions show up.
