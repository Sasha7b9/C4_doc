by Eric Lengyel » 26 Oct 2012, 02:10

JamesMK wrote:how would one go about adding an x64 platform target to an existing project?


Open the configuration manager (bottom of Build menu), and select <New...> from the popup menu under the Platform column in the row for your project. In the dialog that appears, x64 should be the only platform you can add.
