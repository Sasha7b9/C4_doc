Re: Problem with timeout

by Eric Lengyel » 12 Mar 2013, 18:52

The explanation in bug report doesn't really hold any water, unfortunately. As you pointed out, the address (including port number) for the acknowledgement packet is set with the following line:

Code: Select all
acknowledgePacket->packetAddress = rawPacket.packetAddress;


This copies the address from which the reliable packet was received exactly. Whatever port number the NAT stuffed into the UDP packet will be the port number to which the acknowledgement is sent. The server does not and cannot know what port the client actually bound itself to locally because that information is never transmitted to the server.

There must be something different going on. I'm investigating.
