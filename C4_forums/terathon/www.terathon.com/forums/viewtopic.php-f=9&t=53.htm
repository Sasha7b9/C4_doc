by Eric Lengyel » 09 May 2006, 15:32

One you have the DAE file, place it in the Import/dae/ directory. Then open a new world in the engine (by choosing New World from the Tools menu or typing Ctrl-N). In the new world, select Import Geometry from the World menu. A list of files in the Import/dae/ directory will appear -- just select yours and it should bring it into the editor. You will have to import your textures separately -- use the Texture Importer tool to do that.

Once you have your model in the World Editor, you can make a standalone entity out of it by selecting Export Model from the World menu. After you save it, you can open your model in the Model Viewer tool.

Note that to apply animations to your model, you'll want to store all of your DAE exports in the same subfolder inside Import/dae/, and you'll want to give this subfolder the same name as the model. That is, if you eventually export a model named MyChar.mdl, then you should place your DAE files in the Import/dae/MyChar/ directory. This is done so that the Model Viewer knows where to look when importing animations.

The engine currently only supports Collada 1.3.x. (Support for 1.4 will probably be in build 123.) If you try to import a 1.4 file, you'll get the nothing that you're seeing.

If you want to use the older 3DSMax plugins, install the c4g.dle and c4a.dle files in your max/plugins/ directory. Then put the exported geometry files in the Import/c4g/ directory, and exported animation files in the Import/c4a/<modelname>/ directory. Note that these formats are being phased out.

by Eric Lengyel » 11 May 2006, 03:24

The Collada format is being backed pretty strongly by Sony as the preferred data interchange format for PS3, so it's getting a decent amount of professional attention. I think the compatibility-breaking changes that they made between 1.3 and 1.4 were a huge mistake, but the format seems to have stabilized. Writing and maintaining one importer for Collada 1.4 is still much less work than writing n exporters for n different art packages.
