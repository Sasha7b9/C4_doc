The editor does create the materials. If the model is white, then that probably indicates that the textures are not specified in the DAE file, or that the DAE file is not properly constructed (one of the reasons we developed OpenGEX). If you see the purple texture with green Xs, then that means the textures are in the material, but you need to import the textures separately. Textures can only be imported automatically if they are in the Import directory hierarchy and the DAE file refers to them in that location (containing "Import/" in the path name). Otherwise, the importer doesn't know where to look.

Re: Imported model textures

by Eric Lengyel » 29 Dec 2014, 17:54

The texture images themselves are never stored in an OpenGEX or Collada file. Only the file names of the textures appear in OpenGEX or Collada files. This means that you either need to store the texture sources in a place where the importers can find them, or you need to import those textures yourself separately. For the importers to find the textures, they need to contain "/Import/" inside their file names, and the actual texture files need to be stored in your Import directory at the location following the "/Import/" in their names.

Re: Imported model textures

by Eric Lengyel » 30 Dec 2014, 15:36

GameWizard wrote:In the .ogex file there are lines like this:
string {"//../../MakeHuman/v1/exports/textures/brown_eye.png"}

From the previous post, does the importer then look for a file in C4/Import/... named "/Import/brown_eye.png", ignoring the .ogex string "//../../MakeHuman/v1/exports/textures/"? Or do I need to edit all of the file specifications in the ogex file to be something else?


In the previous post, I said that the texture files need to contain "/Import/" for the texture map to be imported. The string "//../../MakeHuman/v1/exports/textures/brown_eye.png" does not contain "/Import/", so it would not cause the importer to try to import the texture map. The file name would still appear in the material assigned to the imported geometries, so you could import the texture separately and edit the material to use the texture that you imported.

GameWizard wrote:Also, I thought only .tga textures could be imported??


That is correct. (But we'll probably add support for .png soon.)
