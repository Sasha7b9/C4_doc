Version 1.5 Beta Now Available

by Eric Lengyel » 28 Dec 2008, 01:38

Version 1.5 Beta is now available for licensed users and can be downloaded from the normal site:

https://www.terathon.com/c4engine/reg/index.php

Releases notes are here.

There are a couple of known rendering problems on ATI hardware and on Mac OS X. We're working on it, but they are hardware and/or driver issues, so we need the cooperation of ATI and Apple to get them fixed.

Note that terrain is not supported on ATI R300 and R400 series graphics hardware or on Intel graphics hardware.

Update: The second beta release is now available.

Update: The third beta release is now available.

Re: Version 1.5 Beta Now Available

by Eric Lengyel » 28 Dec 2008, 15:07

Pavol Lesnak wrote:Is largest possible resolution for single terrain texture 1024x1024 or is there theoretical and practical possibility to have 2048x2048? In case i wouldn't have 9 texture but less than that, for example only 6?


The 9-entry palette ends up creating a 4096x4096 texture with 1024x1024 components (padded up to 1280x1280 for filtering reasons). So there's no way to go above 1024x1024 for individual terrain textures in the current system.
