It would be very welcome to be able to turn off cubemaps for rendering the radiosity via a checkbox. (This so that the cubemaps do not influence the radiosity)

We have models that use an environment map.
When we add radiosity we find the scene has a washed out, overly bright look that diminishes the environment map, even when lowering the intensity.

There was some discussion of adding a flag so that Radiosity would not interact with the emissive map of materials.
Perhaps a flag could also be added for the environment map as well?

Re: Radiosity space studies

by Eric Lengyel » 04 Jun 2014, 00:53

ska wrote:Does higher radiosity spaces with higher resolutions cost more performance for cpu? Or just use more gpu memory?


There is no difference in cost on the CPU between low-resolution and high-resolution radiosity spaces. The cost on the GPU should also be pretty much the same at all resolutions. The only real cost is how much GPU memory gets used.
