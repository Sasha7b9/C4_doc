by Eric Lengyel » 07 May 2007, 14:25

Frank Skilton wrote:Quick noob question, what exactly is meant by the "offscreen" in "offscreen antialiasing"?


This means enabling antialiasing for a framebuffer object instead of the main window buffer. It's not as expensive as it sounds because the hardware uses highly optimized multisampling instead of supersampling, so you're not really rendering 2X-8X the pixels. Any GF6,7,8 will handle it just fine.
