by Grognard » 20 Jan 2015, 06:02

It's always been possible, I have it in my game. It's more a matter of the artwork than the engine since you have to ensure the clothes use the same animations and skeletons and there's no interpenetration. You are basically just keeping track of two objects instead of one and making sure they face the same direction and are animating in the same way. It's actually not that big of a deal.

Re: Customizable Characters

by Grognard » 20 Jan 2015, 15:28

Code: Select all
      Model* mainModel;
      SVector<Model> models;
      SVector<FrameAnimator> animators;

      SQueue<CharacterAnimation> animations;
      CharacterAnimation currentAnimation;
      CharacterAnimation defaultAnimation;


You have a bunch of models. You just have to make sure they are using the same animation at the same time, that's it. It would be nice if there is some Attach() command or something then have it use the same animation, but as it stands it's not that hard. You just have all your attached animations play the same animation as your character model. The only tricky part is making sure you exported them in exactly the same manner so you don't get weird errors but if that happens you will know it's happening as everything will be twisted up.
