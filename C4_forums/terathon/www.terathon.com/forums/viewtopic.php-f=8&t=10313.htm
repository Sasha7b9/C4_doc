Figured I'd just go nuts and go with both of the issues as I'm having troubles with the first which means I don't know if my second piece of code is actually working.
The first piece is essentially something I did while following how a similar thing is done in the example game (e.g. AudioSettingWindow, etc), the issue is that the Panel resource fails to load, the Load function within Window(const char*) returns false.

Basically I have created a subclass of the Window class like so:
Code: Select all
class DeviceDisplay : public Window, public ListElement<DeviceDisplay >
{
protected:

public:

Code: Select all
DeviceDisplay ::DeviceDisplay ( const char *panelName )
   : Window(panelName)
{
}

DeviceDisplay ::~DeviceDisplay ()
{
}


Which is in turn used like this:
Code: Select all
class DeviceDepthDisplay : public DeviceDisplay, public Singleton<DeviceDepthDisplay>
{
private:
   PushButtonWidget   *closeButton;
   ImageWidget      *depthImage;

};

extern DeviceDepthDisplay *TheDeviceDepthDisplay;

Code: Select all
DeviceDepthDisplay *C4::TheDeviceDepthDisplay = nullptr;

DeviceDepthDisplay::DeviceDepthDisplay()
   : DeviceDisplay("Device/DepthDisplay"),
     Singleton<DeviceDepthDisplay>(TheDeviceDepthDisplay)
{

}

DeviceDepthDisplay::~DeviceDepthDisplay()
{

void DeviceDepthDisplay::Open( void )

However, as mentioned above when the constructor for DeviceDepthDisplay is called with through "DeviceDisplay("Device/DepthDisplay")" the Load function within Window returns False, I've also tried appending .pan to the name with no success so I guess I'm just using the function incorrectly or should be loading the panel as a resource first but I couldn't find it done within the sample game code.

For additional reference the panel resource is at the following location (relative to the C4 Data directory) "Device/DepthDisplay.pan".

The second issue is just something that I can't test because of the issue above, basically the Device I'm using has an API function that will let me get a Depth Image where each pixel is the size of an unsigned short (16), and I wish to update an ImageWidget on the panel to reflect this (Think of it as getting an image from a webcam to display what it see's) so I figured I'd need to update the texture each frame that the image needs to be updated and I was going to store the TextureHeader in the and just send the pointer as the image pointer, I've never used the TextureHeader before so as I was already asking a question figured I'd post what I have currently incase it's either wrong or there's a better way to do this:

Then the name of the panel to load is "DepthDisplay". The topmost directory within the Data directory is not included (and neither is the extension).

Arthain-Baka wrote:The second issue is just something that I can't test because of the issue above, basically the Device I'm using has an API function that will let me get a Depth Image where each pixel is the size of an unsigned short (16), and I wish to update an ImageWidget on the panel to reflect this (Think of it as getting an image from a webcam to display what it see's) so I figured I'd need to update the texture each frame that the image needs to be updated and I was going to store the TextureHeader in the and just send the pointer as the image pointer, I've never used the TextureHeader before so as I was already asking a question figured I'd post what I have currently incase it's either wrong or there's a better way to do this:


Pass the texture header and image pointer to the ImageWidget constructor. Update the texture by making the following call:

Code: Select all
GetTexture()->Update(Rect(0, 0, width, height))


It will grab the new texture contents from the same image pointer.
