Character image of the day

by Eric Lengyel » 21 Jun 2009, 21:57

Here's a screenshot of the 100 skinned character demo that I was talking about before.

Goblins.jpg


This image is 1280x1024 pixels in size and was rendered with all graphics features enabled, 4X multisampling, and 4X anisotropic filtering. Each of the 100 goblins is being rendered with ambient + point lighting, stencil shadows, and motion blur, meaning that the mesh data is actually being rendered four times per character per frame. Each character is skinned on the CPU once per frame using the new job-based, SIMD-optimized skinning code in version 1.5.9. The goblin model has three LODs composed of 3362/2010/1095 vertices and 4954/2620/1354 triangles. As shown in the image, the frame rate is just over 30 FPS.

The image was rendered on the following hardware:

CPU: Intel Core2 Quad CPU Q6600 @ 2.40GHz
GPU: Nvidia GeForce 8800 GTX

The weapon in the player's hands is the new Quantum Charger that will appear in version 1.6.
