Re: Version 1.5.2 Now Available

by Eric Lengyel » 13 Feb 2009, 15:53

3ShirtlessMen wrote:Alright - then what is the fastest way to convert all my textures to use the new compression? Did you change the way the format was rendered so there is no need for this?


The fastest way would be to create a batch CFG file with itexture commands for each texture that has a problem. A lot of textures won't change with the newer algorithm, so I recommend only re-importing those for which you actually see artifacts.
