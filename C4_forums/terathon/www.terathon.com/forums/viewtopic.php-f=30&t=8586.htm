I hate to keep bringing up Valve, but I think they have an excellent method for dealing with objects in shadow.

http://www.valvesoftware.com/publicatio ... tress2.pdf

The idea is, when in darkened areas, the characters have a faint "rim" of light around them. While this isn't very realistic (it's for TF2 - why would it be?), it might be possible to create a shader which adds faint light to areas of depth (based on the normal map) when the object is in a darkened (but still lit) room. If the object is in a room with no lighting at all, it wouldn't have these highlights. Think "pseudo-global illumination", and you get the idea.
