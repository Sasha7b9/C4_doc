It "used to be" that You can develop for Business Solutions limited to $99 for the Standard License, and any amount for the Pro version (AFAIK).
But it appears the new terms are:

The price is $750 (USD) per user.
The full source code for the engine, tools, and demo game is included.
The engine runs under Windows XP/Vista/7+, Mac OS X 10.7+, and Linux.
Project files are included for Visual Studio 2012 (Windows), Xcode 4 (Mac), and NetBeans (Linux).
You receive all future updates at no additional cost, forever.
You can sell any number of games for any price, and you won't owe any royalties.
You have access to private licensed user forums.
You cannot receive $100,000 or more in external funding (like publisher funding or a Kickstarter campaign). If you do have such external funding, then you need the Professional Edition.


So, Now, you can make any number of games for any price (including business sims)...

@Shantanu: I cannot imagine that the license would prohibit the use in "business applications". But back to the technical side of the question. The C4 engine is not a Web-CMS and does not offer you visual widgets or a db-ORM or MVC as you are used to in a Web-CMS. But it has widgets and you can use whatever is in C4 for whatever you like. Login requires text-input fields, a button, events and networking. All of these are in C4 right now. So it is ready to use. Else you could just make a normal OS-based GUI which has connection to your C4-based graphical part of the application. There are many possibilities and C4 does not limit you in any way Shantanu.

Re: Developing Business Simulation platform on C4

by Eric Lengyel » 30 Sep 2013, 13:57

There is nothing in the licensing terms that would prevent you from making "business simulation games", or any other kind of application either. You can make whatever you want, and the only requirement is that you use the professional edition of the engine if your funding is $100K or more.

As mentioned above, the engine contains all the GUI features that you would need, and it has networking capabilities, but the networking is designed for multiplayer game connections, not TCP-based web services. We do have a browser plugin (based on Awesomium) that lets you display a fully-functional web browser directly inside a GUI window or in-game panel, and this might be able to provide the web services you need.

There are 2 books dedicated to helping you create games for the C4 Engine:
http://www.terathon.com/wiki/index.php/Useful_Books

There is also the wiki:
http://www.terathon.com/wiki/index.php/Main_Page


The books are pretty extensive and explain in varying levels of detail how to use the C4 Engine.

I don't recall that either of the books has "economic simulation" but RTS is discussed, and you could adapt what is explained in the books to help create business simulations.

Please note, that C4 is not a web based Engine. (Although I have seen some folks try to do it in the past). It sounds like you would need a decent bit of experience with coding to achieve this. I do recall seeing a cURL implementation. I guess how hard it will be depends on your experience and exactly what you want to accomplish.
