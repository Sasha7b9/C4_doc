Re: Version 3.5 Final Now Available

by Eric Lengyel » 11 Jan 2014, 12:37

ca$per wrote:
Eric Lengyel wrote:I recommend creating custom RenderableWidget subclasses. This would be the safest in terms of stability and future compatibility.

Is it possible to output widget's vertices in clipspace? Because that's what our 3rd party gui does.
We used a list of Renderable classes and output them like this:
Code: Select all
  TheInterfaceMgr->GetInterfaceCamera()->SetOrthoRect(-1.0f, 1.0f, -1.0f, 1.0f);
  TheGraphicsMgr->SetCamera(TheInterfaceMgr->GetInterfaceCamera(), TheInterfaceMgr->GetCameraTransformable());
  TheGraphicsMgr->DrawRenderList(renderList);


You can set the kRenderableCameraTransformInhibit flag for the widget to get rid of the ordinary camera transform and then apply a transform to the widget that remaps the interface camera's ortho rect to the rect you want.
