The windows you see there are for skinning. You select a few joints and then open the window, then you select verts and start setting weights. I like it a lot better than the component editor, which was apparently programmed by an insane robot. Only to C4 licensees, though, but unlike 99% of the 'free' stuff out there truly free for commercial use that falls under standard license (nongame, console, or big publisher release not allowed).

Ignore the strange skin tone, it's due to materials differences between packages. I will create shaders in C4 that make it look the way it did originally and/or adjust the texture itself.

Re: I thought this was pretty neat (mel GUI tools for skinning)

by Eeyore » 11 Jun 2009, 19:20

Well, I am not sure what the smooth in maya itself does, but it obviously has some big problems because it will put in some crazy weights. It also pulls some weights from far away, as well. What I did was I only take immediate neighbors, then I come up with the average value of all the neighbors and then I apply that to the selected point based on the weight provided. So if it's at .10 then it gets 10% of its weighting replaced (NOT using the maya replace feature!). It also doesn't make for any weight weight values - that is, it figures out all the exact weights to set and the minimum increment is .001 (or is it .01)?

At first glance you'd think you want to average on more than the neighbors, but you get much more control this way. You can select multiple verts and it will average based on the pre-averaging weights for each result so you don't get funky results. Basically, you end up averaging edge loops a lot or the areas getting heavily deformed.


The smooth slider towards the bottom smooths all of the selected verts by the amount selected.

The set weights button sets the weights to be exactly what's in the sliders. Basically it completely reweights the joint. This part I may change a bit, but the point here is to set the absolute weights. I believe it always zeroes out all the other wieghts, and by default it allows maya to normalize, but in the future I believe I will make it so it figures out the exact weights on its own like the smooth does, but I don't end up using this as much as I thought I would.

What I end up doing is to use the add buttons to add influence to joints and the smooth button to even things out, and it goes surprisingly quickly. Muh, much faster than any other way I have tried. It's odd at first to have no feedback for the actual values, but I find it doesn't slow me down any to not have it.

I will send you a link to download for testing/ideas.

Stuff I might add:

1. Better default bind. Maya does pretty good here, but could be much better. Basically, aside from incompetence there's just no reason to ever have a bind that's worse than what you could get from envelopes. That's a solvable problem, basically, though I would probably not do a full generalized solution but make some assumptions - you want a starting place, not a magic guessing tool. I am thinking of replacing the default bind completely but that would be a bit more work than it would probably be worth for personal use.

2. More feedback. It wouldn't be too hard to display in color the different joint weights, blended to show weight value of multiple influences. So, that's something I might do, but I find I don't need it.

3. Add prune small weights and prune influence count buttons. I'll probably do this so that you can clean up things after you are done, and it would literally take a few minutes.

Other things I am doing:
Geometry projection for maya. This will probably have to be a plugin, which is kind of a pain. If I get this going then I will probably release it (maybe all of this stuff?) as a paid tool. Also, some selection and movement tools. Not sure if those would be of interest to others, though.
