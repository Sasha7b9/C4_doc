Version 2.1.1 Beta Now Available

by Eric Lengyel » 30 Aug 2010, 20:33

A beta release of C4 Engine version 2.1.1 is now available to licensed users of the Standard Edition and higher.

In this version, the collision detection code has been largely rewritten and is now superior to all previous versions by a wide margin. Stability and performance have both been improved considerably. If you're using C4 physics, it's pretty much imperative that you upgrade to 2.1.1 as soon as possible.

There are still a couple of known issues in this beta release, such as tiny objects (like grenades) being able to rotate through the paper-thin surface of a generic triangle mesh. We will be ironing these out this week while we finish beefing up the new demo.

A large amount of the collision data stored in world resources has been eliminated. If you rebuild geometries in a world, you will see the size of the files decrease quite a bit. This is especially true for worlds containing terrain, which can shrink by up to 80%. The fastest way to rebuild your geometries is to open a world, select all with Ctrl-A, and then rebuild with Ctrl-R. Save. If you have applied per-vertex ambient occlusion to any geometries, then it will need to be regenerated after this. Please back up your Data directory before rebuilding your worlds, just in case something goes haywire.
