Re: Basic Network Tutorial added - feedback plx

by Cthulhu » 14 Apr 2008, 08:15

I've added loads to the tutorial, mainly divulging in the act of changing a player's name. It's probably already built-into the engine, but I figured it'd be lolzworthy to add it. The reader will be introduced into basic messages with some data (sending and receiving), etc. The tutorial is still at http://www.terathon.com/wiki/index.php? ... k_Tutorial, and I'd like moar feedback. It's getting pretty long btw, so I'm thinking of separating it into two or three bits now.

The name changing is done in two steps: First, when a client types the name command with a new name, the client system sends a name change request message to the server (even if it's the server itself). The server can then do some validation, then changes the name on the server itself, and finally sends a name change message to all clients - including the one requesting the name change. The name is then updated for that player on all clients. We've tested the whole thing on a lan with a total of 4 people without any problems, so it should work just fine. I'd like you lot to try it out and give me feedback, for great justice.
