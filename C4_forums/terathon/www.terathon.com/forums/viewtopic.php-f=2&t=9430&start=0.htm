TheRhinoDude wrote:The prevalent comment was "who needs Speedtree?".


Excellent! The goal was to completely obviate the use of SpeedTree. No longer would anyone have to suffer the pain of integrating such a third-party library. Furthermore, C4 supports a much greater range of features on its impostors, including full support for shaders, dynamic lighting, dynamic shadowing, and even dynamic self-shadowing. You won't get those with SpeedTree.

Re: Version 2.1 Now Available

by Eric Lengyel » 09 Jul 2010, 14:18

Adam Golden wrote:Eric, related to adding an impostor node to a world containing the real model and assigning the impostor material to it - will this also work in .mdl resources? or .wld only?


It should work in model resources, but I don't recommend using impostors for transient nodes in the world that get created and destroyed during gameplay. Whenever a new impostor is added to the scene or removed from the scene, a big vertex buffer for all the impostors for the same model has to be rebuilt. Impostors are intended to be used for objects that are permanent parts of the world.
