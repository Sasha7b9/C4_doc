Re: Terrain Pallet, Texture Set & Materials

by Eric Lengyel » 05 Nov 2014, 19:32

GameWizard wrote:If one clicks on one of those up pops a 3x3 set of textures to choose from. Is that set of 3x3 textures a terrain pallet?


Yes, that's the terrain palette.

GameWizard wrote:Starting from a different set of original set of 2d textures, what are the steps needed to use those textures as a new and different set of textures?


Create a new palette with those textures as described in the wiki article about creating terrain palettes. Then select the new palette in the shader editor for the terrain material. (In the terrain tutorial level, there are four nodes in the shader that use terrain palettes -- one for the diffuse color, and three for the normal maps.)
