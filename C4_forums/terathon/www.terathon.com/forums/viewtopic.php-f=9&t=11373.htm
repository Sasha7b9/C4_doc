Re: Browser widget with Awesomium 1.6.3

by Eric Lengyel » 26 Nov 2011, 17:30

C4 only works with Awesomium 1.6.2 at this time. The guys who make Awesomium like to change their API when they make minor revisions, and that is causing a mismatch in the function prototypes. It is very bad to change the API like this for something that is always used as an external library like Awesomium, especially in a minor version update.
