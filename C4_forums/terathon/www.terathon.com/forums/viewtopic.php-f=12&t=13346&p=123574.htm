Open-Source OpenDDL Libraries

by Benjamin Dobell » 24 Nov 2013, 09:53

I've started developing a series of generic OpenDDL encoding/decoding libraries for different programming languages under the title "libopendll". The first library of which to near completion is a Java library. I'm hoping that people will find the various libraries useful for data exchange over the Internet as an alternative to XML or JSON.

If you're writing web services for your game (leader boards, lobbies etc.) then perhaps you'll want to check it out. However, as I'm sure Eric will attest to, you can really use OpenDDL to do whatever you want.

The library is a bit rough around the edges and currently missing some key OpenDDL composition features. But I've included two samples to at least give everyone an idea of where the library is headed.

Take a look - https://github.com/Benjamin-Dobell/libopenddl

Any feedback is welcome.

Re: Open-Source OpenDDL Libraries

by Benjamin Dobell » 26 Nov 2013, 07:08

I've just made the first libopenddl (pre)release which includes the libopenddl 0.9.0 Java library.

https://github.com/Benjamin-Dobell/libopenddl/releases

There isn't any documentation at present (beyond the example code included in the three samples), and the library hasn't been thoroughly tested. However, I'm keen to get this in hands of any potential users so I can get some feedback.

Realistically this is probably exactly the kind of project that could benefit from unit tests. But... I figure testing is only for people who make mistakes, right?

Okay, not really. I'll get around to adding unit tests one day, but probably not until I've written the Objective-C and Ruby libraries.

EDIT: Just realised I'm still missing functionality to create properties. They can currently be parsed and read as strings. OpenDDL properties don't have their types defined in the OpenDDL itself, which is why properties are read as strings. However, there really should be some convenience methods to parse these strings into different data types.
