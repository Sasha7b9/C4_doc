The demo game module now defines the variable $fov to be the field of view for all cameras, in degrees. The game will clamp the value to the range [45,90].


Just a heads up for anyone wanting to alter fov... The fov variable was missing from my Variables.cfg file. Once I added it in manually, I was able to alter the fov from the console.

Edit: Another heads up... For lights that are contained within reference markers, make sure "Toggle reference worlds" is enabled if you want to view them in the perspective viewport.

by Eric Lengyel » 07 Apr 2007, 23:32

Scott Sutherland wrote:I put about 12 burning rain emitters in the water level. It looks damn amazing with the motion blur enabled.


This is an experimental particle system, so I didn't mention it in the release notes. But everyone seems to be using it, so I'll talk about it here.

If you place a Burning Rain particle system in the scene, then make an emitter volume for it and connect the particle system's EMIT connector to it. The rain will be distributed evenly at the top surface of the emitter volume and fall to the bottom surface, where some of it will turn into fire. The rain drops that will become fire turn bright orange before they hit the ground.

Each of the flames is currently added to the scene as a separate fire effect with its own controller. This works, but it's not the best way to do things with so many flames. I'm working on a way to make flaming particles so that they can all be drawn in a single render call.
