by mmelo » 16 Mar 2011, 17:25

Hi,

I started playing around with C4 word editor today but seem to be running into a bit of problems importing a small model (and its textures). This DAE file of a textured cube (with two materials) was exported directly from Blender 2.56a.
Here's what I did:

1) Stock World Editor 2.5.2 -> New World
2) Import Scene -> selected multimaterial_pack.dae (which was previously placed in Import directory). Its textures are inside a "textures" subdir as per the attached file;
3) Ticked "Import Texture Maps" and Ok

I do get the cube into the world and it does create two materials with "Texture Map" named after the textures, but

a) the textures themselves don't appear to have been created.
b) also, for some reason the materials have no name though they do have in the DAE file.

I then tried to manually create the textures via "Import Texture". I select the TGA, get the dialog fine, press OK and get no errors. But

c) no new TEX file appears anywhere in or below the C4.exe dir.

I'm sure I'm doing something incredibly stupid here but - for the life of me I can't figure it out. I've looked into the Wiki and older posts but can't seem to find anything that sheds light here. Can anyone help please?

Many thanks!

Re: Having some trouble importing an object

by mmelo » 16 Mar 2011, 18:15

Viva!

I changed the DAE to have <init_from>textures/Import/CityPainterly3.tga</init_from> and moved the files to that sub dir and it still won't import automatically. After turning these statements to fully qualified paths (rather than relative to the DAE file) it imported fine. So it seems the auto importer just doesn't like relative paths (low priority issue).

So, other than the loss of the material name (low priority issue, but maybe worth having a look), seems like the problem is sorted. Thanks all!
