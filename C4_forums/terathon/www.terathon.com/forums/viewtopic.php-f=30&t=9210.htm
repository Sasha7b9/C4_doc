supernerdboys wrote: by the way, how would I go about getting a physics object (the ball) to trigger (the goal hole) an event(a score point, or loading the next level)? Also, how do I get that trigger to load the next world file. Or should I just make the whole game one world with referenced worlds in different zones.


In the world editor there is a page called 'triggers'. Basically, they are volumes that you put in the world that you can set to activate when your ball intersects them. When the trigger activates you can have it do something like run a script, or, in your case, you can create a custom controller for it run. Look at the demo game. The worlds have triggers everywhere so you can see how they are used there.
