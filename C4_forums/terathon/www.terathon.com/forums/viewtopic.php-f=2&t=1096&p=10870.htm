Build 128 now available

by Eric Lengyel » 02 Oct 2006, 01:18

Build 128 is now available for licensed users at

https://www.terathon.com/developer/download.php

This build includes a well-functioning multiplayer game. There is still a lot that we want to add, but the essentials are in place. Please note that there has not been any significant testing over the internet, and therefore performance is not expected to be that great. On a LAN, though, the game runs very well and is pretty fun.

Here's a short list of things we're planning to add to the multiplayer game: kill limits, time limits, armor, more power-ups, more ammo packs, awards, lots of sound effects, first-person weapon view, weapon auto-switch, new weapons (proton cannon, nitro gun, shotgun), protection shield switch/time config, self damage switch, file transfers, and a dedicated server mode.

by Eric Lengyel » 02 Oct 2006, 02:17

The teleporters in the MP world use a different material for the cascading ripple effect, but the floating effect parameters are the same as the Demo world. The new settings (amplitude and period) added to the TeleportController class control how fast and how much the teleporter's destination image floats up and down.
