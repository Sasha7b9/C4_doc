by Eric Lengyel » 11 Jul 2007, 21:51

The problem is that your ReceiveMessage() function doesn't have the right signature, so it's not overriding the virtual base class function. You need to add a 'const':

Code: Select all
void ReceiveMessage(const ControllerMessage * message);


Once I fixed that, using the following code for SendInitialStateMessages() made everything work right:

Code: Select all
void SpellController::SendInitialStateMessages(Player * player) const
{
   const Point3D& position = GetFinalPosition();
   Vector3D velocity = GetVelocity(GetProjectileTime());
   
   player->SendMessage(SpellUpdateMessage(GetControllerIndex(), position, velocity));
}
