Destroyer status

by Eric Lengyel » 13 Feb 2007, 19:56

Destroyer is coming along very nicely. A lot of good stuff is complete, but work on the remaining stuff has revealed the need to "go a little further" in some places in order to do things right. Instead of delaying the completed features any longer, I'm going to release Destroyer in two parts. This will also close the gap between what is currently available to licensees and what is currently in development so that new tutorials can be written that accurately reflect the new state of the engine.

There has also been a huge speed improvement on ATI hardware that necessitates the immediate release of an updated demo.

Look for Destroyer, Part I, late tonight PST. Some code that is a work in progress has been rolled back so that everything in this release is stable. Thus, what you see in this release merely represents a lower bound on the current state of development on the engine.
