Slope calculation

by GameWizard » 17 Oct 2014, 13:15

I have this code:
Vector3D terrainNormalVector = collisionData.normal;
Vector2D orientationVector = CosSin(GetModelAzimuth());
Vector3D modelOrientationVector(orientationVector.x, orientationVector.y, 0.0F);
Vector3D tangent = modelOrientationVector - ProjectOnto(modelOrientationVector, terrainNormalVector);

//The horizontal change is then Magnitude(tangent.GetVector2D()), and the vertical change is tangent.z, so you now have the slope. Don't expect this tangent to have unit length.

float horizontalChange = Magnitude(tangent.GetVector2D());
float verticalChange = tangent.z;
float slope = verticalChange / horizontalChange;



I get positive values for the vertical change as I go across terrain, but I do not get negative values if the terrain slopes down.
