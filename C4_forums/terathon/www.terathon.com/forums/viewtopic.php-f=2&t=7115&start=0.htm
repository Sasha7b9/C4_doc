Re: New C4 Engine Contest Begins

by Eric Lengyel » 05 Apr 2009, 21:48

The Basic Edition will be a binary-only version of C4. It will include the optimized builds of the engine and tools, but no source code other than the header files needed to build a game module. The Basic Edition will include six months of free updates, but after that period, a renewal will be necessary in order to keep receiving updates. The cost of the Basic Edition will be much less than the Standard Edition, but a final price has not yet been established. Upgrades to the Standard Edition will be available for the difference in price.
