Re: Making a model a subnode of another model

by Eric Lengyel » 25 Oct 2014, 12:47

You don't want to call World::AddNewNode() for the testBoxModel because you're adding it to the humanModel right after that. So just remove this line:

Code: Select all
locator->GetWorld()->AddNewNode(testBoxModel);


And add the following line at the end:

Code: Select all
testBoxModel->Preprocess();

Re: Making a model a subnode of another model

by Eric Lengyel » 12 Dec 2014, 19:50

In the demo game, the mount node angle is a relative angle between the look direction and the model's forward direction (which is modelAzimuth). I don't see a look direction in your code, so your relative angle would always be zero. The value of t is always (1, 0) instead of the cos/sin of modelAzimuth.
