Re: Version 2.8 Final Now Available

by Adam Golden » 18 Apr 2012, 22:38

Thanks again for this, I'm always excited about your updates - I have almost no Engine Code changes for any project I'm working on, including Wingball. Specifically.. the only changes to Engine Code still necessary for me are adding includes for cURL, adding "C4API" to export GetExtensionData for my graphics options page (if it's even necessary to get details that way?), and changing the names of the Integer2D variables named "min" and "max" in C4Water and C4Particles so there's no conflicts with those functions added by the cURL includes. Oh, and turning on Leak Detection in C4Memory each time lol, if that counts.. at least, that's it now that C4 has a direct state access workaround as necessary and the external browser support built in! Amazing.

For anyone else with big projects that were/have been shelved for a while, if you're feeling apprehensive about updating, just go 1 version of C4 at a time, since moving a lot of code built on 1.5.9 up to 2.8 directly (as an example) could feel overwhelming or like too much effort... but it's really not once you dig in. Considering the scope of the engine, the backwards compatability is excellent, imho..
