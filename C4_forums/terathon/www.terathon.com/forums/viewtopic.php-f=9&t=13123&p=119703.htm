Re: Is it possible to load scripts in the script editor?

by Eric Lengyel » 19 Aug 2013, 12:45

I don't really understand what you're asking. For a script attached to a node (with a script controller), you can hit the Edit Script button under the Controller tab in the Node Info window or you can simply type Ctrl-E directly in the editor when the node is selected. For a script attached to a widget, just select it and type Ctrl-E.

Re: sharing Shaders, it is possible to export and import a material with its associated shader. However, the textures that are referenced to that shader don't get hard copied er... "included", so if you want to share a shader and have it "work" with another user then you must include the exported material and the associated .tex files as well; (or the user will have to hunt down all the missing .tex files in the shader).

As far as scripting is concerned, I really have not touched the script system much... so I can't assist in that area.
