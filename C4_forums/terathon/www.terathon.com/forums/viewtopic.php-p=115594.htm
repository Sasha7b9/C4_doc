Re: Wingball

by Adam Golden » 29 May 2012, 12:05

Frank Skilton wrote:Wow, that's rather impressive!

I take it you're planning on some bigger/longer levels?

Thanks Frank! Yes - that too eventually, but the main focus for me was never making a player wait long - kills immersion. If it takes 5 seconds to load enough around the player to start playing, the player should be start in some kind of staging area instantly - where driving out the launch tunnel would start your time, but the stage would already be all around you by then.

A secondary issue this resolves is detail management. If you're preloading a stage you're limited by how much can be put into the world before load time gets rediculous. If things are constantly loading and unloading there's no such limit - so up close there could be much denser foliage than I've been able to achieve previously, just for example. Frame rate and performance is already way up from the previous release due in large part to the addition of terrain optimization/LOD. This new system also loads only the distant LOD for distant objects - the video demo above shows a "preload batch" size of 1 - after each object has loaded it's added to the scene. A slight boost in speed here is also available by setting these preload batches up to 10 or more instead.. except that you don't get so smooth of a feel when a bunch of things pop in at once.. so I prefer what I've done over "maximum background performance".

Also, if you used plain geometry and replicated the above video, you would find it's even faster. For Wingball terrain I have to assign 3 high res blend textures to each block (8x8 patches) shader and invalidate each patch again before it is ready to display - which makes it take a bit longer to generate each patch than it would otherwise. Still, in the first part (with wireframe off), by the time I walked to the edge of that platform, the world was done loading. And, in this video, I'm using highest detail LOD and a huge part of the map. What I will be doing before the new system makes it into the game (loading/unloading being centered on the player's position)... that will make this look primitive by comparison.

Another idea I've had in the past which wasn't possible until now was multiple layers in a world. So for example driving on a frozen tundra, ice breaks apart and you fall down onto a layer underneath. Higher points on higher layers means penalty for being careless.. haven't decided I will actually *do* that in a Wingball stage, but new possibilities are always welcome.
