Re: Multipane Widget

by Eric Lengyel » 20 Aug 2011, 18:52

A typical way to manage the panes is to group all of the widgets in each pane and then show/hide these groups as the tab selection changes. You get a kEventWidgetChange event for the multipane widget whenever the user changes tabs.
