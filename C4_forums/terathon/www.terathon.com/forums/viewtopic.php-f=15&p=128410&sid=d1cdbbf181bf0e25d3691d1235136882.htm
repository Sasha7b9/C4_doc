Re: Gloss/roughness vs specular/reflection

by Eric Lengyel » 05 Oct 2014, 23:20

The term "gloss map" hasn't historically been used consistently, but now usually means "specular power map". So it should be multiplied by some maximum specular power and fed into the "p" input of the Specular Reflection process.

The "specular map" should multiply the output of the Specular Reflection process.

We're going to change the meaning of "gloss map" in C4 to match these.

Re: Gloss/roughness vs specular/reflection

by trebor » 11 Oct 2014, 03:21

We are also surprised how good stuff can look in C4 even there is no gamma correction afaik.
However gamma correction should be more important with the contribution of multiple lights. I already added support for sRGB textures (which is trivial since C4 >= 3.5) but it would require to accumulate the light interactions in a HDR buffer and apply the gamma correction back from linear RGB to sRGB during the tonemap process.
It might also work with Renderer::EnableSrgb() during the light accumulation phase. I need to test that. Creating a sRGB capable OpenGL context seems to be no problem on Windows.

I implemented a new Specular BRDF node in the shader editor which does specular in the same manner as developed by Naty Hoffman which was also adopted by the game Remember Me.

However for full PBR the renderer requires:

1. Performing all light calculations in linear RGB space
2. Energy conservation: diffuse + specular lighting <= 1 which means the reflections don't emit more light than incoming light
3. A specular Microfacet BRDF node which contains everything like Fresnel and uses the specular color as input (done)
4. Spaces for specular environment reflections that use parallax corrected cubemaps (this one is not trivial as the cubemaps have to be filtered for mipmaps, as you need to index the mip maps depending on the roughness of your surface)

One nice thing is that you can simplify the default shader graph if you add a more fancy Specular BRDF node:

https://www.dropbox.com/s/q59w6ih33k1ul ... 8.png?dl=0

I implemented the Microfacet BRDF node according to this presentation:
http://renderwonk.com/publications/s201 ... fman_b.pdf
