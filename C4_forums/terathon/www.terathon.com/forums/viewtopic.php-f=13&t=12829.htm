Commercial for use with Visual Studio only
CodeRush and Visual Assist X. I've never used them before, so I don't know if they are worth it. If I do buy them, I would also have to buy Visual Studio Pro 2012. The lowest price I've been able to find is ~$500, so I have to consider that in the total cost.

Free cross platform tools

Re: Code Beautifiers/Code Refactoring?

by Grognard » 01 May 2013, 23:29

I'd suggest to NOT edit the code of the library. Instead build your own interface to the library on top of the library's code.

For instance with C4 I made my own class that used C4's collision detection, but if need be I could put in some other code or move to another library.

You might slowly refactor it anyway but I'd only do so as needed or it's likely you will be wasting your time and introducing bugs.

I just got around to trying this. I used Eclipse a few years ago and didn't like it much, but I see it has come a long way.

ATM I'm using it as an editor and will continue to build and debug in VS, until I figure out how to do both from within Eclipse. Their refactoring works well, quite impressive because it is free.

I also got Artistic Style working in Eclipse and the only problem is there is a pause of around 5 seconds before it does its job.

These are my Artistic Style settings. I'm pretty sure they match the C4 standard on almost everything.

MSVC++
-A1 -t4 -C -S -K -N -L -w -Y -M -f -p -H -U -E -k3 -W3 -O -o -xy $(ItemPath)

Eclipse CDT
-A1 -t4 -C -S -K -N -L -w -Y -M -f -p -H -U -E -k3 -W3 -O -o -xy ${resource_loc}
