by Eric Lengyel » 05 May 2009, 13:31

A sound can only start playing at the beginning of each mix loop, which has a period in the tens of milliseconds. It's possible that you're attempting to replay a source that's still playing in some cases.

So back on topic:

I added this to Sound class.

Code: Select all
void SetEndTime(long time)
         {
            if (time != 0)
            {
               if (endTime == 0) frameCountFull = soundFrameCount;

               soundFrameCount = soundFrameCount * ((float) time /GetDuration());
            }
            else
            {
               if (endTime != 0)
               {
                  soundFrameCount = frameCountFull;
               }
            }
            endTime = time;
         }


You will also need to set it back for the last shot. Sometimes there will be 1 shot less or more but still better than default behaviour

EDIT: And probably you want to fill buffer before that. Call soundStreamer->FillBuffer(); with original frameCount upon playing.

Ludi wrote:
Eric Lengyel wrote:C4 only plays one continuous sound to the actual hardware, so that will never be the source of any sound problems.

The sound driver only sees one "sound" from C4, the final mix buffer, and it plays continuously while C4 is running. All of the real sounds played in a game are mixed by C4 itself into the continuously playing mix buffer.
