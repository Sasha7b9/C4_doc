Well, if you could convert your custom terrain to a height map then you could make a voxel terrain out of it but the problem you will run into is resolution. The voxel terrain is a gridded terrain and roads usually don't follow a grid unless you made a city and have the streets on a grid. But even then the resolution you'd need would most likely not be feasible with the voxel terrain.

When you need high detail precision like paved roads a custom terrain is pretty much the only way to go. Voxel terrain is good for "non precision" terrain with paths through a forrest and things like that.

You could make the roads as custom meshes and place them on a voxel terrain but since they need to be very close to the ground you will probably run into Z fighting. Making the voxel terrain smooth enough to be a nice clean surface for custom roads is also difficult.

Re: Precise Terrain creation help needed

by Arthain-Baka » 20 Dec 2011, 21:57

You could either make the terrain align to the road or make to road align to the terrain. It is actually very easy to get the terrain geometry from C4 (as in Voxel to Triangle Mesh) but I haven't done any work with programatically altering voxels in C4 so I'm not sure how easy that is...

What is your road geometry like though?
Is it mainly flat polygons with some kind of bump or parallax mapping for the details or is it a high polygon mesh?
If it's mainly flat it'd be quite easy to align it to the terrain but it would mean that your road path needs to be constructed in the voxel terrain. That way it'd be more like a road paintbrush that you could move along the terrain and it would fit the road to the terrain which would take longer to setup but for creating worlds in the long run it would be invaluable.

If you wanted it the other way so that the terrain is altered to fit the road there will still be work to be done and I think it would be less of an automatic process (because otherwise you'll get strange geometry such as a cliff next to a road that you didn't want). And you'd either need some system to ensure some level of compatability between the terrain and the road (or create the road first and sculp the terrain around it), or break the road into tiles which can be rotated. And I think the easiest thing to do with the terrain would be just to drop the section immediately under the roads down a few units to avoid Z-Fighting which would either be a manual job or you'd need to create a painting tool for each road tile to do this automatically.

Another solution would be to create a tool to export terrain you create in C4 to something simple like an OBJ file which you can then import into Blender to make your road ontop of so it can just be imported straight into C4 without worrying about Z-Fighting, this method would pretty simple to do as OBJs don't have a complicated structure and it's easy to get the triangle soup from C4s Voxel Terrains.

Or you could just avoid using the voxel terrain at all and model it all inside Blender.

Another option which would require programming would be to create a new import tool that will accept a triangle mesh and then transform it into C4s Voxel Terrain, though due to the nature of voxels this might mean you lose some detail. On the plus side there should be plenty of references for voxelising triangle meshes so you'd just need to alter one to C4s voxel structure.


I think I rambled for longer than I intended too... hopefully it either helps or gives you some ideas

You mean importing a high resolution mesh and somehow converting it to a voxel terrain? I'm not so sure this is really feasible and definitely not trivial. You could pretty much just as well make a voxel terrain from a high resolution height map then. A custom mesh is really the only solution without some road making tool built into C4.

Re: Precise Terrain creation help needed

by Javier Moya » 21 Dec 2011, 11:51

I don't know Blender, but in Max, loft objects are a good solution to create roads. A loft object is similar to C4 path tube geometry, but you can define the cross section. It has more options like banking control and deformations along the path. In addition, the uv map is automatically arranged so it follows the path, making it perfect for roads. Maybe blender has something similar. A quick google search so you can get a picture of this tool:

http://lab.visual-logic.com/skills-techniques/modeling/creating-a-street-using-loft/

I made some circuits using this technique long ago (really old work):

http://www.javy3d.com/wordpress/?page_id=63 (at the middle of the page, roughly)

The only solution that I can think of using this and C4 voxel terrain is that the road borders are long enough so they get into the terrain geometry. It wouldn't be the first game doing this (though I don't know if this is an option for you).

Btw, Acropora (http://www.voxelogic.com/) can 'voxelize' imported meshes. Then, you can export the 'voxelized' mesh to RAW, if I'm not wrong, which can be loaded into C4 WE. Maybe you can convert your terrain into C4 terrain this way.

Hope it helps.

Regarding roads and terrain:
The last time we created terrain and roads I created a road segment added array and than curve modifier to bend it along a spline. Unfortunately this resulted in wrong banking of the road.
