Re: Version 4.0 Beta 1 Now Available

by Eric Lengyel » 12 Sep 2014, 20:14

If you're seeing any strange rendering on AMD hardware, it's due to a driver bug involving the GL_ARB_multi_bind extension. We intended to disable this, but forgot before releasing the beta. You can disable this extension by finding it in the table near the top of C4Graphics.cpp and changing the last item on the same line to false instead of true.

This extension works correctly on Nvidia hardware, and it is not supported on Intel hardware.
