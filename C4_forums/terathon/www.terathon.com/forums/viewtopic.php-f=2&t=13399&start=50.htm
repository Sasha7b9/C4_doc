by Eric Lengyel » 25 Dec 2013, 14:57

BORODA wrote:Awesomium, Logitech and nVidia libraries that are in the engine currently


Awesomium is used only in an optional plugin that isn't part of the core engine. We're actually going to drop official support for it in version 4.0 because it doesn't run in 64-bit and maintaining it has become a serious hassle.

The Nvidia library is just an interface to the graphics driver that we use to retrieve the driver version properly. You could also say that C4 uses the OpenGL library, but we have no choice in that, and it's really a driver anyway.

The Logitech library is just a driver interface as well that we have to use in order to support certain input hardware.

Re: Version 3.5 Beta 2 Now Available

by Eric Lengyel » 26 Dec 2013, 04:21

OpenGEX is designed to support data in a format / configuration that would be most useful to game engines. Features like smoothing groups from Max are not directly supported, but smoothing groups are taken into consideration when writing the normal vectors to an OpenGEX file so they represent the correct result that is produced internally by Max. The same goes for lots of features, and OpenGEX has been designed with generalizations that cover a lot of different ways of doing things in different modeling programs. The format was never intended to preserve the original data for program-specific features, but to use that data to convert a scene into a form that would work in a game engine, given that they all need to render the scene using typical GPU functionality.

BORODA wrote:Oh by the way, does OpenGEX and C4 support animated bones without skin?
