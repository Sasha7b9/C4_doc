Re: Build 147 Final Now Available

by David Vasquez » 28 Feb 2008, 03:38

A feature to allow the player to be hit by the lightning is a cool idea.

I also think it should be a lot more hazardous to walk around in the burning rain field, since I've only been hit by the fireballs twice with the default settings, since the odds aren't that great for getting hit at any given moment. (If you leave the player standing in the burning rain field, it takes a long time to eventually be killed by repeated hits from the fireballs.)

The BurningRain particle system has two variables, minFireballTime and maxFireballTime, that can be adjusted in the World Editor to increase the frequency of the fireballs. I found it was not overly dangerous to set those values to 0.25 (min) to 2.0 (max), which has the added benefit that there is often more than one fireball in the air, which makes for quite the show.
