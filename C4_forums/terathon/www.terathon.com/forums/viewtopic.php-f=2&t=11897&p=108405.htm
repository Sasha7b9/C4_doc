Re: Version 2.9.1 Final Now Available

by Eric Lengyel » 07 Jun 2012, 21:09

You can do this with CFG files. Just put an [i]itexture[/b] command on each line, and end each command with a semicolon. You can store CFG files in either the Data folder hierarchy or the Import folder hierarchy. If stored in the Data folder, use the exec command to run it, and leave off the top-level subdirectory of the Data directory. If stored in the Import folder, use the import command to run it, and keep the top-level subdirectory of the Import directory. You can find the command-line parameters for the [i]itexture[/b] command here:

http://www.terathon.com/wiki/index.php/ ... _a_Texture

As an example, below is a file that I have that imports a bunch of textures used in the world editor. The output name of the .tex file is the same as the import name specified in each command.

Code: Select all
itexture Tools/WorldEditor/volume/Acoustics -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Ambient -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Beam -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Camera -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Emitter -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Field -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Fire -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Flare -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Fog -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Light -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Occlusion -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Paint -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Panel -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Quad -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Shadow -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Shape -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Source -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Trigger -format INTS -alpha ALFA -highres;
itexture Tools/WorldEditor/volume/Tube -format INTS -alpha ALFA -highres;
