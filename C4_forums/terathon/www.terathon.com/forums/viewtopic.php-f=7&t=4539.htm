by Eric Lengyel » 13 Mar 2008, 14:11

Cthulhu wrote:Is this correct, does this have a proper reason, or is this an error of sorts?


This is correct. A client machine is sending a message to the server that says "I want to move". When the server receives that message, it sends a message to ALL clients saying "Player X has begun moving" so that everybody sees your character start running.
