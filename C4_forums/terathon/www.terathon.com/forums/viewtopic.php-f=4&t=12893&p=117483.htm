Re: FrustumViewportWidget

by Eric Lengyel » 08 May 2013, 02:38

There is some stub documentation in the API docs for this. I'll bump it up to the top of the list to be the next thing to be documented more thoroughly.

Do you have any kind of mock-up of how the inventory will look? If you just want to render a 3D object in a small viewport, then it would be really easy to use the WorldViewportWidget. You can call the LoadWorld() function on this widget to load a WLD file containing an inventory item, and you can let the user click and drag to spin it around by calling the EnableCameraOrbit() function. There's an example usage in the WorldPicker::UpdatePreview() function in C4FilePicker.cpp. This code shows the preview when selecting instanced worlds in the editor.

Re: FrustumViewportWidget

by Eric Lengyel » 08 May 2013, 13:55

With any viewport widget, you have the option of continuously re-rendering the 3D scene or copying the current contents to a texture that can be used to cheaply display the most recently rendered scene. The editor stashes the current render of each viewport in a texture when you're not doing anything so that the UI stays responsive. I'll point you to the relevant API documentation later today after it has been posted.
