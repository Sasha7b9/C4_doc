Re: Shader Editor: Glow

by Arthain-Baka » 30 Sep 2011, 01:16

Oh, my bad I completely misunderstood your question :p
I wouldn't have thought that it would be the desired result, it seems a little pointless in most cases.
Here's some info from Eric:
Eric Lengyel wrote:... bloom and glow work by writing their intensities to the alpha channel in the frame buffer. When they are used, you can't also use the only available alpha channel for alpha testing. The solution is to turn off alpha testing and use the "Kill Fragment" process instead. It's slightly slower than alpha testing, but you have no choice if you want to kill fragments and write a value to the alpha channel.

The complete thread where that was is here.

So with that process I would imagine that it isn't a bug as it would write the alpha straight to the frame buffer, you'd need to apply some handling code to avoid it.
