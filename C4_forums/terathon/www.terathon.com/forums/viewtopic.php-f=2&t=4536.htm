Build 148 Final Now Available

by Eric Lengyel » 13 Mar 2008, 03:01

Build 148 is now available for licensed users and can be downloaded from the usual place:

https://www.terathon.com/c4engine/registered/index.php

Some miscellaneous notes:

  • With this build, we begin including project files only for Visual Studio 9 and Xcode 2.4.
  • The Data.zip file is getting rather large, mostly due to textures. We are going to be updating the texture format for build 149, and they should compress a lot better.
  • Starting with what would have been build 150, we're going to use more traditional version numbers. Build 150 will be called version 1.5, and major/minor version numbers will be changed for new releases based on how big the new features are.
  • It's very probable that version 1.5 will also mark a price increase for the standard license. This isn't carved in stone, and the new price has not been set. Such an increase does not affect current licensees in any way.
