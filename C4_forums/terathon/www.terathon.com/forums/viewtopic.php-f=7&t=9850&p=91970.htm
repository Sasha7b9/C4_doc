Please don't discuss Java in this tread or forum? C4 is built in C++. If you don't want C++, don't use C4.

Sending a UDP datagram on Windows, Mac and Linux is really simple.

Code: Select all
int sock = socket(AF_INET, SOCK_DGRAM, 0);

struct sockaddr_in sin;
memset(&sin, 0, sizeof(sin));
sin.sin_af = AF_INET;
sin.sin_addr = htonl(0x12345678);
sin.sin_port = htons(0x1234);
int r = ::sendto(sock, "Hello, World!", 13, 0, (sockaddr *)&sin, sizeof(sin));


This code is pretty much 100% portable.

If you think filling out the sockaddr_in structure is hard, then writing a simple wrapper class that does it for you is trivial.

Re: C4 - non C4 connections

by Robert » 10 Dec 2010, 20:17

I'd suggest using an stl container to make a kind of data-to-send-list, a queque type fifo structure might be completely sufficient. Then give a struct containing a pointer to that data structure to the thread that you create only for sending data, and let that thread regularily check that list struct and send the data stored in its fifo queue. Then you won't have to care if sockets are blocking, you'd just have to watch somewhere that you can still send/receive, i.e by using a timeout. Do the same with the receiving part and perhaps set a mutex for the two fifo list objects. That might end up more effective and more flexible than using non-blocking sockets. I'd suggest stuffing both threads and the connection data into an own class, so you can easily re-use it for other projects later.

   MySocketBlockReader::MySocketBlockReader(MySocket * socket, Handler * handler):
   bufferHeader(4)
   {
      this->socket = socket;
      this->handler = handler;
      pbufferMain = nullptr;
   }
   MySocketBlockReader::~MySocketBlockReader(){
      if(pbufferMain) delete pbufferMain;
   }
   void MySocketBlockReader::process(){
      if(!pbufferMain){
         int s1 = bufferHeader.read(socket);
         if(s1 < 0) return;
         if(bufferHeader.isFull()){
            const char * buf = bufferHeader.getBuffer();
            int size = (buf[0] & 255)
               | ((buf[1] & 255) << 8)
               | ((buf[2] & 255) << 16)
               | ((buf[3] & 255) << 24);
            bufferHeader.clean();
            pbufferMain = new MySocketBuffer(size);
            if(s1)
               pbufferMain->read(socket);
         }
      }else{
         int s1 = pbufferMain->read(socket);
         if(s1 < 0) return;
      }
      if(pbufferMain){
         if(pbufferMain->isFull()){
            const char * buf = pbufferMain->getBuffer();
            if(handler)
               handler->handle(buf, pbufferMain->getSize());
            delete pbufferMain; pbufferMain = nullptr;
         }
      }
   }
