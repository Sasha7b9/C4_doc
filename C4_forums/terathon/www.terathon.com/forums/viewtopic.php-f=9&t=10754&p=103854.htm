Re: making closed mesh terrain

by Zitheral » 08 May 2011, 04:06

I'm not sure I understand what you are trying to do... are you trying to use the world editor to make asteroids? If so, it isn't going to work well because the world editor doesn't allow direct vertex manipulation. You would only be able to create unaltered primitives. You might?? be able to make something with the path tool... but realistically, no. If you are familiar with a 3D modelling program, you would probably need to actually model your asteroids. If not, about the only thing you can do is buy models from a 3rd party or use the .map file importer I posted in the community tools section. Making asteroids is extremely easy in Dark Radiant, but you would have to go through some setup before you can use it.
