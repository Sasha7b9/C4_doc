Connect4 Game

by thomas » 10 Dec 2009, 06:30

My objective was to make a Connect Four game using only the script functionality provided by the C4 Engine. I did have to make a small change in the engine - found here - but it could've been done without it.

The Connect4 game is located within a world (works with 1.5.9): http://members.optuszoo.com.au/~dakkon/Connect4.zip
Custom C4 executable with small changes (built upon 1.5.9): http://members.optuszoo.com.au/~dakkon/C4.zip

Screenshot of the game in action: http://members.optuszoo.com.au/~dakkon/connect4.jpg
Main script for button placement and win scenario checks: http://members.optuszoo.com.au/~dakkon/full_script.jpg
