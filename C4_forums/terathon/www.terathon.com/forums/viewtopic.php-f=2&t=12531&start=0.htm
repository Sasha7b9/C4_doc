Re: C4 Engine 3.0 development release now available

by Eric Lengyel » 08 Jan 2013, 16:44

If you'd like to instantly see the difference in rendering with and without SSAO turned on, you can type these into the command console or put them in your roaming input.cfg file:

bind "," "$renderAmbientOcclusion=0";
bind "." "$renderAmbientOcclusion=1";

Then the < and > keys will turn SSAO off and on while you're walking around a level.

Re: C4 Engine 3.0 development release now available

by Davaris » 09 Jan 2013, 20:04

ska wrote:What the landscaping tool will do?


The landscaping tool has a few steps. You select additive or subtractive brush and a window opens. In that window, you can create as many instance groups as you want. There is a Worlds tab that lets you add multiple world files to each instance group. There is a Settings tab where you can alter density, overlap, placement, randomness, etc for each instance group. The last tab is called Modifiers, it has a list of 10 C4 Modifiers you can attach to each instance group.

It doesn't place anything yet, as far as I can tell, but it looks like its going to be very useful, when it is complete.
