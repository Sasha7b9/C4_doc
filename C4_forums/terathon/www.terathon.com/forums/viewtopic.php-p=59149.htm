2) You can't use the same DX on both XP and Vista and still take advantage of current-generation hardware capabilities.
3) OpenGL is faster.

It would only require even more maintenance since every feature would have to be implemented in 4 more or less different render APIs -- as a direct consequence new features would take longer. And if AAA studios can't ignore the pre DX10 market, how on earth do you think indies can?
