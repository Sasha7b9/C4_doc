Re: Dedicated Server Questions

by Eric Lengyel » 02 Sep 2011, 22:54

The intention is that you don't comment out any game code in dedicated server mode. This mode prevents the engine from rendering any graphics or playing any sounds, but everything else still takes place. The game shouldn't even be aware of whether it's running as a dedicated server, except that it wouldn't allow a local player.

Re: Dedicated Server Questions

by Eric Lengyel » 30 May 2012, 18:04

As you've seen, the server build has no interface whatsoever. It's completely up to you to implement whatever kind of interface you need for your game. You can put commands (equivalent to what is understood in the C4 console) on the command line or put them in a CFG file that gets executed by your game. You could implement a basic terminal interface that uses stdin and stdout. It's up to you.
