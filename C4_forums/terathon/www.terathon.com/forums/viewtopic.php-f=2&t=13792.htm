Re: C4 Engine 4.0 development release 3 now available

by Eric Lengyel » 29 Jul 2014, 01:16

Dalus wrote:
Eric Lengyel wrote:What OS and GPU?


Windows 7 Home Premium 64-bit

AMD Radeon HD 6970 (Catalyst Suite 14.4)


Thanks. It looks like this is being caused by the GL_ARB_multi_bind extension not functioning correctly on AMD hardware. You can disable this extension by typing "ext" in the command console and unchecking it, but this only applies to the current run. To disable it permanently, find the table of extensions at the top of C4Graphics.cpp, set the last value on the line for GL_ARB_multi_bind to false instead of true, and rebuild.
