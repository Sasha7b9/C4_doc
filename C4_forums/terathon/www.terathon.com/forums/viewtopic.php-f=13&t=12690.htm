Re: Anyone using VirtualBox?

by jwatte » 08 Jun 2013, 22:58

Note that the drivers for OS-es /inside/ the VM should be drivers for whatever graphics hardware abstraction the virtual machinery exposes -- this is /not/ the same thing as the native graphics drivers. Typically, there is one graphics adapter device exposed by the virtual machine, and calls to that device then get translated to whatever the host is using (typically D3D or OpenGL.)

Previously, the VirtualBox 3D "support" was more of a "hack" that provided a DLL that would funnel high-level commands (GL or D3D) to the host, and it would execute those commands. However, that never worked for me (I use apps like 3ds Max, etc.)

FWIW, VMWare Workstation 8 with the vm virtual graphics device actually works for me; I can run 3D graphics inside virtualized Ubuntu or Arch, with the vmware graphics drivers installed on the virtual machine. This is with a Mobile FireGL host running Windows 7. I hear that, in 9, they will support Linux hosts and Windows guests with 3D graphics; I haven't been brave enough to try
