Re: Thinking of buying C4. One question, Replacing network?

by Eric Lengyel » 12 Sep 2012, 18:46

While it's not quite as easy as replacing the physics system, the networking system is well isolated and can be replaced fairly easily. By doing this, however, you would be losing a significant amount of higher-level functionality that is built into the controller system in the engine because it is designed to work with the built-in networking.

The background loading that will be included in the next release (version 2.10) is not a streaming system. What is does is allow user interaction with interface system to continue while a level is being loaded (which doesn't take very long anyway). That is, you would be able to display graphics, animation, and interactive windows to the user while a level loads. Right now, you can't really do that.

A full streaming system that will allow new parts of a world to be loaded while another part of the world are being played is planned for 2013, but I'm afraid I can't be more specific about that time frame.

Re: Thinking of buying C4. One question, Replacing network?

by jwatte » 13 Sep 2012, 14:29

If you want to implement your own network system, you can totally do that.
A single-player game will have controllers on nodes to actually "do things" to the scene graph.
It's totally possible to make those controllers "look aside" to a separate networking system, to figure out what they would "do."
Doing it this way, it's totally possible to use C4 as a presentation scene graph and GUI, and put all the game logic "side by side" with the C4 code.
You probably do want to integrate some parts of the scene graph, though -- being able to extract collision and trigger and object placement information from the level files is likely something you'll want, and that comes from the scene graph. Thus, you'd probably want to run the scene graph (albeit headless) even on the server.

Also, be careful: C4 is *not* "open source" -- it's a commercial engine, where source code access is included in the license. Very different, especially as Eric is understandably very protective of his intellectual property and livelihood.
