The tutorials are worthwhile. I don't recall if the demo ships with Example Worlds, but I used those as my primary tutor.

In this particular example, I used a global texture but it's only a little more complicated to export a traditional Splat Map that can be used to blend in different textures in C4's shader editor based on whatever criteria you decide for the color channels. Red - rocks, G grass, B rock grass blend, for example. The shader can be as intricate as you want, using as much data from world machine as you need. The two work well together.

Re: How to make terrain?

by Jesse Meyer » 23 Apr 2014, 20:03

I like how their UI is formatted, with the large visual display next to the generation tools (Looks like they've separated chunks of it according the golden ratio). That probably makes it somewhat simpler to learn, especially with their historical modifier stack. But since their modifiers seem to only pour in one dimension (top to bottom), that probably imposes limits to the extent of what their outputs can be. I can generate all sorts of unique data from World Machine, in parallel, because each node can branch into its own computational limb that can interact with the outputs of other limbs, where it makes sense (it prevents loops). That's really important to me, and I don't see that kind of functionality demonstrated in any of their videos.
