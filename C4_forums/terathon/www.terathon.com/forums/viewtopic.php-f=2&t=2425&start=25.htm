Generic animated entity marker.

by David Vasquez » 15 May 2007, 12:42

I think we could use a generic animated entity marker to make it easier to try out animated models.

The idea is that you would place a generic animated entity marker in the world editor, and choose Get Node Info for that marker. At a minimum, the settings would allow you to choose the base model and an animation that would play for that entity, along with options for looping, reverse playback, back and forth playback, and start/end frames, as seen in the model viewer.

A more advanced version of this feature would allow you to use the visual scripting editor to specify different animations to be played one after another - although for now you would be limited to using the Delay visual scripting node to specify the amount of time that would elapse between each animation.
