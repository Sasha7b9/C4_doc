Re: Move WorldViewport Widgets?

by Eric Lengyel » 01 Nov 2013, 17:47

You need to call the Move() function for the world being rendered in the viewport. The move/render loop would typically look like this:

Code: Select all
   world->Move();
   world->Update();
   world->BeginRendering();
   world->Render();
   world->EndRendering();
