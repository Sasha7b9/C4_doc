Re: [SOLVED] Animation Import

by Eric Lengyel » 22 Mar 2014, 19:43

So it turns out that the bones were actually animating correctly in the unmodified file, but the skin controller wasn't being notified because it wasn't on a top-level node. This was kind of a hold-over from earlier versions of the engine, but it has been changed for version 4.0 so that the skinned geometry does not need to be at the top level.
