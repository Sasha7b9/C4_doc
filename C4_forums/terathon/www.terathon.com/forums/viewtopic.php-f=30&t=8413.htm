Generic Particle System v0.6c for 1.5.9

by DeRatizator » 05 Dec 2009, 13:51

Generic Particle System (GPS) is free C4 plug-in created by C4 users for easy particle effect creation. Effects created using GPS can be used for smoke, explosions, snow, sparks and many more. All of them can be created within C4 Editor itself.

http://www.terathon.com/wiki/index.php/ ... cle_System

Attached windows binary version contains all functionality except for animated particle textures.
Version with animated texture support stays in licensed section because it requires some modifications to the Engine ( hence it isn't compatible with 1.5.9 Demo Game anyway).
