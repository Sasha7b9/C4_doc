by Optime » 23 May 2006, 14:11

Ludi wrote:And for the glow effect: How do you apply it? I didn't found the option in the World Editor? And how can I apply it to my own item? Again, I'm really confused


This is from the release notes:

Glow is automatically applied whenever a glow-enabled object is rendered in the scene. Currently, a skybox can be made to glow by checking the "Enable skybox glow" box in the World Settings dialog. The textures used in a glowing skybox should contain alpha channels representing the glow intensity. Glow for ordinary geometries is determined by the emission attribute in their materials. The emission alpha determines the glow intensity, and this is taken from the emission color or emission texture (or the product of the two if they are both present). For a geometry to glow, the "Enable emission glow" box must be checked in its Get Info dialog.

by Eric Lengyel » 23 May 2006, 17:01

You could clone the material. There's something else that might work. You can put the emission attribute in a secondary attribute list and attach it to the geometry when it's selected.

Code: Select all
List<Attribute>       myAttributeList;
EmissionAttribute    myEmissionAttribute(color);

myAttributeList.Append(&myEmissionAttribute);

...

// When selected

myGeometry->SetAttributeList(1, &myAttributeList);
myGeometry->InvalidateShaderData();

// When unselected

myGeometry->SetAttributeList(1, nullptr);
myGeometry->InvalidateShaderData();


This changes a little in build 122. Instead of calling SetAttributeList with two parameters, you'll just call the following with only one parameter.

Code: Select all
myGeometry->SetMaterialAttributeList(&myAttributeList);


These apply attributes to the geometry in addition to the its material.
