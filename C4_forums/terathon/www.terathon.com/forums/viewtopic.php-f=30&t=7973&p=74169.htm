Someone just asked via PM, how I manage to accomplish the aiming and rotation of characters body to be aligned in the direction of the crosshairs. It's not a big secret, so if anyone wants to know how I do it:

Actually, I'm converting the character position to screen space coordinates (http://www.terathon.com/wiki/index.php/ ... he_Display) and do all the required math in screen space coordinates. E.g. if the player looks to left or right is a simple if statement.

if(mouse.x < characterscreenposition.x)
look left
else
look right

Well, with the help of google, I found the solution to the problem:

Code: Select all
netsh firewall set allowedprogram program="f:\Ludicrous\lc3d.exe" name="Ludicrous" mode=ENABLE


This adds a firewall rule and allows the game to run without showing the prompt. I'll add it to the installer.
