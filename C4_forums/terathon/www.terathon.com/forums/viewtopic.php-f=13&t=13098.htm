This is why I mentioned the runtime-less version of Rust. At the moment Rust only works through a Rust entry point, which sets up a runtime for things like garbage collection. This unfortunately means you can't use Rust in a C4 project because C4 is launched from a C++ entry point, and hence the Rust runtime isn't running. You can however call out to C/C++ from Rust itself. However for most projects this requires quite a lot of rework and drastically limits Rust's usefulness, particularly with respect to writing plug-ins for other C/C++ applications.

They are however working on making Rust code callable from C/C++. But they were talking about only supporting a sub-set of the features, for instance no garbage collection. Whilst I like the idea of avoiding GC in general, some of Rust's threading mechanisms rely on GC, so I'm not entirely sure how useful Rust would be without these capabilities.

Eric Lengyel wrote:It's a language for babies.


Are you sure you're not confusing Rust with Ruby?

Seriously though, it is by no means a language for babies. The memory model is one of the most complex I've seen, with various types of boxes and explicitly named lifetimes. The language (or rather compiler) has support for macros that allow you to essentially extend the language itself and perform compile time operations with static safety checking. Which would surely make things like C4's StaticHash a lot less cumbersome, and a lot more flexible.

It's pretty much a system level language through-and-through, extremely powerful, but also quite complex. Of course, the language is still undergoing a lot of changes at the moment, so it will be interesting to see how it turns out.

In any dimension, the cross product between two vectors produces a bivector representing the orientation of the plane containing those two vectors. In two dimensions, a bivector has one component. In three dimensions, a bivector has three components (which causes a lot of confusion because they look just like vectors, but they are not). In four dimensions, a bivector has six components.
