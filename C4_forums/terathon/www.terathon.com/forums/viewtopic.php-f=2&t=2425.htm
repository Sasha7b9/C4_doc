Build 135 Now Available

by Eric Lengyel » 13 May 2007, 08:09

Build 135 is now available for download:

https://www.terathon.com/c4engine/registered/index.php

Release notes can be found here:

http://www.terathon.com/c4engine/notes.php

Here are a few more notes about this build:

*) The proton cannon is currently set to do a lot of damage, and it's basically an instant-kill gun. It's not going to stay that way.

*) I was originally playing with the idea of moving the crosshairs on the screen to match the location where the gun would shoot, but it looked stupid. Instead, the aim of the gun is going to change so that shots hit whatever the stationary crosshairs are pointing at.

*) There is a SimpleChar project in the works right now that should be available with the next build (expected very quickly). I had said before that I wasn't going to do this in favor of just commenting the demo game more, but I changed my mind again.

*) The glow effect is currently disabled until a new technique is implemented.

*) Do not attempt to run C4 under Vista with an ATI GPU. The drivers are crap.
