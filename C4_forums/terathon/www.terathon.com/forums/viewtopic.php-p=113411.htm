Hello Everyone! Macktek and Fairuz would like to announce a new C4 Book:

True, a vanilla implementation would only work with a square grid and uniform cost, but if the algorithm is really that much cheaper than a vanilla A* grid search, you could potentially do multiple searches. One with a search with only true obstacles and other progressive searches where different cost parts of the grid are treated as obstacles. You could then compare paths and decide which one to use.

I'm certainly interested in investigating this jump-point search and doing a direct comparison to alternative path generation techniques (namely alternative A* searches with path graphs etc.) to see which is best for my game project.
