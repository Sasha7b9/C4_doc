Official Roadmap Updated Again

by Eric Lengyel » 28 Sep 2008, 23:42

Another big feature has been added to version 1.5: the visual shader graph editor. With all of the shader additions going in for the terrain, it made sense to implement them in the context of the new shader assembly back-end that would have to be written to support custom shaders.
