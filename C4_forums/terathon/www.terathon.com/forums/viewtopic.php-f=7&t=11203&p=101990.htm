by Arthain-Baka » 30 Sep 2011, 00:49

Warning: I'm pretty much guessing in this post but as I saw no replies I thought I might see if I could get lucky and stumble onto something. Don't treat what I say as any form of a definitive answer.

grahamde wrote:I compiled the project (version 4.2.6) in Visual C++ 2010 and ran it in debug mode.


Do you mean version 2.6? We are only just up to version 2.7 Beta at the moment, or have you made some extensive modifications to your version, in which case was any of the graphics or networking changed?
I don't have a massive amount of experience with the networking of C4 though I believe I understand the basics, I'm also at work and not on my PC at the moment so I can't test if I get that same issue but I'll give some suggestions anyway, maybe I'll get lucky :p

One thing to test would be to trade executables (leave your directory structures and resources in their place) and get him to run the server and you can join to him, then see if you can see the monsters or not. If so it's probably some kind of mistake with the resource files.
Typically if the resource is missing you'd get a visible texture (I think it's purple with green X's on it) to let you know the texture selected isn't there but maybe something is going wrong. At the very least it doesn't hurt to try...

Another thing is if they were both built from the same system and code, I don't think the C4 Networking checks what version the clients are running (I could be completely wrong here) so maybe there is two different versions being floated around in your tests?

If you haven't made any changes to the engine try copying your resource tree over to the other machine relative to his and your executable file (the file tree structure is crucial) and see if you still get this bug appearing.

If that fails I'm not sure (though honestly I'm guessing at the moment anyway), I will be able to see if I get the same issues when I get home, I believe I still have the original 2.6 floating around in my Git repository somewhere).
One thing to note is it doesn't sound like the issue is with the monster packets, they don't send the graphics to the client they just send everything needed to update the world which it turn is what is rendered, and as you said he can run into the monsters and shoot them so you are getting some packets from the server. Though it almost seems like you are just getting sent the results of the physics step (at least those pertaining to the player movement) but not getting anything else.
You could try starting up the Network display on each system and see if there are any irregularities (I can't remember the console command but if you look in the C4Commands.cpp it should be listed in there, otherwise there will be a reference to it in the C4Engine.h and C4Engine.cpp).
I would also suggest doing a clean build of the project and use the executables generated from a single machine as opposed to two generated by different machines.

Additionally, what systems are you both running. The more details the better, I think the most useful here are:
  • Operating System (Windows XP, Windows 7, MacOSX Snowlepard, etc) and if it is 32-bit or 64-bit
  • Graphics Card (And driver version if you know it)
