I'm not sure what the FeelingViewer is doing, but it can't possibly be following the spec to apply the animations. I'm talking to them about these problems, and hopefully they'll be resolved this week.

by Frank Skilton » 15 Nov 2006, 19:53

I submitted two bugs to Feeling Software regarding system / display units and it looks like they have been fixed.

Refer this thread for more information:

Max System Scale

The response from Feeling Software:

Fixed the asset units' export. Max applies units display preferences on top of
the chosen system units. Therefore we now export the <unit> asset's element
based on the system units scale factor (default = 1.0f) and type only (default
= centimeter or inch). I also added some commented code that fetches the user
unit display preferences.

We were previously using incorrect information from the display units. System
units should always work fine since they only serve as a basis for generic
units.


Hopefully the new build of the Max Collada exporter (1.07) and the changes you have made to the C4 Collada importer play nicely with each other and alleviate some of the problems we were having importing geometry into C4 from Max.
