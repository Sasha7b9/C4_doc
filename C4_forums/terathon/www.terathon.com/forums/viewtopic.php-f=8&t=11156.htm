Re: ImageWidget progress bar

by Eric Lengyel » 18 Sep 2011, 22:46

The scale and offset are applied to the texture coordinates, which range from 0 to 1 across the full image regardless of the actual pixel dimensions (unless it's a RECT texture, in which case the range is from 0 to the width and height). The default scale is (1,1), and the default offset is (0,0). New texture coordinates are calculated by multiplying the ordinary texture coordinates by the scale and then adding the offset.

All you need to do is set the x scale to the percentage complete with SetImageScale() and set the width of the widget to the full width multiplied by the percentage complete with SetWidgetSize(). Leave the y scale at 1.0, and keep the widget's original height.

This works nicely thanks.

Code: Select all
void PlayerStateWidget::UpdateVelocityBar(PilotController* _pilot)
{
   const float currentVelocity = fabs(Magnitude(_pilot->GetLinearVelocity()));
   const float maxVelocity = _pilot->GetMaxVelocity();
   
   velocityBarFull->SetWidgetSize(Vector2D((kVelocityBarFullLength * Clamp(currentVelocity / maxVelocity, 0.0f, 1.0f)),
      velocityBarFull->GetWidgetSize().y));

   velocityBarFull->SetImageScale(Vector2D(Clamp(currentVelocity / maxVelocity, 0.0f, 1.0f), 1.0f));
}
