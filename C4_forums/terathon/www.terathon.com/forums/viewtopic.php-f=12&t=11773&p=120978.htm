Re: A few Questions before I order C4 Engine

by Davaris » 05 Nov 2013, 04:51

BORODA wrote: (amazon can't ship anything to Ukraine).


In the case of US companies not wanting international customers, you can use a buying and shipping service like PriceUSA.

If it was me I would start out with 'The Beginner’s Guide to the C4 Engine, Second Edition' because that gives you a good grounding and then move on to the next book, as it has more advanced code in it. The code in the Beginners Guide was released late last year, so some of it is out of date. Eric provides the engine source from that time, so I suggest you use that when you work through the book. When you have a good understanding of the engine, then move up to version 3.5.
