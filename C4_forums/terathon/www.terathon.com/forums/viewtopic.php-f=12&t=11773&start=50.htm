Re: A few Questions before I order C4 Engine

by Eric Lengyel » 24 Jan 2013, 09:35

Daniel_S wrote:1) How many bones engine supports for one skeleton?


There is no limit.

Daniel_S wrote:2) How many bones engine supports for influence at one vertex of skinned mesh?


There is no limit.

Daniel_S wrote:3) Is there any troubles with add and delete bones or objectd to other bones by code realtime (during game)?


There's nothing stopping you from adding bones from a skeleton during gameplay, but they wouldn't do anything because the skinning data associated with the actual geometry would not reference those bones. Removing bones during gameplay would probably crash because vertices referencing those bones would suddenly be missing transform data that they need.

Daniel_S wrote:4) Wheather Frame, Blend and Merge animators can be used at one mesh and one frame, or they must be used for different objects?


Animators can be arranged in a hierarchy, and different types of animators can be combined however you want for any particular mesh.

Daniel_S wrote:5) Is there one structure type for animation or it can be in global, local, parent coordinate system (in world coords, relative bone origin, relative parent origin?)


Animations are played relative to the model node at the root of a skeleton, in the model's local coordinate system.

Daniel_S wrote:6) Is there any troubles with applying one skeleton to different meshes?


It is possible to use the same skeletal structure with different meshes.

Daniel_S wrote:6) What versions of OpenGL or shaders supported by engine?


C4 requires OpenGL 2.1 or higher, and it uses features from OpenGL 3.x and 4.x if they are available.

Daniel_S wrote:7) Is there differed lighting or its analogy?


The engine does not use deferred lighting for its main rendering functions, but it does make use of some deferred-like techniques for some special effects.

Daniel_S wrote:8 ) What additional libralies need, for instance, boost?


C4 does not require any external libraries, not even the standard C library.
