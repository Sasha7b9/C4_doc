Re: Simple 2D Game with C4

by gautam » 07 Oct 2009, 15:06

bamboo_7 wrote:I am looking at also doing a 2D-ish game with C4,figured it had to be possible. Thanks for sharing, the screens look really really good! I would love to hear about the challenges you had to face while working on it. Anything special to be aware of with a 2D game? Anything you found particularly helpful?

Thanks!


Well frankly the biggest challenge I think for us is yet to come which is the sheer file size of the game. It's increasing madly as we keep adding stuffs - and for a 2D game, something above 40-50MB may not hold water. Considering that we are just doing this for fun as of now we aren't worried about file size but I definitely would not want to host a 300-400 MB 2D game on any server.

Collision detection is a bit of an issue - we want to get as close as we can to high accuracy of player versus level. At the moment player world collision is so so - and the player and various effects collision still has a lot to be desired.
