by Eric Lengyel » 07 May 2006, 23:36

dxben wrote:Speaking of which, Eric, if you're still reading this thread, are there any major reasons why a port to 64bit for C4 would be anything but straightforward? I haven't walked all the code much yet, I am just wondering out loud.


A 64-bit build ought to be very straightforward. Some precautions have been taken in the engine to ensure a smooth transition. There's a line in C4Base.h that mentions 64-bit, and it redefines "long" to be 32 bits for consistency in GCC. The "natural" type defined by the engine is either 32-bit or 64-bit depending on what you're compiling for, and it should be used for things that are normally in registers, like for-loop indexes.

The only problem I foresee is in the movie code. Apple defined a callback function that takes a 32-bit int instead of a pointer as the user-data object. We currently pass a pointer through that, but it will have to change to some kind of reference number.
