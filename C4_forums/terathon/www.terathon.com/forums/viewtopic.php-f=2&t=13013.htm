Re: Version 3.0 Alpha Now Available

by Eric Lengyel » 02 Jul 2013, 16:45

Jesse Meyer wrote:what are your opinions on LLVM, particularly with Clang?


I only have experience with LLVM 3.2 on the PS4. I'm not impressed with the quality of the machine code it generates. The much-hyped sparkling new SRAO optimizer in version 3.2 turned out to be a buggy piece of junk that caused problems like what you saw with the water. (It has since been fixed for the PS4, but I don't know whether that applies universally.) Clang appears to function well, and it's fast. I have not had any issues with C++ language compliance.
