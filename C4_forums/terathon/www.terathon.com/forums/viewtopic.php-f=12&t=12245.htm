Re: using C4 for a Text adventure game?

by MACK » 30 Sep 2012, 01:41

This is a decent concept. There's a whole cadre of "text" based players still wanting that kind of game. Having said that, I would not go back to that style of game unless it blended the text based system heavily with 3D elements. If they can solve the main problems with text based games of the past... requiring very specific text statements to do certain things:
Open Chest... You cannot "open chest".
Unlock Chest... you do not have "chest"
Get Chest... Chest is in your possession
Open Chest... You cannot "open chest".
OMG
Unlock Chest... You do not have a key.


The whole process of "type", then "get a response" is slow, and it gets to be annoying. And a repeat of that is not something I would want in game play, so... the developer would want to deal with those issues.
Still, IF it could be done well, it might be intriguing.

But there's nothing that says C4 can't do it. C4 has text, and input as already mentioned. The expert system to handle the text based questions and answers etc... would need to be implemented.
