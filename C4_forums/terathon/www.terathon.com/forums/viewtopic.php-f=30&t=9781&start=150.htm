Well, 0.5.3 is just about ready. I'm doing some final checks now, then packaging it up. It'll go out for testing first then be released later today. If you want to get your hands on future updates ahead of schedule and help out by reporting bugs, let me know by PM or email. Here's the list of what's new:

- Added a new level (Crystal Sands - Act 1).
- Added rough version of a stage selection window.
- Added rough feature for levels to have an infinite water plane with reflections.
- Added an Exit button to the Profile window.
- Added placeholders for Tutorial and Options buttons on Profile window.
- Added a shockwave on entering/exiting from bullet time.
- Added a glow to the Wingball tread while in bullet time.
- Added the [temporary] Wingball logo to the loading window.
- Added a shortcut to input.cfg in the Programs/Wingball folder in the Start Menu.
- Added background music to the profile/stage select/loading windows ("Hidden in The Shadows").
- Removed "Hidden in The Shadows" and "Mona Lisa" audio tracks from both stage's playlists.
- Removed default key assignment safeguard (only worked in Windows 7 / unreliable feature).
- Fixed Website buttons not working in Windows XP (requires confirmation).
- Fixed an issue with an occasional double-jump, and improved jump/glide responsiveness.
- Fixed bullet time being usable during level intro / countdown.
- Changed foliage on Noob Hills stage (several new types, and no more palm trees).
- Changed max physics steps count for more consistent gameplay at lower frame rates.
- Changed terrain culling from block- to patch-level. The finished game will have sliders for distance adjustment.
- Changed GL_EXT_direct_state_access extension to be disabled by default. Toggle by "DSA" variable.
- Changed default multisample value to 1 for compatability. Adjust by "displaySamples" variable.

This will be my last update this month.. I would have liked to get a few more things in (like reflective crystals sticking out of the sand and some fish/dolphins/whatever jumping up from the water), but I'm out of time and I won't be able to do anything else for the next week or two, at least. Re: Wingball 0.5.3 Released

by Adam Golden » 17 Oct 2010, 12:35

DeRatizator wrote:New racetrack is much more interesting.
Objects simply popping up are quite noticeable though. Is there a way to increase drawing distance ?

Yep, the performance options window will have separate sliders for the culling distance of terrain, objects (rails/coins/etc.), and foliage. Until then it's optimized to work well with low end systems. Kamikazi's laptop for example has double the frame rate as it had with 0.5.2 (going up from 15-20 fps to 35-40), which makes it playable for him out of the box. For me it's a difference of now being able to play "overgrowth" mode (which will eventually just be the maximum allowed value on a foliage density slider) on both levels at 35+.

However, you're right about it being noticable. I have code in place already to fade terrain and objects in and out instead of pop them, but the problem is that when they're rendering in the effect pass, it seems like they're losing the lighting pass or some other changes are happening to the shader. I haven't yet been able to match something up from having full alpha in the effect pass with something not being in the effect pass. As soon as it flips to effect pass, it gets much darker. Once I can get that transition working properly it will go from popping to fading, which is much less noticeable.

Without solving that, it's just as noticeable when popping into or out of the effect pass, so the performance impact that fading things makes isn't worth it until it looks like it should - meaning, as you get within distance "A" of something (terrain patch, tree, whatever), it should be added to the scene, rendering in the effect pass with no alpha output, then gradually fade in between distance "A" and ""B" to full alpha, then when it's closer than distance "B" you disable the effect pass for it, and it should still look the same as with the effect pass enabled at full alpha. But it doesn't.

by Adam Golden » 19 Oct 2010, 10:30

@wtblife

Kamikazi had the same problem when he tried this level and told me pretty much the same thing, and then he realized (I guess he missed this part in the Tips) that unless you're on the "white line" you're moving way too slow. Honestly, I'm finishing both stages with 15+ seconds left on the timer and able to get most coins, have I really been playing so much that it's that much easier for me?

1. You should rarely be off the white line - there's almost no way to shortcut. If you skip a corner by driving off the path ("white line"), you lose too much speed to make it worthwhile. The main point is accuracy for this mode.

2. If a corner isn't too sharp, try to take it by just turning with the mouse. Your speed will be higher than if you strafe through it. If you're moving left and right you're slowing down because momentum is being transferred to sideways movement.

3. Rails aren't really optional for getting a lot of time. To make it to the finish you'll have to ride most of them from their start to their finish.

4. You should almost never remove your finger from W (accelerate). Slowing down at all will cost you a lot of time speeding up again.

5. If you don't want to run out of bullet time (because there's several places you really will need it, particularly at the very end where there's a long row of coins along a curving path), then just use it until you've corrected your heading, and let go again. Personally I use it when I'm about to make a big mistake or there's a really hard turn (maybe for 1 second or 2 at the most before letting go).

If those tips don't help I'll make a video of a run with 15+ seconds left at the end, and you can compare your approach with that and hopefully be able to complete the stage. As you said there should be levels between these two, and there will be (Noob Hills 2 and 3), but it's only going to get harder in levels following Crystal Sands 1. In levels near the end of the game, you will have to be up to a point where you can ride every rail and never leave the path just to complete them.

by Adam Golden » 19 Oct 2010, 17:34

wtblife wrote:After reading through the tips on the site, it makes a bit more sense knowing the priorities. Do you plan to put these in game later?

Yep, each time a level is loading it will show a random tip. There will also be a tutorial mode that basically plays the level itself, slowing down and stopping time (like pause does) and displaying a tip with an image (i.e. cropped screenshot with arrows/highlights indicating whatever it's talking about), then continuing a bit, then stopping again to explain the next important thing etc.

One thing that irks me about a lot of games is how easy they are to master, and how tight the high score spread is (with the leaders only a few points away from each other, or even tied). In the very beginning when deciding on gameplay I wanted it to be (relatively) easy to pick up and play casually, but rewarding to get better at (hence the difficulty and leaderboards). Don't take it too hard that you can't ace a new level overnight... when you do get through it (if you don't give up haha), you'll be that much more proud of the accomplishment. I've played these levels hundreds of times (especially Noob Hills) and I still get excited when I can get every coin and/or beat my old score.
