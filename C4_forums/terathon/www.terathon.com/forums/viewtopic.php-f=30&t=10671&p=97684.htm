Project: Calamity

by Arthain-Baka » 12 Apr 2011, 02:58

Project Calamity has been something I've been meaning to do for a while but recently I've had enough time to work on it a bit and just hit an issue and needed some time to step back from the problem and clear my head so I thought I'd just make a little post to show some people just how easy it is to modify the C4 Engine (This stage was completed in less than 24 hours of work), let's start off with some eye candy!

Calamity - Ocean.png

Calamity - Ocean Wireframe.png


I won't try to pass this off as an original technique because we all know better than that, but what this is an implementation of nVidia's DirectX SDK11 OceanCS application in C4, the base OpenGL rendering system has been completely removed (Which is why there's no GUI as it isn't complete yet).
The nVidia SDK description describes the techinique better than I would so:
The sample uses compute shader to implement Jerry Tessendorf's statistic model of ocean surface, which requires to perform a large set of FFT at the runtime. In addition, perlin noise is used for eliminating the tiling artifact at distance.


The above scene runs at a little over 300 FPS (i7 950 @ 3.06Ghz, nVidia GTX570 @ Stock, 8Gb 1666Mhz DDR3 Ram) which is a little less than the nVidia Sample but the difference is so trivial and solely because of the additional overhead of C4 (Not saying this as a bad thing, it is such a small drop with so much more functionality).
Sadly this is currently a fixed scene without the C4's World, Nodes, Objects, etc integrated.
The next step is streamlining this into using the C4 Resource pipeline but there's a lot of small tasks that need to be done to get this working correctly and numerous changes to the engine (not to mention hours of trial and error as this is my first work using DirectX 11).
