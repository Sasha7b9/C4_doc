by cbken » 18 Dec 2014, 17:06

I don't know exactly what kind of behavior you want from this but it is difficult for several reasons. What I would do with a character that needs to pick up weapons, drop them etc, is to turn off all rigid body physics for the object when it's "picked up". That way it doesn't interfere with the character in any way. Then after it's dropped the physics is turned on again. This of course means that the object has no collision detection while it's being carried but that's pretty typical in FPS games. But it's possible you are aiming for something different here that would require a more realistic behavior.

Okay I got something working using the code you worked out with Eric earlier:

Code: Select all
   C4::Model *model = C4::Model::Get(C4::kModelEricFlag);

      float modelAltitude;
      float modelAzimuth;

      ZedC4::GetControllerAltitude(owner, &modelAltitude);
      ZedC4::GetControllerAzimuth(owner, &modelAzimuth);

      C4::Point3D      position;
      C4::Vector2D u = C4::CosSin(modelAltitude);
      //C4::Vector2D t = C4::CosSin(modelAzimuth);
      C4::Vector2D t = {1, 0};

      C4::Vector3D view(t.x, t.y, u.y);
      C4::Vector3D right(t.y, -t.x, 0.0F);
      C4::Vector3D down = view % right;
      float d = 0.375F + modelAltitude * 0.1F;
      position = right * 2.25F + view * d;
      position.z += 1.15F;

      C4::Joint *joint = new C4::SphericalJoint();
      joint->SetNodeTransform(view, -right, -down, position);
      owner->AppendNewSubnode(joint);

      C4::Transform4D transform = owner->GetWorldTransform();
      C4::Point3D pos(0, 0, 0);
      //pos.x += 0.0001F;
      transform.SetTranslation(pos);
      model->SetNodeTransform(transform);
      joint->AppendNewSubnode(model);


The joint you will have to set as a class member, I have not done that here.

This is what I see when I run the code: The joint is placed to the right of the owner and the model is attached to it. When the creature runs around the map, the flag always stays on owner's right, even if he rotates quickly. The flag has a shape node attached and it still works correctly. However the flag can be dragged through walls. I think its because the forces holding it to the joint are so strong, it can be pulled through solid objects. To fix that you must set the break strength, but I can't see how to do that. I'm pretty sure it was a feature in one of the updates.
