Fat Princess Adventures

by Cameron » 10 Dec 2014, 17:36

Hi All,

Fun Bits is proud to announce Fat Princess Adventures for the Playstation 4. The Fun Bits team has been hard at work on a bigger, and badder than ever, fast-paced hack ‘n’ slash action game set in the Fat Princess world. To help build the game the team used the C4 Engine as a base for our technology. We would like to thank Eric and the community for their continued support. For more information please visit our website:

http://www.funbits.com/

and the Playstation blog:
