Mysteriously disappearing properties

by cboyce » 18 Dec 2009, 13:52

I have markers with custom properties attached as part of a model. I have an instance of the model placed in the world, and I can see the markers when I expand the model graph in the world editor. I have code that iterates over the nodes in the model and looks for specific marker properties. It finds the markers, but not the properties. However, if I Load/Save the model (without changing anything, just making a new world, loading the model and re-saving it), now the properties appear when I play the world containing the model. Now that in itself is strange, because I loaded the exact model resource, didn't change a thing, and just re-saved it. I verified that indeed the markers do have the property set. What's even stranger is if I close and restart, I run into the same problem. The properties don't appear unless until I load/save the model resource. I'd think it's some strange serialization problem, but when I load the actual source model via Load Resource, the properties are still there. Any idea what could be going on?

bool WheelProperty::ValidNode(const Node *node)
{
   if(node->GetNodeType() == kNodeMarker){
      const Marker *marker = static_cast<const Marker *>(node);
      if(marker->GetMarkerType() == kMarkerLocator){
         const LocatorMarker *marker = static_cast<const LocatorMarker *>(node);
         return (marker->GetLocatorType() == kLocatorWheel);

   }
    return false;
}

Code: Select all

    // ... etc.
