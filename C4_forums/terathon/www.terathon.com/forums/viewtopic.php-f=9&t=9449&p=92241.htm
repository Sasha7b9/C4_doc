Re: Texpal import

by Eric Lengyel » 14 Jul 2010, 14:11

mwituni wrote:Are there any complications with having say 12?


On DirectX 10 hardware and later, the number of palette entries can really be anything, and you won't use any extra memory or run with any lower performance. If a palette having size other than 9, 18, or 36 is loaded on DX9 hardware, then the size of the palette has to be rounded up to the next number in that list, wasting memory in the process.
