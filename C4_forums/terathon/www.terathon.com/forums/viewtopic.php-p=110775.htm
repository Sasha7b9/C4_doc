Re: New postmortem posted

by smittix » 06 Sep 2012, 23:52

Yeah, no problem. I was testing on two Windows machines.

Windows XP, ATI Mobility Radeon HD 3650, 4GB RAM
Windows 7 64bit, Nvidia GeForce GTX 560, 8GB RAM, AMD Phenom II X4 965 3.4GHz

I had to turn the settings down slightly on the first machine, but it ran fine. On the second machine I can play with all settings turned all the way up.

I would have to ask the artist (ska in these forums) what tools he used, but for programming I just used Visual Studio C++ 8.0. And yes the GPS particle editor was extremely helpful in the development of the game.

The most valuable resource I found about lag compensation was a by Valve: https://developer.valvesoftware.com/wik ... Networking - I worked on it for a while, but as described in the postmortem, I ultimately decided that it was way out of scope of the game.
