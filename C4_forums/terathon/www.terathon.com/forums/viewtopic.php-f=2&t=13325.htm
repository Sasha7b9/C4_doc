Version 3.5 Alpha Now Available

by Eric Lengyel » 18 Nov 2013, 17:31

The alpha build of version 3.5 has been released to all users of the Professional Edition. Updated release notes can be found here:

http://www.terathon.com/wiki/index.php/ ... ersion_3.5

This release includes the source code for the 3D Studio Max exporter plugin for the OpenGEX format. The geometry pipeline is fully functional, but the animation parts are currently being reworked a little and so are not functional in this release. The beta release will include fully functional plugins for Max and probably Maya.

Re: Version 3.5 Alpha Now Available

by Eric Lengyel » 18 Nov 2013, 23:09

Jesse Meyer wrote:
cbken wrote: I love that the character is no longer sliding. Huge improvement!


What was decided to resolve this issue?


This was ultimately solved by introducing a velocity multiplier that the physics system applies to the character. When the character is in contact with the ground and no external force is being applied (e.g., when the character is trying to run), the multiplier goes from 1.0 to 0.0 over a short period of time (400 ms), after which the character cannot possibly move. The character instantly becomes unstuck if the ground contact disappears or a force is applied.
