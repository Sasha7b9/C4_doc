Re: Terrain texture palette description

by Eric Lengyel » 12 Jun 2010, 13:19

The texture palette that shows up in the Terrain page depends on the current material, as set in the Material page. After a terrain palette texture has been created, you need to create a terrain shader as (briefly) described at the bottom of the Editing Terrain wiki article. It might be easiest to simply copy the material in the terrain tutorial level and just change the names of the texture maps.

Re: Terrain texture palette description

by Eric Lengyel » 04 Jun 2014, 14:49

It sounds like you might be trying to use the alpha channel of the normal map to store occlusion data. Is that right? Because of the way that compressed normal maps are stored, you can't actually use the alpha channel for something else. It's occupied by one of the components of the normal vector. So you would ordinarily have separate diffuse, specular, and normal texture palettes. Texel-scale ambient occlusion would usually be stored in the alpha channel of the diffuse texture, and then you have a free alpha channel in the specular texture if you need it.

As for different specular powers for rock and ice, it might be easiest to store the intended power for each material in the alpha channels of the specular textures. You could scale them up and apply them in the shader to get the right effect.
