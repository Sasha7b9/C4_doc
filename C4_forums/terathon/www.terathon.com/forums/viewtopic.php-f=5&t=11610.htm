Re: Fog?

by Eric Lengyel » 09 Mar 2012, 11:44

You can achieve this by attaching a fog space to the camera and setting its z position to the distance at which you want the fog to kick in. All fog spaces can cull objects that are far enough away to be completely obscured. The easiest way to see that is to put the fog plane above the whole scene and increase the density enough that things get completely fogged out. The linear fog setting becomes more dense a lot faster with distance than the constant fog setting does.

Re: Fog?

by Eric Lengyel » 20 Mar 2012, 06:39

It works just fine the way I originally described. After looking at the above code again, I noticed that the transform is wrong, and you're looking at the fog plane from the underside. Use the following code instead, which rotates the fog space so that you're looking at it from outside like you want:

Code: Select all
fogSpace->SetNodeTransform(K::x_unit, K::minus_y_unit, K::minus_z_unit, Point3D(0.0F, 0.0F, 100.0F));
camera->AddNewSubnode(fogSpace);


You'll need to connect all the zones in the world to this fog space. (And no zone can have a fog space already in it.) Here's some code that will do it:

Code: Select all
void ConnectZones(Zone *zone, FogSpace *fogSpace)
{
   zone->SetFogSpaceConnector(fogSpace);
   
   Zone *subzone = zone->GetFirstSubzone();
   while (subzone)
   {
      ConnectZones(subzone, fogSpace);
      subzone = subzone->Next();
   }
}


(In version 2.8, the SetFogSpaceConnector function is called SetConnectedFogSpace.)

Just call this function for the world's root zone:

Code: Select all
ConnectZones(world->GetRootNode(), fogSpace);

Re: Fog?

by Eric Lengyel » 20 Mar 2012, 20:09

cbken wrote:The fog we are talking about here is for outdoor scenes and this brings up the problem of water. I have water in my scene too and a fog space there to make that look right. So I can't easily add another fog space.


As long as two fog spaces don't get rendered in the same perspective (direct, reflection, refraction), then you are allowed to have more than one fog space visible at once. For example, an underwater fog space can be rendered only in the refraction perspective, while a fog space attached to the camera is rendered only in the direct perspective. You'll just need to set the perspective exclusion flags appropriately.

cbken wrote:Then there's the problem of hooking the fog space up to the appropriate zones as the character moves around in the world also.


You can use the code I gave above to connect all zones to your fog space. This only has to be done once.
