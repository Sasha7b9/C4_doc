by Baalfeus » 25 Apr 2013, 21:19

Necroing this, cause i don't want to make a new thread:)

A year has passed since my last post here, and I think ist time for an update...

I guess it won't make sense to write a list of what has been done since then, those of you that are interested, can check out the news-section of the Forum at http://www.baalfeus.com.

I'm finally getting somewhat close to release, might still take a few more months as I usually always find out that i need some more new graphics and features, as I go on:) Though i really should stop doing this... getting close to 1GB of data which is quite a lot for such a simple TowerDefense-Game:)

Status is:
- coding is quite done, maybe some bugfixing and tweakings here and there, and probably adding some additional minor Features, but should not take too much time anymore.
- 5 Levels completed so far, aiming for something like 15-20 total, but should go faster with every Level, as there is already a pool of graphics and models that i can use to populate them
- 6 Monsters done, aiming for something around 15, so quite some work still in this section
- 4 different Towers done, 2 of which can be upgraded 9 times (for a total of lvl10) and 2 can be upgraded 4 times. There are 2 Basic Towers, one for flying and one for ground-mobs, one is Kind of an artillery Tower that does area-damage to all Mobs and a Kind of chain-lightning-tower that shoots a bullet that will not get destroyed when hitting an Opponent, but damage every mob that it hits - currently not planning to add further ones, except maybe a slow-tower that would slow down one mob... not sure though, would have to Change quite some code i guess to do this, and not sure if it's worth it... but if I have or someone else tells me a good idea for another one that makes sense, i might still add it:)

Enough text for now, here's a small Video of the current state:
