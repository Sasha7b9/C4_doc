Re: Version 2.5.5 Final Now Available

by Eric Lengyel » 15 Apr 2011, 12:36

ca$per wrote:The section sizes are:
10-30-50-70 with a transition size of 1 of all sections.
This is a stock tutorial level - Impostor.wld. I just changed sizes.


There aren't any restrictions on section sizes, but it looks like we'll need to add some coordinate clamping. The section sizes you're using here are not very typical -- you would normally want the sections further away to get much larger. Try 10-30-60-120 instead (and you'll get a much nicer blend by increasing the transition size to 5-10).
