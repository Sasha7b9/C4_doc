C4 Book - Start making games with C4 now!

by jimbobjames » 24 Mar 2008, 17:04

Would anyone be interested in a "mini-book" about getting started with C4?

For the body of the book, I've got 3 or 4 simple game prototypes which I could describe in detail, with a view to helping people get up to speed more quickly.

The games prototypes are:

1) A game of 3-D snake. Building on HelloWorld and SimpleBall, the focus here is to explain in detail how to manipulate and move entites using controllers.

Here is a screen shot:
snake3D.jpg


2) A game where you are in control of a vehicle - a car and/or tank and/or plane - this would build on SimpleChar and show you how to start making vehicle controllers. I'd also show how to get models - like the cobra below from GamesterArt at turbosquid http://www.turbosquid.com/FullPreview/I ... /ID/273235 - into C4.

3) A game like "Beach-Head" where you are being attacked by enemy planes which you have to shoot at, before they overrun your defenses. This would describe how to build upon the Game application to implement path following enemies that can shoot at you the player. You'll also learn how to create entities from code and how to set them off in the right direction and with the right seed once created.

Here is a preview:

crashingPlane.jpg


The book's introduction would explain key parts of the C4 API and how to use them. I remember how difficult I found C4 at first and would use that memory to guide the writing. (I'll be double checking with Eric about what I can and cannot describe, but I'm guessing an API guide is probably OK.)

I would also add an appendix on "learning C++ while making a game!" for people who know C++ basics but get lost quickly when reading C4 code.

I'll admit I am still learning C4 myself every day - and I'm certainly by no means an expert with art! - but I do now know enough to be able to help newcomers get started with C4 programming quickly. I'm thinking a pdf format will help get it done faster than following the normal publishing route.

If there is interest, let me know by posting here (or by sending me a Private Message). Let me know also if you'ld be willing to part with say 25 dollars (plus/minus) for this kind of info. Obviously I would get it finished more quickly and with higher quality if the interest was significant.

Thanks,

James.
