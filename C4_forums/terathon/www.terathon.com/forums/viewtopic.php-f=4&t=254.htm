by Eric Lengyel » 31 May 2006, 15:53

Hi --

It's perfectly okay to mix C4 source with something else you have as long as no one else ever sees the resulting code. Do whatever you want on your own machine.

For visibility/occlusion, there are quite a few things going on:

1) At the highest level, the engine uses zones and portals to determine what parts of the world are visible. There are no size limitations, so a space game could use giant zones with giant portals between them.

2) Occlusion portals (a.k.a. antiportals) can be used to block out areas that you know can't be seen from a particular perspective. They'll block everything from geometries and special effects to other portals that may be behind them.

3) Within each zone, there is a hierarchy of nodes, and these can be used to prune the tree of visible objects using bounding volumes at each level. Grouping geometries in the world editor creates a new node with its own bounding volume that will be tested before anything in the group is tested.

4) If you're using fog, the engine will occlude objects that are completely fogged out. It will also ignore portals that are far enough away so that everything on the other side must be completely fogged out.

Keep in mind that using zones is critical to the performance of shadow rendering. The set of shadow-casting objects is bigger than the set of visible objects because something off screen can cast a shadow into the region that you can see. If zones and portals are used effectively, then the engine can figure out what objects need to cast shadows much more efficiently.
