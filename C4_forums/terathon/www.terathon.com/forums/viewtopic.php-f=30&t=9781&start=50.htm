Frank Skilton wrote:When you mention multisampling, are you referring to AA from C4? If so, I don't know if its enabled or not, I don't even know where the config file is these days?


Hi Frank - what you can do is open the Wingball folder in your AppData (I believe that's where it is on XP, but not 100% sure), and delete both files that are there now (input.cfg and variables.cfg). Then run 0.5.2 again, it will restore defaults. In 0.5.1 I was missing those two files in my installation so I have no idea what defaults were being create on install.. aside from the keys being assigned, but then F should be working for you. Either way.. after new default cfg files are generated there (which will happen right after loading the game), close the game, then edit the input.cfg and make sure this line is under the bindings for your keyboard to fix the headlight issue you're having:

bind "F" %lite;

Then open the variables.cfg and find this line and change it to 1, to disable multisampling:

$displaySamples = "2";

If that fixes the problem for you, I'll have to make 1 the default, or at least add the issues you and yaure have (along with solutions) to the Support page of the website.

Frank, if your headlights default wasn't set before, it's conceivable you also didn't have some other controls in your bindings either. You should try for a new high score if that's the case - hold the right mouse button to slow time on difficult corners.

Would you mind letting me know the path to your .cfg files in XP? I'll be updating my Support page soon and that would be useful. Thanks.

For anyone else who had 0.5.1 installed originally, if any of the controls on the pause window aren't working, replace the content of input.cfg with this:

Code: Select all
$device = "Mouse";
bind "Button 0" %fire;
bind "Button 1" %trig;

$device = "Keyboard";
bind "W" %frwd;
bind "A" %left;
bind "S" %bkwd;
bind "D" %rght;
bind "F" %lite;
bind "R" %retr;
bind "M" %bgmt;
bind "Space" %jump;

undef $device;
