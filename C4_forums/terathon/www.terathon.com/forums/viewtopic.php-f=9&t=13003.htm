Hello. I'm using C4 2.9.1 on Ubuntu Linux 12.04.

I have imported a heightmap to create a world with no issue. However, now I'm trying to overlay one large image on top of it. The image I'm using is a grayscale 2279x2279px TARGA. I go to Import Texture, select my TARGA, hit Open, and accept all the defaults (since http://www.terathon.com/wiki/index.php/ ... _a_Texture says the defaults are usually appropriate) and hit Import. Then nothing happens. So I go to Open Texture, navigate to where I told the Import Texture dialog to output, and nothing is there.

No errors on the command-line, no apparent issues. Am I missing something? How do I create a texture? I even ran the find command on the entire tree and was unable to find my generated texture anywhere, so it's apparently failing (although not telling me that it failed). Any ideas?
