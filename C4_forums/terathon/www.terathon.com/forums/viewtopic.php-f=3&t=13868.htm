Re: Instance Worlds

by Eric Lengyel » 17 Sep 2014, 14:04

GameWizard wrote:How do I get my worlds to show up?


Use the Instanced World tool at the top of the Worlds page. Click in the scene to place a new world, and specify what world you're referencing in its Node Info window. Each of the worlds you've already used will appear in the list in the Worlds page, and selecting one of those (or multiple) lets you quickly place new instances of that world in the scene. To see the worlds, make sure the Instanced World Toggle at the top center of the editor window is selected.

GameWizard wrote:Is there a folder needed for them? Or, do I need to somehow register them in code?


No and no.

GameWizard wrote:Also, the barrels act as if physics is applied to them, but the scene graph shows no physics shape. Are instance worlds automatically controlled by the physics??


Instanced worlds are not automatically controlled by physics. The physics controller and shapes are part of the world being instanced. The shape nodes do appear in the scene graph.

Re: Instance Worlds

by Eric Lengyel » 10 Dec 2014, 15:07

Use the following code to add an instance to the world (of course, with a different resource name):

Code: Select all
Instance *instance = new Instance("forest/pine/Pine1-A");
instance->SetNodePosition(whateverPosition);
world->GetRootNode()->AppendSubnode(instance);
instance->Expand(world);
world->ExpandInstancedWorlds(instance);   // This line only necessary if instances inside the instance need expanded
instance->Preprocess();


To delete it, just use the delete operator on the instance.

Re: How to get the Instance of a placed prefab

by Eric Lengyel » 16 Dec 2014, 14:52

When an instance placed in the editor contains a rigid body, the nodes belonging to the instance are extracted when the world is played, and the instance node itself is deleted. It no longer exists. This process is necessary for saving and restoring games properly as they're being played.

Re: Instance Worlds

by Eric Lengyel » 16 Dec 2014, 18:39

I have merged your two separate threads about this topic.

As I mentioned, if an instance contains a rigid body (or other dynamic object), then its nodes are extracted into the main scene when a level is loaded, and the instance nodes are deleted. A node with a rigid body controller must be at the top level of the world as a subnode of the infinite zone. A rigid body cannot remain inside an instance. Instances really aren't designed to be created dynamically when a game is being played. They are meant to be placed in the world editor and be in the world already when the world is first loaded. You're trying to add instances to the world dynamically, which is going to require some hacky code to get working right. You need to manually extract the rigid body and delete the instance node just as it would happen if the instance had been there all along. Try using this code:

Code: Select all
Instance *instance = new Instance("prefab/MyBoxPrefab");
world->GetRootNode()->AppendSubnode(instance);
instance->Expand(world);

Node *rigidBody = instance->GetFirstSubnode();
instance->Extract(world);

Vector3D testBoxOffset(2.0F, 2.0F, 0.0F);
Point3D testBoxLocation = humanLocation + testBoxOffset;
rigidBody->SetNodePosition(testBoxLocation);
rigidBody->Preprocess();


This will only work if the instance contains a single top-level node with a rigid body controller assigned to it.

The right way to do this is to create a model with your box in it and a shape at the top level (not a subnode of the box). Then register the model and give it a default controller type. These are designed to be placed in the world dynamically, and you automatically get a new controller of the registered type.
