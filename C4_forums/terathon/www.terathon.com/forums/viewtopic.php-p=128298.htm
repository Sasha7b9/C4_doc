Re: Multiple instances of C4 on same machine

by piyush_soni » 27 Mar 2008, 19:23

Just one thing you can do to increase productivity that you don't actually need to copy the code files... Each time you make changes to your game, just copy the newly built game dll file into the other folder so that both C4 applications pick up the same dll file.
You only need to make sure that all the resources used by the applications are there with the same folder structure - like model files, world files, library files etc...
