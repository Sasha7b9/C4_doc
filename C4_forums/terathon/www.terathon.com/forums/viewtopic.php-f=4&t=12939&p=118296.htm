Re: Moving instanced worlds?

by Eric Lengyel » 27 May 2013, 16:35

Yes, moving instanced worlds around will cause problems in the current 2.10.3 release as well as the 3.0d4 release, especially if there is an impostor in the instanced world. In the next 3.0 release, it will probably be possible to move instances safely. The code is still being finalized for that, so bring it up again once the next release is out, and I'll be able to tell you for sure.
