by Frank Skilton » 17 Jun 2006, 11:08

Hi Flash,

1. I put one light in the room: a spotlight. In game, it appeared to be fullbright. What did I do wrong?
Try hitting ctrl-i with the light selected to bring up it's properties. You can adjust certain values from there

2. How do dimensions in the world editor relate to real world dimensions?
1 C4 unit = 1 metre

3. Is there a way to see the dimensions of a piece of geometry as I am creating and manipulating it?
No

4. Is there a way to change the colors of selections so that they are very easy to identify?
No, but others have asked for this feature before and it may be implemented in a future release

So if this were set to black, then yes it should be completely black in the room.

by flashjackson » 17 Jun 2006, 21:30

4. Is there a way to change the colors of selections so that they are very easy to identify?
No, but others have asked for this feature before and it may be implemented in a future release


I actually found an easy mod for the source that highlights the selected geometry in a different color. In line 145 of C4Manipulator.cpp you will find the following statement:

Code: Select all
const ColorRGBA Manipulator::kManipulatorSelectedColor(1.0F, 1.0F, 1.0F, 0.0F);


You can change these numbers to change the selected color. For example, changing that line to:

Code: Select all
const ColorRGBA Manipulator::kManipulatorSelectedColor(1.0F, 0.0F, 0.0F, 0.0F);


will highlight the selected geometry in red. It is an easy, yet handy mod.
