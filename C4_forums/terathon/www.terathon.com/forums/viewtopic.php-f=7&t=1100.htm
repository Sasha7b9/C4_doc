by Eric Lengyel » 02 Oct 2006, 17:27

As expected, the performance over the internet isn't exactly stellar. You guys have actually done more testing of this than we have here. Has anyone been able to play a LAN game?

By the way, the server always listens on port 28327. Client machines let the OS pick the port, and then they send a connect request to IP:28327. As long as the server firewall will let UDP packets in over port 28327, you should be able to connect. Of course, you'll need to make sure that UDP packets can get out on any port.
