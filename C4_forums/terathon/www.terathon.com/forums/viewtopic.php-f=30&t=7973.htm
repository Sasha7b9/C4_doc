Update 08.10.2009
We'll attend the IGF and the IGC this year too with Ludicrous. And in order to get as much feedback as possible, we decided to release a reduced (we don't want to show everything yet ) but working beta, before we submit the game.

It would be really great, if you could download the beta, install it and test it. If there's something wrong, please post here (e.g. wrong spelling, install errors, crashes), if you like it and everything works as expected, you can leave a comment here too

The multiplayer mode is disabled in this beta. We're currently in the process of getting the code certified by GameSpy, during this time, we disabled the mutliplayer mode.

Currently, we're using PhysX, but it will be dropped as soon as Eric releases 2.0. There are some nice eye-candy physic features planned in the future.

There's no manuel included yet. The game menus should be self explaining. Here are the ingame controls:

Left Mouse - Attack
A/E/D - Movement
Space - Fly
1-8/Mouse Wheel - Change Weapons

B - Team Window
Tab - Score Window
T - Chat

Finally, here's the download link: (Link removed) (~ 65 MB, use at your own risk)

Have Fun

Most of you should already know it, I wanted to start a public thread about Ludicrous, finally. Ludicrous is a 3D multiplayer side scrolling shooter featuring detailed 3D graphics, an arsenal of weapons and items, a detailed story, and a series of varying levels to play on.

lc3d-2009-08-02-13-46-20-26.jpg

lc3d-2009-08-02-13-55-07-84.jpg


Our homepage contains more information: http://www.ludicrous.eu


I just uploaded a new video showing the bots I'm currently working on: http://www.youtube.com/watch?v=NAmhJJte24s. Currently, they support free movement (using my NavMesh implementation: viewtopic.php?f=4&t=7793) and aiming/shooting.
