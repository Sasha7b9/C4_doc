Re: How to check for mouse button?

by Grognard » 09 Jan 2015, 20:03

Code: Select all
      static const long LEFT_BUTTON = 0;
      static const long MIDDLE_BUTTON = 1;
      static const long RIGHT_BUTTON = 2;


Code: Select all

static void HandleMouseInput(EventType eventType, const Point& point, void* data);
bool eventConsumed = TheMouseEventManager->handleMouseInput(eventType, point, data);


   mouseInput = new MouseEventHandler(&HandleMouseInput, this);
   TheEngine->InstallMouseEventHandler(mouseInput);



This has almost certainly changed since 2.12 because the signature of the method was changing constantly for quite a while.

You basically send in a function pointer to the engine that has the correct parameters to tell it to send input to your function. Does that make sense?

It's not easy to rip out all the stuff you need without sending you a full project but hopefully you get the idea. The values for left/right/middle have not changed since I started using the engine so they are probably the same today.

It's a little of a pain to update when you change because it won't be clear why it won't compile. But I think at some point the expected parameters for similar items all became kind of the same so maybe it is not going to change again.

cbken wrote:The only way to do this seems to be to get a Device* for the mouse and then set up a button control with the name set to "Button3" and hook an action to the control. Something like that.. You don't need to know the device name. You can just check that the device type is kInputDeviceMouse. Once the HID usage info is available (I'll get it into 4.2), you can then look for a usage of 1 for the primary mouse button among the device's controls. (You would not add a new control.)
