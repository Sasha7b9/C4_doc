Re: Linux support coming in next release

by Eric Lengyel » 27 Apr 2012, 20:27

thomas wrote:
Eric Lengyel wrote:C4 Engine version 2.9 runs on Linux.

Wow, nice...

Can you elaborate more on the details? The libraries you're using, preferred IDE, graphics performance, etc.


The engine only uses the bare-bones standards: POSIX for low-level stuff (files, time, threads, network), X11 for window system interaction and event handling, GLX for an OpenGL context, and ALSA for sound. I have found the graphics performance to be extremely good. I've been using NetBeans for an IDE, but we will also include generic makefiles.
