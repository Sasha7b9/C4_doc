Easy when you know how

by Silk » 05 May 2006, 06:14

Hi again,

Hmmm, okay. This seems easier than I thought.

To create a new page, I just define a link to it from an existing page. Then I can click on my link and start editing the new page. That's nifty!

For anyone else interested in wiki editing, here are some comments from a post by Eric in the old forums:

Use the <code> and </code> tags around code that appears in a paragraph.
Use the <pre> and </pre> tags around code listings, even one liners that appear outside paragraphs.
If you want opening and closing quotes, use the &ldquo; and &rdquo; entities to get the correct appearance on all browsers.
Enclosing a phrase in '' (single quote repeated twice) on both sides makes it italic.
Enclosing a phrase in ''' (single quote repeated three times) on both sides makes it bold.


Wikipedia, which uses the same basic software, has some really useful editing stuff, too. For a cheat-sheet, see: http://upload.wikimedia.org/wikipedia/c ... eet-en.png
