Re: PanelController documentation?

by Eric Lengyel » 30 Jun 2013, 12:01

Yes, there were some outdated methods listed for the panel controller. I removed them a few weeks ago, but it looks like that didn't get updated on the website. The new docs are posted now.

You can use the GetRootWidget() function to get the root widget for the panel, and you can add widgets by calling AddSubnode() for that root widget.

The internal panel size defines the coordinate system for the panel contents. This internal size is fit to the physical size of the panel effect.

Unfortunately, viewports do not work with panel effects displayed in a 3D environment. You are not rendering to a texture when you draw into a viewport, but directly to the framebuffer. They are intended for things like editors that are drawn in the main desktop interface.
