Re: Hope C4 Engine would host on github

by caedes » 07 Nov 2014, 20:10

IMHO, the main feature of Github is pull requests.
They make contributing code (and reviewing those contributions) much more enjoyable than e.g. sending patches to a mailing list oder posting them in a bugtracker.
Many Open Source projects I know have much more contributions since they're on Github (for example, the D programming language got a lot more contributions for both their compiler and their standardlib/runtime since they switched from SVN on self-hosted Trac or something like that to Github.)
And the UE4 shows that this also can also work for proprietary projects.
From what I've heard (I'm not an UE4 subscriber myself), there are tons of contributions from the community, including most of the code for Linux support.

I think C4 too could profit from
  • licensees having a way to improvements they developed in-house upstream
  • .. and review of them could be started by the community, so the first rounds of feedback (and consecutive improvements to the proposed patches) can be done by the community without wasting Erics time
  • having the whole git history available (makes merging new releases easier)
  • .. licensees getting fixes that are upstream earlier, not just on (pre-)releases
  • being able to share code amongst each other, even if it might not go upstream

The biggest problem I see is the code for platforms that are not part of the standard license, especially the PS4 code which can't be made available to "normal" licensees.. refactoring the platform-specific code so platforms mostly have their own classes (in their own files) instead of #if blocks all over the place would make this more feasible, I guess.
