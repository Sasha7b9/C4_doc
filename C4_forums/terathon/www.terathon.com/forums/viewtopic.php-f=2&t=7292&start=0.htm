Re: Version 1.5.9 Now Available

by Eric Lengyel » 29 Apr 2009, 10:47

TheRhinoDude wrote:I read in the Release Notes that Mac PPC support has been discontinued. A few questions:

- Does this mean that you are now simply providing binaries in x86 format instead of universal format? Or does it mean that if you attempt to rebuild the engine in universal format, it simply won't work as there are now x86 specifics in the source (ie inline assembly, etc.)?


It means that the PPC build architecture setting has been removed from the project file, so the binaries are no longer universal, but x86 only. There is nothing in the code to prevent a PPC build, and in fact, PPC is alive and well in the Playstation 3 version of C4. If you add the PPC target back to the project files, then it will continue to work.

TheRhinoDude wrote:- What was the impetus for this change?


No significant interest in the community, and no support from Apple.

by Eric Lengyel » 29 Apr 2009, 16:10

smariobros wrote:Why S3TC normal map compression and not RGTC? Or this is already in the engine and I didn't noticed?
Doom3 whas the first game using this scheme of normal compression, but besides the need to support more video cards,
