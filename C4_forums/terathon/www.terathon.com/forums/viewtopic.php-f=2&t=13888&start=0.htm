Re: Version 4.0 Beta 2 Now Available

by Eric Lengyel » 02 Oct 2014, 21:29

Jesse Meyer wrote:Wow. Excellent craftsmanship on the new Island demo. I think you're going to pull some real attention when its decided to ship and market 4.0.


Yep, and with the new cemetery as well, we'll be demoing C4 a lot better than before.

Jesse Meyer wrote:While it is still annoying to manually swap translation modes (move, rotate), nearly all my frustrations moving about nodes has vanished.


We're planning to make all three modes of movement (axis move, planar move, rotation) available at once. That's why the movement boxes and rotation arcs are different sizes. Doing so meant too many internal changes to the editor for the 4.0 release, though, so it will come in 4.1.

Jesse Meyer wrote:When you rotate an object that has attached to it an imposter, the imposter does not adopt the new proper translation.


Impostors always stand straight up, so if you rotate about the x or y axis, it won't be aligned to the geometry. We'll probably change this in the future so that it is aligned, but it could mean a performance impact.

Re: Version 4.0 Beta 2 Now Available

by Jesse Meyer » 03 Oct 2014, 16:04

Suggestion : Begin the player on the interesting small island (I won't speak anymore of it unspoilerified as not to ruin any surprises but you know which one I'm referring to). Doing so will not only spark more of the adventuring spirit when they see the big impressive island off in the distance for the first time, but they'll become more familiarized with two important game play elements you're structuring the game around trying to get them there:

The use of portals (just reverse the portal direction and add another entrance, perhaps inside the garderobe)
The reward for exploration [spoiler] the fun corpse / chest nestled away in the cave.

I've read some psychology literature that shows when elementary rules in a simple system are well described within the first ~15 (depending on how simple the system is) minutes of introduction, the learner realizes not only the existence of rules, but are also more properly identified. Please don't fall into the trap of having to explicitly denote how to experience the game when it can be more properly taught through world interaction / responses.

I know the level is purposely designed to allow the player to traverse either right or left out of the little village. Now that becomes another reward for browsing about the large island.
