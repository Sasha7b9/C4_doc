Build 134 Now Available

by Eric Lengyel » 14 Apr 2007, 20:52

Build 134 is now available for download:

https://www.terathon.com/c4engine/registered/index.php

Release notes can be found here:

http://www.terathon.com/c4engine/notes.php

In this build, the Skeleton project has been renamed to SimpleBall. I was hoping to include another project called SimpleChar, but it ended up having to copy almost everything from the FighterController and SoldierController classes out of the demo game. So, I decided that it would be more worthwhile to just add more documentation to the existing character control code in the demo game. This will be included in the next build (which will be another minor update in 1-2 weeks.)

by Eric Lengyel » 14 Apr 2007, 21:57

Frank Skilton wrote:The only thing I couldn't get working was adding new vertices to zones? It works fine when I try with a portal but not for a zone. I.e. I select a zone, click the "Insert Zone Vortex" tool and try to plot in new vertices and nothing happens.


Make sure you're clicking on the boundary of the base of the zone. If you're in a viewport in which you're looking at the zone from the top, it should always work. The tool will insert vertices in a side view if you click on the bottom boundary of the zone, but it's not that useful since you can only drag it in one direction.
