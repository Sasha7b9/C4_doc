by Eric Lengyel » 19 Jun 2007, 15:34

You must use a controller to make this work well. For any node that you need to be able to reference on all machines in a game, attaching any kind of controller will give it a unique index through which it can be identified. (And this index is retrieved by calling Controller::GetControllerIndex().) Controllers are also the "ports" through which messages about nodes are distributed to other machines. When you want to change something about a particular node, you send a message to its controller.
