I watched the video again focusing more on the graphical features and the UI with C4 windows was actually from the old engine so I retract that. I now also see the terrain does look like normal height map terrain after all and it definitely is texture mapped as a height map terrain.
About bloom. HDR in games uses bloom to provide a better illusion of intense light but it's very over exaggerated here so I can't really say if there is actual tone mapping going on or not. Thinking about it, I would expect to see much more pronounced tone mapping if it was true HDR...

It might not be C4 after all. The dynamic lighting would indicate C4 tho. But the tree LODs are popping very noticeable and if it was C4 it doesn't make any sense to have it like that. The fog is not standard C4 fog either. As far as trees and vegetation it's all art from a well known vendor that could be used in any engine. The UI at the end did not look like C4 at all.

So.. now I'm not sure after all.. What other engine could it be? There are of course a number of free or similarly priced engines as C4 to pick from. Moving to another engine might not have been too much work.. There's only a guy running over terrain at this point plus the networking.

Either way, I'm hoping for nice HDR in 3.0
