Documentation Supplement?

by DrVonBraun » 28 Jan 2013, 05:09

I know that this is a topic that nobody likes to hear and I got slapped on the wrist in the Ogre forums for bringing it up but I absolutely believe this is essential for any tool software: A complete documentation. For instance I was trying to add an item to a ListWidget and make sure that the last item added becomes immediately visible, aka make the list scroll up automatically. It's not in the documentation but when you look into the code you find the function RevealListItem() which together with GetListItemCount() solves this problem. RevealListItem() isn't documented and neither are many other functions.

Now my idea would be to have a forum thread where users can post complete documentation paragraphs for missing functions (as good as they can make it from their understanding) ready to be copied into the respective H files and Eric could put them into the next release or so and update the API documentation (by the way which tool is used to generate the documentation?)

Well just a thought. I would certainly be willing to add anything I come across and I have the feeling there's going to be a lot to explore for me on my way right now.

Re: Documentation Supplement?

by Eric Lengyel » 28 Jan 2013, 09:59

When a function is missing from the documentation, it means exactly one thing: I haven't gotten to it yet. There are thousands upon thousands upon thousands of API functions in C4, and the documentation has not caught up to all of them. New doc pages are being written all the time, and it's usually a bit random as to which ones get done next. If you mention specific functions or classes in a thread like this, then we can prioritize the docs for them.
