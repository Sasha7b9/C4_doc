I figured out why things are not working and now I realize why I should've posted my _entire_ input section of the log.
I have a cheap Logitech K200 here and a SpeedLink USB game controller.
The engine detects the K200 media keys also separately as "USB Keyboard" additional to the main "Keyboard" and for some reason when device configuration is processed the first of those "USB Keyboard" entries is searched for the control name instead of the "USB Joystick" device.

Edit: USB Keyboard seems to be used instead of USB Joystick, because the device with the latter name is not found. And then when searching for a device by type 'JSTK' the first USB Keyboard device is returned.

Edit: And the reason for why the USB Joystick was not found was that the name of the device was actually: " USB Joystick " and I did not think to check the source of the HTML log file for that.
