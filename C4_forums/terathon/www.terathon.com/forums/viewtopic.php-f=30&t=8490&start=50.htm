Out of curiosity, have you ever considered selling the source code to Bounce? I can certainly understand if you don't want to. However it might be an interesting opportunity for you (and perhaps Terathon) to sell a version of the game that comes with source code at a much higher price. You'd probably want to ensure that license doesn't permit redistribution of Bounce's art assets in order to prevent people simply redistributing your game. I think it would be a very interesting experiment seeing if new developers are interested in something like this.

Selling the source code to games isn't something that is usually done. I can understand why when you're talking about multi-million dollar games powered by trade secrets and proprietary algorithms. However it'd be great to see something like this in the indie scene.
