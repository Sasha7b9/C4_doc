Re: Converting a Sprite Sheet for use in C4

by Frank Skilton » 19 Apr 2011, 04:30

The panel editor can play back animations from a sprite sheet.

Create a new world -> create a panel item -> draw out an 'image' widget -> set the 'Texture map' to Data/C4/C4/Test.tex -> add an 'Animate' mutator -> check the 'Looping' box -> set 'Frames horizontally' and 'Frames vertically' to 4 -> set 'Total frame count' to 16.

If you look at the test texture, you should be able to work out how it works. From memory, it plays from bottom left to right and works its way up.

E,g,

Frame 3 | Frame 4
Frame 1 | Frame 2

Thought this may be helpful to you. You may be able to examine the code and get some ideas.

Watch on YouTube


I re-sized your texture to 256 x 128 as C4 requires a 2D texture for the animate mutator to work. I also added an alpha channel (image -> calculations -> transparency -> tell it to create a new channel and set blending to normal) and re-saved as as Targe file.

I set frames horizontally to 8, frames vertically to 4, total frame count to 32 and frame rate to 30.
