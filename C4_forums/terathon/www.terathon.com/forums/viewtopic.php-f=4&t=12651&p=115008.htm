Re: Weird stac variable behaviour

by Eric Lengyel » 13 Feb 2013, 17:00

I've seen a problem like this before, where the debugger was not showing the correct matrix entries. I don't know what the cause is, but it's definitely a bug in the debugger. (Everything in the code worked correctly in my case, too.) It would seem that the debugger is using an incorrect address for the variable. It's possible that it has something to do with the alignment for the Transform4D structure, but that's just a guess.

In your screenshot, the value of the "this" pointer is badly misaligned. Not sure what's going on there. Pointer addresses for any structure should always be a multiple of 4, and anything allocated with the new operator should be 16-byte aligned.
