I have a question about server built with C4. When it starts (TheMessageMgr->BeginMultiplayerGame(true)), the server starts listening at a first found address (hostInfo->h_addr_list[0]). For example i have two network adapters, with addresses: 192.168.1.100, 192.168.2.100
When i start C4's server, it waits for connections (for example) on 192.168.1.100 and i need to set it up on 192.168.2.100.
Is there any way to setup this?

Re: Listening address

by Ludi » 17 Jun 2009, 12:56

You could try something like that:

Code: Select all
         if (hostInfo)
         {
            char *adr = hostInfo->h_addr_list[0];

            // This belongs into the constructor
            TheEngine->InitVariable("BaseIP", "192.168.1.10");

            Variable *variable = TheEngine->GetVariable("BaseIP");
            if(variable)
            {
               const String<kMaxVariableValueLength> &baseip = variable->GetValue();
               if(Text::GetTextLength(baseip) > 0)
               {
                  NetworkAddress baseAddress = MessageMgr::StringToAddress(baseip);
                  natural i = 0;
                  while (hostInfo->h_addr_list[i] != 0)
                  {
                     if(baseAddress.GetAddress() == ntohl(*(unsigned long *)hostInfo->h_addr_list[i]))
                     {
                        adr = hostInfo->h_addr_list[i++];
                        break;
                     }
                  }
               }
            }
            NetworkAddress localAddress(ntohl(*(unsigned long *) adr), localPortNumber);
            ....


Then, you can set your desired IP to the variable "BaseIP" and then it will be used, oterhwise the default address will be used. This code is untested, therefore I don't know if it works.
