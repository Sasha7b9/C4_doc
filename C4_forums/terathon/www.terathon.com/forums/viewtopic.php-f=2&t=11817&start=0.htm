Version 2.10 will NOT require DX10+ graphics chip

by Eric Lengyel » 07 May 2012, 18:33

In C4 version 2.10, we were thinking about dropping support for DX9 graphics chips. This would mean that C4 would not run on an Nvidia GeForce 7x00 or earlier, and it would not run on any ATI Radeon hardware that's too old to have "HD" in its name. This move would have allowed us to implement new optimizations and better features across the full range of DX10 and DX11 GPUs without having to worry about backwards compatibility with ancient hardware.

UPDATE: We are not dropping support for DX9 hardware anytime soon.
