Re: Troubleshooting Collada imports

by cboyce » 21 May 2014, 11:44

After some poking around, I discovered that (on Linux at least) having the extension be a capital .DAE will cause the importer to silently fail. I can see the model in the resource list and select it, but the call from ColladaResource::Get() returns null, which causes the importer to just return. Changing the case allows them to be imported without issue.
