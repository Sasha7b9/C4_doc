by Eric Lengyel » 31 Jul 2012, 13:46

mschifter wrote:OK, here's the path for the wav file:
C:\dev\TRex\Pre-PDR\C4\Data\TRex\Marines\singleShot.wav


Now everything makes sense.

mschifter wrote:"singleShot" alone should still work as far as the engine is concerned, right? After all, the load code was returning success on the load. I only added "Marines" and not "TRex/Marines" to the path, and it started working.


In the virtual folder hierarchy, the resource path always starts with the first folder that is not a top-level folder inside the Data directory. So in the case of the above full path, the name of the resource is "Marines/singleShot". The "TRex" directory is omitted because it is the top-level folder. Everything below that is included.
