Re: Looks like Modo has got character animation now

by mschifter » 30 Aug 2012, 08:58

I'm going to get another eval period approved by luxology.

I really want to know if the product can be used to produce content for c4, 2.9.1. I will post the results here.

EDIT: OK, I've spent a number of hours this week and last weekend trying to get modo to work with FBX file format on the import and export. The source for models was DAZ, 3DRT.com (test model and purchased model), and a few generic models off the internet. The best result I could get was the stinger DAZ model with animation rigging imported into C4. However the geometry was bad, and I could not get animation data imported.

Given the lack of collada animation support, the only other option was to go to FBX and then use Autodesk's converter to get to collada format. So I tried the converter extensively. The converter always read any source animation/rigging/model/texture correctly and converted it between versions of FBX as well as collada. The test of the result was to read the output back into the converter and verify identical appearance of the model and animation. Introducing modo 601 SP3 into the process, the best I could get was an animated textureless model.

I searched the modo forums and FBX support only seemed to work with the latest Maya.

So I've dropped my purchase plans for modo 601. Maybe 701 will be more robust.

Hope this helps,

Matt
