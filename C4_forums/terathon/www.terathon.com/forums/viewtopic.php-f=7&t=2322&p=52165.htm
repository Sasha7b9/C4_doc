by Eric Lengyel » 09 May 2007, 00:40

Are you sending a ServerInfoMessage inside the HandleConnectionEvent() function when you receive a kConnectionQueryReceived event? Here's what's supposed to happen:

1) A client machine wants to find a server, so it broadcasts a server query. This happens in the JoinGameWindow::InterfaceTask() function.

2) The servers on the network receive the query, and the HandleConnectionEvent() function is called with the kConnectionQueryReceived event.

3) In response to that event, the server should send back a ServerInfoMessage to the client that sent the query as a connectionless packet.

4) The client will receive the ServerInfoMessage and call the ReceiveMessage() function.
