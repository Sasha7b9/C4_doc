The source code for build 123 has been updated to fix a small, but serious bug. If you have already downloaded build 123 before the timestamp on this post, and you haven't also downloaded the patched C4MaterialObjects.cpp, then you need to download Code.zip again from the developer download site:

https://www.terathon.com/developer/download.php

You do not need to download Data.zip again if you've already downloaded it for build 123.
