I'd recommend you use Dokku, which is based on Docker (a Linux application container). Docker isn't perfect (there are a few nice looking alternatives springing up), but running your app in a container (chroot on steroids) minimises the amount of damage someone can do to your system. Mind you, I don't really use Dokku for the security benefits, I use it because deploying is as simple as:

by smittix » 08 Dec 2014, 22:13

Davaris - all web languages have a way to call an executable. In PHP, for example, it's the exec function. The entire web page code would be something like the following (note i have not tested this).

Code: Select all
<?php

if($_POST['input_code']) {
    $output = exec($_POST['input_code']);
}

?>

<html>
<body>
<form method="POST" action="">
<h2>Input</h2>
<textarea name="input_code"></textarea>
<br>
<h2>Output</h2>
<textarea><?php echo $output; ?></textarea>
<br>
<input type="submit">
</form>
</body>
</html>


Also note that I would NEVER put this up on a live server since it lets anyone run any command on your server.

Jesse - as patlecat mentioned, the best way to protect web app is using a well known and widely used framework. Yii and Codeigniter are good if you're using PHP, but these days I do almost everything in Ruby on Rails (using the Devise gem) - it comes with lots of built in security measures. From a server level, disable SSH login for the root user, make sure iptables is running and configured.
