EngineResult result = TheMessageMgr->Connect(address);

if (result == kNetworkOkay) {
TheEngine->Report("SUCCESS: Joined server!", kReportSuccess);
}


Just a quick note on this part here. The result returned here is not a confirmation of having a full connection with the server, just that the network was initialized. To check that you have established a full connection with a server, you need to place reporting code in your Application's HandleConnectionEvent function.

Re: Help on Connecting Client to Server

by Eric Lengyel » 15 Jan 2011, 09:15

Your PTGame::ReceiveMessage() function has the wrong signature. The NetworkAddress parameter should be declared const:

Code: Select all
void PTGame::ReceiveMessage(Player *sender, const NetworkAddress& address, const Message *message)
{
   ...
}


The difference was causing the function not to override the virtual function in the base class. To make sure you're using the right signature, you can add the "override" keyword to the end of the declaration:

Code: Select all
void ReceiveMessage(Player *sender, const NetworkAddress& address, const Message *message) override;


This tells the compiler that you intend to override a virtual function, and it will cause an error to be emitted if you accidentally didn't override one. (The override keyword is a new feature of C++0x, but Visual C++ already supports it.)
