Very frustrating mesh import problem

by cbken » 08 Jan 2011, 04:32

Please add an option to the scene import dialog for turning off the mesh optimization when importing. There's no end to the frustration the optimizing can cause sometimes when you have some special UV layout.

Been working a couple of hours on a simple piece of geometry (basically a flat plane) that would not import correctly, meaning lighting on it was screwed up because it gets messed up at import. Finally had to do the texturing differently with a different look and even then it took some massaging of the UV layout before it would import correctly.

Texturing is not always a simple square texture slapped on in a square 0-1 UV space and in these cases being able to turn off the optimization would solve the problem. All the vertices and UVs and normals would import exactly as they are laid out. Sometimes I really do know how I want it to be and I don't want the editor to go change it when importing.

Re: Very frustrating mesh import problem

by Eric Lengyel » 08 Jan 2011, 19:32

This is being caused by the lack of an average tangent vector along the center vertices. The tangents for the triangles on the left are exactly opposite the tangents for the triangles on the right, so the average is zero. But the vertices have the exact same positions and texcoords, so they are not duplicated. The trick for avoiding this problem is to add 1 to all the mirrored texcoords on one side of the center line (and make sure the texture is imported with the wrap mode set to repeat in that direction).

You can solve it very easy.

Code: Select all
         
/*
for (machine b = 0; b < indexCount; b++)
{
   unsigned long index = indexArray[b];
   if (inputVertex[index] != position) continue;
   if (inputTexcoord[0][index] != inputTexcoord[0][a]) continue;
   if ((inputTexcoord[1]) && (inputTexcoord[1][index] != inputTexcoord[1][a])) continue;
   if ((inputNormal) && (inputNormal[index] != inputNormal[a])) continue;
   if ((inputColor) && (inputColor[index] != inputColor[a])) continue;
   
   vertexIndex = remapTable[index];
   break;
}
*/




EDIT: You have to reimport the mesh, too.
