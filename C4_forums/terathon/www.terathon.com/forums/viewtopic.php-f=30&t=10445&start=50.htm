C4 has become outdoor engine long ago and VoH had to adapt...
dm-core themed maps are removed until Eric fixes sound and zoning problems. With C4 you must choose sounds or zones, you can't really have both as you might already know Also you can't really attach nods to each other and make them transition through zones without flickering.

Warehouse doesn't use zones so it doesn't produce disorienting sounds, nor flickering body parts.
Warehouse is something that I put together in a hurry hence quality is lower than in previous screenshots Also it uses mostly ambient light for performance reasons, that's why lightning looks a bit boring in that level.

Patch v0.6.7:
http://www.megaupload.com/?d=0YLMKO9H

With basic form of NAT punch-through available. I am not sure if NAT part works, but please tell me if it does

Code: Select all
>Fixed:
Dedicated server performance degradation if up for more than 24h;
Kicked bots rejoining until arenaMinPlayers, addbots/removebots shall override arenaMinPlayers setting if used during the game (updating arenaMinPlayers midgame shall restore old behavior);
Redundant armor indicator when no armor used;
Fire sounds keep playing if players fire and reload at the same time;
Players not able to swap ammo while blocked;
>New:
Ability to disable Warmup, off by default. Warmup time is set in minutes in server.cfg (default $gameWarmupTime = 0.0);
Balance teams setting - $arenaAutoteams. Balancing takes place right before a respawn. Bots are used first, then players.
Refresh button for the Arena list;
User can force bots to join specific team by appending "red|blue" right after "addbots" command (e.g. "addbots red 5"). Such command will disable balancing set by $arenaAutoteams (useful if players want to play against bots);
Added basic NAT punch-through functionality, Master shall be acting as a relay;
>Changes:
Executable renamed to VoH.exe;
Credits;
Less fall damage;
Higher armor efficiency, from 25%-30% to 45%-55%;
Reduced weapon sway while in sprint;
Excess bots leave server when killed if arenaMinPlayers exceeded, unless overriden by manual add/remove;
Dozens of fixes, tweaks and improvements have been made to the bots (better moving, smoother aiming, etc ...), still some to go though;
