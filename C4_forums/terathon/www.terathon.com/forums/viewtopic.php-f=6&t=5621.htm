The high-pitched chirping will be heard if one forgets to check the "Sound is streamed (compressed)" option, so make sure to check that it's correctly set in the C4 source node when using ADPCM samples.

Re: Why Sounds Won't Work?

by Eric Lengyel » 14 Mar 2011, 17:13

In the future, please start a new thread.

Your WAV file doesn't work because it does not use a compression format supported by C4. A WAV file must use either no compression (format code 1) or Microsoft ADPCM compression (format code 2). Your WAV file uses IMA ADPCM compression (format code 17).
