Some issues i found with the book,

Reading the book from cover to cover, even though i know most of the stuff in the early parts, i've been
away from c4 for a few months, so thought it would be a good refresh for me

Some problems ive found so far:

The early chapters covering world editing and materials ( building the woodstud wall ) the book refers to some
textures to use that i cannot find,

Page 120:
    GreenGrass.tex
    Wood4.tex

Page 158:
The book says to load the following file for a tutorial on material usage, but cannot find it anywhere.
    Data/Exercises/world/art_gallery_start.wld

There are several references to a Data/Exercises folder which does not exist. I backtracked a bit since i thought i missed
something in the project structure guide, but couldn't find anything about creating this folder.

I did a fresh install of C4 2.10.1 before i started. I'm using the Standard license, so i figured that some of these assets
are not included in the Standard version perhaps? I checked the books Assets as well but couldn't find anything there.

Another thing i should point out is that the screenshots in the book are of a rather poor resolution.
I understand that there are probably space restrictions etc, but it was very difficult to read text in most of the
screenshots so far.

None of this has so far been a major problem for me, just a bit annoying.
If i'm missing something obvious here please accept my humblest apologies and point me in the right direction

Apart from these issues im really enjoying the book. Very easy to follow the tutorials, and i really appreciated the chapters
on MapZone, being a programmer with zero artistic skill this one was gold for me
