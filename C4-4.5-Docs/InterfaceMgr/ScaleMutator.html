class ScaleMutator

Defined in:  C4Mutators.h
The ScaleMutator class causes a widget to change scale.
Definition

class ScaleMutator final : public Mutator

Constructor

ScaleMutator(const Vector2D& start, const Vector2D& finish, float time);

Parameters
start The start scale factor.
finish The finish scale factor.
time The time over which the widget is scaled from start to finish, in milliseconds.
Description
The ScaleMutator class scales an image widget from the scale specified by the start parameter to the scale specified by the finish parameter over the time specified by the time parameter, where the scales represent multiples of the widget's original size.
Base Classes
Mutator A ScaleMutator is a specific type of mutator.
