Texture::GetImagePointer

Defined in:  C4Textures.h
Returns a pointer to the image data for a texture object.
Prototype

void *GetImagePointer(void) const;

Description
The GetImagePointer function returns a pointer to the texture image for a texture object created from an image in memory. The return value is the pointer that was passed to the image parameter of the Texture::Get function. If the texture object was created from a resource, then the return value is nullptr.
