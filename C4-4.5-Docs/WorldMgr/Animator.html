Description
The Animator class is the base class for a variety of model animation classes that can be attached to a model node. A model node may have a single animator attached to it, or it may have multiple animators attached to it organized in a tree hierarchy. When a model is animated by calling the Model::Animate function, the animator objects attached to the model calculate new transforms for the nodes belonging to the model.
Base Classes
Tree<Animator> Animators are organized in a tree hierarchy.
Packable Animators can be packed for storage in resources.
Creatable<Animator> New animator subclasses may be defined by an application, and a creator function can be installed using the Creatable class.
