Description
The MessageMgr class encapsulates the high-level networking and multiplayer features of the C4 Engine. Low-level networking functionality is exposed by the NetworkMgr class. The single instance of the Message Manager is constructed during an application's initialization and destroyed at termination.

The Message Manager's member functions are accessed through the global pointer TheMessageMgr.
