Creating A Logfile-Class

From C4 Engine Wiki

Jump to: navigation, search

C4-Engine does offer a logfile by default. To access it, you have to go to your system/users/username/AppData/Local/C4Directory, there you will find the C4Log.html. You won't see the AppData folder by default, you can go up to username and then click in the path-bar and add \AppData manually to access it or use folder-options to display hidden files/folders in users to unhide it.

I would suggest creating links to your C4-folders in .../AppData/Local/C4Directory and .../AppData/Roaming/C4Directory and place them in your main C4-folder, so you can access them easily from there. By default those directories will be "C4 Engine", you can change that in the C4Main.cpp in Engine/System: #define APPLICATION_NAME "NAME_OF_YOUR_APPLICATION" - you will need to recompile and edit the options of the demo-game to have the engine create the files there.

To add a log-message to that default logfile, you can use Engine::Report("text", kReportLog);

See File Locations for more infos on where C4 stores data.

Fine so far, now I will give you some code to add your own logfile-class, that will create a logfile directly in your C4-working-directory:

Lets start with the header-file: 

#ifndef LogFile_h
#define LogFile_h
 
#include "C4Files.h"
 
namespace C4
{
	enum // Flags for logging
	{
		kLogMessage		= 1 << 0, // message will be default black on white background
		kLogError		= 1 << 1, // message will be highlighted in red
		kLogSuccess		= 1 << 2  // message will be highlighted in green
	};
 
	class LogFile
	{
	private:
		File logfile;
		FileResult result;
 
	public:
		LogFile();
		~LogFile();
 
		void Write(const char* text, unsigned_int32 logtype = kLogMessage);
		void Line(void);
 
	};
 
	extern LogFile *TheLogFile;
 
}
 
#endif

and the cpp-file: 

#include "LogFile.h"
 
using namespace C4;
 
LogFile *C4::TheLogFile = new LogFile;
 
LogFile::LogFile()
{	
	result = logfile.Open("log.html", kFileCreate);
	if (result != kFileOkay) TheEngine->Report("Log-File couldn't be created!", kReportLog); // shouldn't fail, if it does, add a message to default logfile
	else
	{
		logfile <<	"<html>\n" <<
					"<head>\n" <<
					"<title>Logfile</title>\n" <<
					"</head>\n" <<
					"<body>\n" <<
					"<h1>Logfile</h1>" <<
					"<hr>" <<
					"<table border=\"0\" cellspacing=\"0\" cellpadding=\"0\">\n";
	}
}
 
LogFile::~LogFile()
{
	logfile <<	"</table>\n" <<
				"<hr>" <<
				"</body>\n" <<
				"</html>\n";
 
	logfile.Close();
}
 
void LogFile::Write(const char* text, unsigned_int32 logtype)
{
	String<127> date;
	String<127> time;
	TheTimeMgr->GetDateTimeStrings(&date, &time);
 
	if (logtype == kLogSuccess) logfile << "<tr bgcolor=#00FF00><td>" << date << " - " << time << "</td><td>: " << text << "</td></tr>\n";	
	else if (logtype == kLogError) logfile << "<tr bgcolor=#FF0000><td>" << date << " - " << time << "</td><td>: " << text << "</td></tr>\n";
	else logfile << "<tr><td>" << date << " - " << time << "</td><td>: " << text << "</td></tr>\n";
}
 
void LogFile::Line()
{
	logfile << "</table><hr><table border = \"0\" cellspacing=\"0\" cellpadding=\"0\">\n";
}

That's it. Include it to your game.h and you should be able to send messages to the logfile from anywhere in your code by using TheLogFile->Write("text",[flag]); , it will be stored to log.html in your main-game-folder. If you need more than one logfile, you can just add them using more externs with other names.
