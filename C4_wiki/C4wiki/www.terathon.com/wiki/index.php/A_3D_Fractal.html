A 3D Fractal

From C4 Engine Wiki

Jump to: navigation, search

You can make a simple 3D fractal using C4 very easily. This example shows you how to make a Sierpinski Pyramid in just a few lines of code. The example also illustrates how easy it is to create C4 geometry primitives in code.

Here are the steps:

1. Open the C4 solution file, which is in the directory ..\C4\VisualStudio2012\C4, in Visual Studio and then open SimpleBall.cpp

2. Replace the void MovementAction::Begin(void) function as follows: 

void MovementAction::Begin(void)
{
	// This function is called when the input control associated with this
	// particular action is activated (e.g., a key was pressed).

	GameWorld *world = static_cast<GameWorld *>(TheWorldMgr->GetWorld());
	if (world)
	{
		// If there's currently a world loaded, apply the movement to
		// the spectator camera.

		SpectatorCamera *camera = world->GetSpectatorCamera();

		if (movementFlag & 16) {//Space Bar pressed, so draw the fractal

			Point3D center = Point3D(-20,-20,10);
			BuildPyramids(center, 20.0F, 4);
		} else
			camera->SetSpectatorFlags(camera->GetSpectatorFlags() | movementFlag);
	}
}

3. Still in SimpleBall.cpp, the following fucntion just before the function MovementAction::MovementAction() 

void BuildPyramids(Point3D startPosition, float a, int depth) {
	World      *world = TheWorldMgr->GetWorld();

	C4::MaterialObject *materialObject = C4::MaterialObject::Get("material/Wine");

	Vector2D            pyramidSize( a, a );

	Point3D position;

	for (int i=0; i<5; i++) {
		PyramidGeometry *pyramid = new PyramidGeometry(pyramidSize,a);
		pyramid->SetMaterialObject(0,materialObject);
		pyramid->GetObject()->SetGeometryLevelCount(1);

		switch (i) {
		case 0: 
			position = startPosition + Point3D(0,0,0.0F);
			break;
		case 1: 
			position = startPosition + Point3D(a,0,0.0F);
			break;
		case 2: 
			position = startPosition + Point3D(0,a,0.0F);
			break;
		case 3: 
			position = startPosition + Point3D(a,a,0.0F);
			break;
		case 4: 
			position = startPosition + Point3D(a/2.0F,a/2.0F,a);
			break;
		}
		if(depth == 0) {
			world->GetRootNode()->AddSubnode(pyramid);
			pyramid->SetNodePosition(position);
			pyramid->Update();
			pyramid->GetObject()->Build(pyramid);
			pyramid->Preprocess();
		} else
			BuildPyramids(position,a/2.0F,depth-1);
	}
}

4. Add the following include directive at the top of the file: 

#include "C4Primitives.h"

5. Now change this line: 

TheWorldMgr->LoadWorld("world/SimpleBall");

to 

TheWorldMgr->LoadWorld("world/Water");


6. Now hit F7 to compile those changes and use F5 to run it in Debug mode.

7. Click the start button that appears and then hit the SPACE bar to draw your fractal! Well done!
