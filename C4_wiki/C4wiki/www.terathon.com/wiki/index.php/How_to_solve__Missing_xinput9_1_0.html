How to solve "Missing xinput9 1 0.dll" error on Windows Server 2008R2

Xinput9_1_0.dll Is Missing Error

Windows Server 2008R2 is capable of running C4 applications, however when compiling it will complain about a missing DLL. This is because DX does not install this DLL on the server version. You can read more about it | here. This site also provides a tool that contains the missing DLLs. Supposedly this problem can also be solved by installing | this driver software , however, it didnt work for me. I had to download the above tool to be able to run C4 again.

In case that site ever goes down, I will copy the descriptive text here. I won't upload the tool though since I can not verify that it is safe to use, the choice is up to you. 

The xinput9_1_0.dll file is a library needed for using Xbox controllers and is by default included in Windows Vista but not in Windows Server 2008. 
This dll is needed to play several games like Grand Theft Auto IV,  Halo 2 and more.

Get the files manually
The various files in the archive are taken from two different places:
- The x86 and x64 versions of the *.inf, *.cat and infinst.exe file are taken from the "DirectX Software Development Kit" 
which can be downloaded from Microsoft.com – Downloads: DirectX Software Development Kit.   
After downloading extract it and go to the Redist folder where you can find the x86 .inf and .cat file in the file 
Oct2005_xinput_x86.cab and the x64 .inf and .cat file in Oct2005_xinput_x64.cab.
- The x86 and x64 versions of xinput9_1_0.dll and XInput9_1_0.dll.mui are extracted using 7-Zip from the install.wim file 
in the sources directory of the Windows 7 Retail x64 MSDN DVD.

Alternative
An alternative way of solving this missing file is to install the Microsoft Xbox 360 Accessories Software which can be 
downloaded from Microsoft Gaming Hardware – Downloads. If you want the software in an other  language than English, 
go to Microsoft – Download Gaming Software, choose Controller as Type and Windows 7 (64 bit) as Operating System. 
It doesn’t matter which controller you select in the Controller field.


Finally, in case you want to gather the files manually, I include a list of files that are found in that tool and which are taken from the DX installation set:

XInput9_1_0.dll.mui
./x86:
en-US  xinput9_1_0.dll	xinput9_1_0_x86.cat  xinput9_1_0_x86.inf
./x86/en-US:
XInput9_1_0.dll.mui
