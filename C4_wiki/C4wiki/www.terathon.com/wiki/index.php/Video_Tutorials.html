Video Tutorials

From C4 Engine Wiki

Jump to: navigation, search

Here are some simple video tutorials which may be helpful to beginners when starting to use the World Editor.


You can now support us by buying our book, "The Beginner's Guide to the C4 Engine" on Amazon: http://www.amazon.com/exec/obidos/tg/detail/-/0985811714


(Note that I also have some other tutorials over here.)


  • World Editor Basics

This first video shows the very basics of how to use the C4 World Editor.


  • Skeleton Island

This video shows some simple steps to add some skeleton models to the island demo world using the C4 World Editor.


  • Zombie World

This next video shows some simple steps to add Zombie models to the Water tutorial world using the C4 World Editor. It also shows you how to add a trigger and how to add a script which will generate the zombies if the trigger is activated.


  • Creating and downloading an animated, textured model from Mixamo

This video shows you how simple it is to create an animated, textured model (for free) at mixamo.com. The model can be downloaded as a collada file, ready to be imported into C4.


  • Importing an animated, textured model into C4

After downloading a 3D model in the collada format, this tutorial shows you how to import the model, including the tetures and animation, into the C4 Engine. This tutorial uses sound to help explain the steps.


  • How to register a model with the World Editor

This tutorial shows how to register a model with the World Editor using just 2 lines of code. It then shows how to add the model to your game world.


  • C4 Pirate Ship Part 1

This is the first part of a two-part tutorial which shows how to import a 3D model of a Pirate Ship into the C4 Game Engine using the C4 World Editor. It shows you various sites with free 3D content, as well as how to use Blender to convert the downloaded model from the .3ds format to the collada (.dae) format.

The relevant links for the free 3D content, which are mentioned in the tutorial are: http://www.hongkiat.com/blog/60-excellent-free-3d-model-websites/ and http://artist-3d.com/free_3d_models/dnm/model_disp.php?uid=2837


  • C4 Pirate Ship Part 2

This is the second part of a two-part tutorial which shows how to import a 3D model of a Pirate Ship into the C4 Game Engine using the C4 World Editor. It shows you how to correctly register the model with the World Editor using just two lines of code.


  • C4 Controllers Part 1

Here I show you how to assign a Controller to a Node in C4. A Controller is used to apply motion or animation to your models and other game objects. I use the Rotation Controller which ships with the engine to make a Pirate ship circle the island. No coding required.


  • C4 Controllers Part 2

Here I show you how to integrate a Custom Controller in C4. I use the Controller to make a pirate ship fire at the player.


--Jimbobjames
