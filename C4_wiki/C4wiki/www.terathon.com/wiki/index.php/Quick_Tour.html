This article describes what you'll see when you run the engine for the first time using the stock binaries or after building the engine with the stock project files and data. Most of the information on this page also applies to the C4 Engine demo.

Basic Interface

By default, the C4 Engine is configured to start up in the demo game called The 31st. (This is a game currently in development at Terathon Software.) After the C4 Engine logo movie plays, the demo game's title screen appears as shown in the background of the screenshot below. All of the settings that can be accessed from this title screen are fully functional and can be used to configure things like the graphics options used by the engine.

Like many engines, the C4 Engine contains a command console that can be accessed by pressing the key directly below the Escape key on the keyboard. On English keyboard layouts, this key types a tilde or grave accent. If you press this key to open the console from the title screen, then you should see everything in the following screenshot:

The command console is the window that opens in the upper-left corner of the screen. It displays the version of the engine upon startup. When a window like the console is opened, the “strip” also appears at the bottom of the screen. The strip behaves like the taskbar under Windows and contains buttons for each of the major user interface windows that are open inside the engine. The strip also contains a C4 menu in the lower-left corner of the screen that is analogous to the Windows Start menu. The C4 menu contains commands for opening utility windows, quitting the engine, and accessing tool plugins as described below.

The C4 Menu

When you click on the C4 menu at the bottom of the screen, the following commands are available when the default tool plugins are installed.

Command

Description

New World

Opens the World Editor with a new blank world. You can type Ctrl-N (Cmd-N on the Mac) when any major window is being displayed to create a new world.

Open World...

Opens an existing world in the World Editor. A dialog is displayed from which a .wld file can be chosen. You can type Ctrl-O (Cmd-O on the Mac) when any major window is being displayed to open a world.

Reopen Played World

Reopens a world in the World Editor that was previous played by using the Save and Play command in the editor. This command is not available until a world has been played from the editor. You can type Ctrl-Shift-P (Cmd-Shift-P on the Mac) when any major window is being displayed to reopen a played world.

New Panel

Opens the Panel Editor with a new blank user interface panel.

Open Panel...

Opens an existing user interface panel the Panel Editor. A dialog is displayed from which a .pan file can be chosen.

Open Movie...

Opens an existing movie resource in the Movie Player. A dialog is displayed from which an .mvi file can be chosen.

Import Movie...

Opens the Movie Importer for creating a new movie resource.

Open Sound...

Opens an existing sound resource in the Sound Player. A dialog is displayed from which a .wav file can be chosen.

Import String Table...

Displays a dialog from which a .txt file can be chosen and creates a new string table resource.

Open Texture...

Opens an existing texture resource in the Texture Viewer. A dialog is displayed from which a .tex file can be chosen.

Import Texture...

Opens the Texture Importer for creating a new texture resource.

Generate Terrain Palette...

Opens the Terrain Palette window for creating a new terrain texture palette resource.

Generate Textures...

Opens the Texture Generation tool, which renders textures for light projections, shadow maps, and environment maps. (This can only be invoked while a game world is running.)

Open Model...

Opens an existing model resource in the Model Viewer. A dialog is displayed from which an .mdl file can be chosen.

Generate Font...

Opens the Font Generator for creating a new font resource.

Command Console

Opens the Command Console.

Rate Window

Opens the frame rate window.

Stats Window

Opens the engine stats window.

Network Window

Opens the networking window.

Take Screenshot

Takes a screenshot and places it in the user's Documents folder. (See File Locations.)

Quit

Quits the engine. You can type Ctrl-Q (Cmd-Q on the Mac) when any major window is being displayed to quit.


Quitting

The C4 Engine application can be closed in a number of ways:

  • If you're running in windowed mode, then you can click the close box of the OS window containing C4. Note that you can only do this when you see a cursor, and this is the case only when a major engine window is open, like the Command Console or World Editor.
  • Choose the Quit command from the C4 Menu, as described in the previous section. You can also type Ctrl-Q (Cmd-Q on the Mac), but only when a major engine window is open. If a game is being played, you don't want the combination of the control key and the Q key to quit because the user may have bound those to different actions in the game that could be used simultaneously.
  • Type "quit" in the Command Console, without quotes.
