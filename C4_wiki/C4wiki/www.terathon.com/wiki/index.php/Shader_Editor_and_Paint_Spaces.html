Shader Editor and Paint Spaces

From C4 Engine Wiki

Jump to: navigation, search

In this tutorial we will look at Paint Spaces, as an example of how to use C4's powerful Shader Editor. Here are the steps:

1. Start C4 and open the "Inout" world which is in the Data/Tutorial/world/ folder. Save the world as "PaintWorld".

2. Use the Page menu to open the Spaces Page and the Paint Page.

3. From the Spaces Page, left click on the Paint Space to select it.

4. In the top viewport, draw out a Paint Space such that it completely covers the plate geometry which represents the ground in the Inout world.

5. Use the resize tool (shortcut 4) to adjust the size of the Paint Space in the Front viewport. Your world should now look like this:

6. Use the Selection Page to deselect the Space Select Mask as shown next:

This will allow us to select the ground in the world unimpeded.

7. Next, in the perspective viewport, left click on the ground, which is a plate geometry. We are going to paint on the ground.

8. In the Scene Graph viewport (lower left viewport by default), shift-left click on Paint Space node. Now both the Paint Space and ground plate nodes should be selected.

9. Now use the Paint Page to associate your Paint Space with the ground geometry as show below:

Shader Editor

OK, so we've set up our Paint Space, so lets move to the Shader Editor.

10. Double click on the material in the Material Page to open the Material Manager.

11. Create a New Material by clicking the New button at the bottom left of the Material Manager screen.

12. Now click the Edit Shader button and use the scroll wheel to zoom out as shown next:

Notice that the shader simply takes a plain white constant color as input and feeds the alpha component to the Alpha Output. It also feeds the constant white color to the RGB input of the Lighting Output, which is described in the C4 wiki as follows:

"This Lighting Output is the primary output process for the ambient shader. The color sent to this output process is combined with the ambient lighting environment to produce the final ambient light reflection for a material."

The Lighting Output is the only required output process. Output processes are described here in the Shader Editor article.

13. To create our own shader, first left click on the Constant Color process and delete it.

14. Next add the six shader processes and connect them together as shown in next. We will explain how they work later in the tutorial.

You can find the Texture Map and Paint Texture processes in the Basic processes list, the Linear interpolate process in the Math processes list and the Texcoord 1 process in the Interpolants process list. Note that to connect two processes together, you simply need to left click the output of one to an input of the other. Note also that to set the route (or connection) between the Linear Interpolate process and the Alpha process, you simply double click on the connection and then replace 'xyzw' with 'a'. This ensures that only the alpha component of the Linear Interpolate output is sent to the Alpha process as you would expect.

Here is the decription from the C4 wiki:

"A swizzle and negation may be applied to a route. These can be set by double-clicking on a route or by selecting a route and typing Ctrl-I (Cmd-I on the Mac). By default, the swizzle for a route is xyzw, meaning that there is no change to the order of the components. If any other swizzle is specified, or the values are negated, then that information is displayed in a small box at the center of the path representing the route. The swizzle may be specified using any letters from the sets xyzw, rgba, or stpq. Specifying only a single letter is shorthand for the same letter repeated four times. For example, the swizzle z is equivalent to the swizzle zzzz."

15. Next, double click on each of the texture map processes to set the texture you wish to use, as shown next:

I used the FloorStones-diff.tex and Caution.tex textures.

16. Once you have the processes set up and connected together for the Ambient Pass as in Fig x.z, shift left click all processes and press Ctrl-C to copy them to the clpboard.

17. Left click on the Light tab and left click the Diffuse Reflection process and delete it. Now press Ctrl-V to paste the processes from the Ambient pass and connect the Linear Interpolate process to the Alpha and Lighting Output processes as shown below:

18. OK, now we are finished with the Shader Editor, so save your changes with Ctrl-S or use the Shader menu and select "Save Shader".

19. Close the Shader Editor with Ctrl-W or use the Shader menu and select "Close".

20. Name your new Material whatever you like and close the Material Manager.

21. Now left click on the ground in the perspective viewport and set the material to our new material using Ctrl-M.

22. Double click on the Paint Space node at the bottom of the scene graph viewport and set the channel count to 4 in the Paint Space tab. For detailed painting, you can also set the x and y resolution values to 1024 as shown next:

Painting

Now its time to use our new material and the tools in the Paint Page to paint the ground.

22. In the Paint Page, left click on the Paintbrush tool as well as on the RGB and A buttons which represent a channel mask. Set the color of the paintbrush to either black or white. I used white as shown. Set the brush radius to 5 and now the Paint Page should look like the one in fig x.

23. Now click Ctrl-4 to maximize the perspective viewport. Click and hold the right mouse button and use the WASD kees to zoom in close to the ground.

24. Now just left click on the ground to start painting! If you now click the inverted box in the Paint Page or alternatively, if you set the paintbrush color to black, you can paint with the other texture as shown below:

How it works

Let's have a look at the Shader we created again and see how this works. It's quite simple really.

The Linear Interpolator creates a blend of the two input textures. The formula for the output of the interpolator is:

Output = A(1 − t) + Bt

where A and B represent our Floor and Caution textures prespectively.

So when we set the paintbrush color to white, the values of Red Green and Blue are 1 and therefore the t input to the interpolator is (1,1,1,1). The result of the interpolation in this case is therefore B, which is why we paint with the Caution texture when the paintbrush color is white. And when we invert the paintbrush color, or set it to black, then the Red Green and Blue values are all 0. Since t in this case is (0,0,0,1) the result of the interpolation in this case is A, which is the floor texture.

If you set the paintbrush color to some value between black and white, the the texture which is painted onto the ground will be a blend of the two input textures in the Shader Editor. Your Turn:

See if you can change the Shader to use 3 textures as inputs and set it up so that the first texture is painted when the Red color mask in the Paint Page is selected, the second texture is painted only when the Green color mask is selected and the third texture is painted only when the Blue color mask is selected. Have fun!
