The Texture Viewer is part of the Texture Tool plugin that ships with the C4 Engine, and it is used to preview texture resources in the engine's proprietary .tex format.

Opening a Texture

The Texture Viewer is opened by selecting Open Texture from the C4 menu, or by typing texture [name] in the Command Console. If the Open Texture menu item is selected (or name is omitted from the console command), then a dialog appears to let you select a texture resource.

Texture Viewer Layout

The Texture Viewer window has the layout shown below.



Basic information about the texture map (type, format, alpha channel usage, and size) is displayed in the upper-right corner of the window.

If the Flip vertically box is checked, then the image is displayed upside-down. You can also type Ctrl-F to flip the image.

If the Enable alpha blend box is checked, then alpha blending is applied to the texture image using the alpha channel in the texture map (if present). The background color or pattern that shows through can be selected from the Background menu.

If a texture has mipmaps (the usual case), then you can type Ctrl-M to cycle through the mipmap chain.

For 3D textures and 2D array textures with multiple layers, you can type Ctrl-D to cycle through these layers.
