A Sample Inventory Window

From C4 Engine Wiki

Jump to: navigation, search

This article shows one way to create an inventory window for a character. The purpose is to show the items, a character is carrying. Some of these items can be containers which, when doubleclicked, open a window of the same kind that show that inventories content. Items can be dragged between inventories.

This is not a copy-and-run tutorial.

My game is a client server game, so lots of the code that is involved in moving the actual data around happens on the server and is not included here. This sample is a framework so that you can build your own solution based on the code here. This sample also demonstrates how to use the C4::WorldViewportWidget class which is where the rendering of the inventory takes place. I include my panel file here which I use to depict the window. You could download it and check it in your version of the C4 engine, but there's really not much special content there except that particular widget.

There is a forum article here: [1] in which I discussed the topic and asked questions before I coded my solution. It contains a video of the final window, although the graphics are all dummy, but it shows how the system looks.

Lastly, I used a number of code samples from the wiki, mainly the ones that pick a mesh in the scene with a C4::Ray object. Credit for those parts go to the respective authors, mostly here: [2] and here: [3]

			void Container_Inventory_Window::GetWorldRayFromClick(const C4::Camera *pc_camera, const C4::Point3D& c_point, Ray *pc_ray)
			{
				// Get the viewport rect for the pc_camera.
				const C4::Rect& viewRect = pc_camera->GetObject()->GetViewRect();
 
				// Normalize the click coordinates.
				float x = c_point.x / (float) viewRect.Width();
				float y = c_point.y / (float) viewRect.Height();
 
				// Cast a local ray from the pc_camera.
				pc_camera->CastRay(x, y, pc_ray);
 
				// Transform the ray into world space.
				const C4::Transform4D& cameraTransform = pc_camera->GetNodeTransform();
				pc_ray->origin = cameraTransform * pc_ray->origin;
				pc_ray->direction = (cameraTransform * pc_ray->direction).Normalize();
 
				// Set the rest of the ray fields.
				pc_ray->radius = 0.0F;
				pc_ray->tmin = 0.0F;
				pc_ray->tmax = 1000.0F;   // Set to max distance ray will go.
			}
 
 
 
			void Container_Inventory_Window::Inventory_Mouse_Event(const C4::MouseEventData *pc_event_data, C4::ViewportWidget *pc_viewport_widget, void *p_cookie)
			{
				DebugValueNL("Mouse Event");
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Get the window this event is for and determine if the wheel is rotating a new item to the front. If so, we dont allow any input
				// ################################################################################################################################################################
				Container_Inventory_Window		*pc_window = static_cast< Container_Inventory_Window * >(p_cookie);
				if( 0.0f != pc_window->mf_delta_wheel_rotation )
					return;
 
 
				switch(pc_event_data->eventType)
				{
				case kEventMouseDown:
				case kEventRightMouseDown:
					{
						// --- PATRIC 2013/05/10 ----
						// ################################################################################################################################################################
						// If this is a left click, check for a doubleclick event first. We ignore a doubleclick down and leave the event handling for the up event, otherwise there
						// are problems when a window is created during a doubleclick and comes up under the mouse position
						// ################################################################################################################################################################
						if( pc_event_data->eventType == kEventMouseDown)
						{
							if( std::chrono::duration_cast< std::chrono::milliseconds> (std::chrono::system_clock::now() - pc_window->mc_last_item_click_time).count() < 500 )
							{
								return;
							}
						}
 
 
 
						// --- PATRIC 2013/05/10 ----
						// ################################################################################################################################################################
						// No check for clicking of a new item that will them be rotated to the front position
						// ################################################################################################################################################################
						//
						C4::Ray		c_test_ray;
						GetWorldRayFromClick( ((WorldViewportWidget *)pc_viewport_widget)->GetViewportWorld()->GetCamera(), pc_event_data->mousePosition, & c_test_ray);
						C4::Point3D origin = c_test_ray.origin;
						C4::Point3D target = origin + (c_test_ray.direction * c_test_ray.tmax);
						C4::CollisionData s_data;
						if(((WorldViewportWidget *)pc_viewport_widget)->GetViewportWorld()->DetectCollision(c_test_ray.origin, target, c_test_ray.radius, 0, &s_data))
						{
							C4::Geometry	*pc_geometry_node = s_data.geometry;
 
							// --- PATRIC 2013/05/09 ----
							// ################################################################################################################################################################
							// Identify the item that was clicked by comparing the returned node with the copies of the model pointers we have
							// ################################################################################################################################################################
 
							for( S32 s32_index = 0; s32_index < (S32) pc_window->mcvps_items.size() ; s32_index++ )
								if( nullptr != pc_window->mcvps_items[s32_index].mpc_c4_model)
								{
									const C4::Node *pc_node = pc_window->mcvps_items[s32_index].mpc_c4_model->GetFirstSubnode();
									while (pc_node)
									{
										if ((pc_node->GetNodeType() == kNodeGeometry) && (pc_node == static_cast<C4::Node *>(pc_geometry_node)))
										{
											// --- PATRIC 2013/05/09 ----
											// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
											// Determine the delta angle in radian between the item that is at the front and the one that was clicked and that is to be brought to the front by rotation.
											// We also need a factor to speed up the rotation the farther the selected item is from the front position where it rotates to
											// Set the index of the new item that is to become the front item.
											// Set that item's name in the text widget
											// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
											pc_window->mf_delta_wheel_rotation					= (s32_index - pc_window->ms32_index_of_item_in_front ) * pc_window->mf_angle_per_item_radian;
											pc_window->mf_main_wheel_rotation_speed_factor		= fabs(float(s32_index - pc_window->ms32_index_of_item_in_front));
											pc_window->ms32_index_of_item_in_front				= s32_index;
 
											pc_window->mu32_index_last_clicked_item				= s32_index;
 
											const char *pzstr_item_name = CLIENT::TOOLS::String_Tables::Get_Singleton().Get_Stringtable_Items().GetString( 
												C4::StringID( 
												'ITEM', 
												'NAME',
												STATIC::ITEMS::Items::Get_Item_Static_Ptr( pc_window->mcvps_items[s32_index].mpc_item->Get_Item_Type() )->u32_text_id));
 
											// --- PATRIC 2013/05/22 ----
											// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
											// Set the item name, damage, stack etc into the text fields
											// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
											pc_window->Write_Active_Items_Data_Into_Fields();
 
											return;
										}
										pc_node = pc_window->mcvps_items[s32_index].mpc_c4_model->GetNextNode(pc_node);
									}
								}
 
								pc_window->mu32_index_last_clicked_item	= MINUS_ONE;
								return;
						}
						pc_window->mu32_index_last_clicked_item		= MINUS_ONE;
						return;
					}
 
 
				case kEventMouseUp:
					{
						// --- PATRIC 2013/05/10 ----
						// ################################################################################################################################################################
						// Check for a doubleclick event first. We ignore a doubleclick down and leave the event handling for the up event, otherwise there
						// are problems when a window is created during a doubleclick and comes up under the mouse position
						// ################################################################################################################################################################
						if( std::chrono::duration_cast< std::chrono::milliseconds> (std::chrono::system_clock::now() - pc_window->mc_last_item_click_time).count() < 500 )
						{
							pc_window->On_Doubleclick();
							pc_window->mc_last_item_click_time	= std::chrono::system_clock::now();
							return;
						}
						pc_window->mc_last_item_click_time	= std::chrono::system_clock::now();
 
 
 
 
						// --- PATRIC 2013/05/09 ----
						// ################################################################################################################################################################
						// This is used to drop an item that was picked up in this window. The item can either be dropped in the main window, which will drop it in the world, or
						// in another inventory window, which will move the item there. However the UP event will always be received in the source inventory window
						// ################################################################################################################################################################
 
						// --- PATRIC 2013/05/10 ----
						// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
						// Get the target window, where the object was dropped, if any
                        // This is part of my GUI system and I cant show all the details here. If there is a another inventory window under the mouse coordinate at this point, this 
                        // function will detect it and return that window
						// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
						CLIENT::USER_INTERFACE::UI_Manager::S_WINDOW_WIDGET_COLLISION_DATA		s_result = CLIENT::USER_INTERFACE::UI_Manager::Get_Singleton().Get_Window_From_Mouse_Position_On_Screen(  );
 
 
						if( nullptr == s_result.mpc_window )
						{
							// --- PATRIC 2013/05/10 ----
							// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
							// If there is no target window, that means the object was dropped on the main screen which is equal to the player wanting to drop the item on the ground
							// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
							pc_window->Drop_Selected_Item_On_Ground();
							break;
						}else{
							// --- PATRIC 2013/05/11 ----
							// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
							// Call the overloaded function in the target window to accept the item. That function will either ignore this call or forward it to the server to process it.
							// If the two windows in the test are the same, that simply means that a single or double click has occurred within the window and not a drop event
							// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
							if( pc_window != s_result.mpc_window)
								s_result.mpc_window->On_Object_Dropped_On_Widget( pc_window->mcvps_items[pc_window->ms32_index_of_item_in_front].mpc_item, s_result.mcvpc_widget );
 
						}
 
 
						break;
					}
 
 
				case kEventRightMouseUp:
					{
						break;
					}
 
 
				}
 
			}
 
 
 
 
 
 
 
 
 
 
 
 
			float Container_Inventory_Window::_Make_Model_Standard_Size( C4::Model *pc_model )
			{
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Get the largest box that surrounds all nodes in the model
				// ################################################################################################################################################################
				C4::Box3D	c_world_box;
				bool		b_box_flag = false;
 
				const C4::Node *pc_node = pc_model->GetFirstSubnode();
				while (pc_node)
				{
					C4::Box3D	c_actual_box;
 
					if ((pc_node->GetNodeType() == kNodeGeometry) && (pc_node->CalculateBoundingBox(&c_actual_box)))
					{
						if (b_box_flag)
							c_world_box.Union(c_actual_box);
						else
						{
							b_box_flag	= true;
							c_world_box = c_actual_box;
						}
					}
					pc_node = pc_model->GetNextNode(pc_node);
				}
				ASSERT_1( b_box_flag );
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Determine the largest radius from the 3 radii in XYZ direction. An item must have a positive dimension 
				// ################################################################################################################################################################
				float		f_largest_radius = c_world_box.GetSize().x;
				if( c_world_box.GetSize().y > f_largest_radius )
					f_largest_radius	= c_world_box.GetSize().y;
				if( c_world_box.GetSize().z > f_largest_radius )
					f_largest_radius	= c_world_box.GetSize().z;
				ASSERT_1( f_largest_radius > 0.0f );
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Return the result. We want each item to be roughly 0.5 meter in size, hence the 0.5 nominator
				// ################################################################################################################################################################
				return 0.5f / f_largest_radius;
			}
 
 
 
 
 
			void Container_Inventory_Window::_Place_One_Item_On_Position_Around_Circle( S32 s32_item_index )
			{
				ASSERT_1( s32_item_index < static_cast<S32>(mcvps_items.size()) );
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Determine the amount of items to consider. there is a constant value that determines the maximum that fits into an inventory, but it is possible that the server
				// is forced to fit more than that into an inventory. So the maximum number is etiher the constant or the real NOF items
				// ################################################################################################################################################################
				S32				s32_nof_items = max( D_MAX_NOF_ITEMS_IN_INVENTORY, mcvps_items.size() );
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Calculate the angle in radian between two entries based on the maximum NOF entries. If there are less entries that will leave empty spaces but this will
				// create a consistent optical effect without having different gap sizes in different inventories with different NOF items. 
				// ################################################################################################################################################################
				mf_angle_per_item_radian	= PI2 / static_cast<float>(s32_nof_items);
 
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Create a standard vector for the first item position and rotate it for each new item by the given angle
				// ################################################################################################################################################################
				C4::Point3D		c_position D_ITEM_START_VECTOR;
 
				C4::Transform4D			c_transformation_displacement;
				C4::Transform4D			c_transformation_rotation;
				C4::Transform4D			c_transformation_scale;
				C4::Transform4D			c_transformation_result;
 
				c_transformation_rotation.SetRotationAboutZ( mf_angle_per_item_radian * s32_item_index );
				c_transformation_displacement.SetDisplacement( c_position );
				c_transformation_scale.SetScale( mcvps_items[s32_item_index].mf_size_factor );
				c_transformation_result = c_transformation_rotation * c_transformation_displacement * c_transformation_scale;
 
				mcvps_items[s32_item_index].mpc_c4_model->SetNodeTransform( c_transformation_result );
				mcvps_items[s32_item_index].mpc_c4_model->Invalidate();
 
 
			}
 
 
 
			void Container_Inventory_Window::_Distribute_Items_Around_Center()
			{
				for( S32 s32_index = 0; s32_index < (S32) mcvps_items.size() ; s32_index++ )
					_Place_One_Item_On_Position_Around_Circle( s32_index );
			}

			void Container_Inventory_Window::InterfaceRenderTask( void )
			{
				if( Visible() )
				{
					// --- PATRIC 2013/05/09 ----
					// ################################################################################################################################################################
					// Rotate each item around it's Z axis
					// ################################################################################################################################################################
					//
 
					// --- PATRIC 2013/05/09 ----
					// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
					// Determine the rotation advance for each item around it's Z axis since the last call
					// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
					mf_angle_around_item_axis	+= 
						std::chrono::duration_cast< std::chrono::milliseconds> (std::chrono::system_clock::now() - mc_last_item_rotation_time).count() * 0.001f;
 
					// --- PATRIC 2013/05/09 ----
					// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
					// Rotate each item around it's Z axis
					// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
					for( S32 s32_index = 0; s32_index < (S32) mcvps_items.size() ; s32_index++ )
					{
						if( mcvps_items[s32_index].mpc_c4_model != nullptr )
						{
							C4::Point3D		c_position D_ITEM_START_VECTOR;
 
							C4::Transform4D			c_transformation_displacement;
							C4::Transform4D			c_transformation_rotation_around_z_axis;
							C4::Transform4D			c_transformation_rotation;
							C4::Transform4D			c_transformation_scale;
							C4::Transform4D			c_transformation_result;
 
							c_transformation_rotation_around_z_axis.SetRotationAboutZ( mf_angle_around_item_axis );
							c_transformation_rotation.SetRotationAboutZ( mf_angle_per_item_radian * s32_index );
							c_transformation_displacement.SetDisplacement( c_position );
							c_transformation_scale.SetScale( mcvps_items[s32_index].mf_size_factor );
							c_transformation_result = c_transformation_rotation * (c_transformation_displacement * c_transformation_rotation_around_z_axis) * c_transformation_scale;
 
							mcvps_items[s32_index].mpc_c4_model->SetNodeTransform( c_transformation_result );
							mcvps_items[s32_index].mpc_c4_model->Invalidate();
						}
					}
 
 
					// --- PATRIC 2013/05/09 ----
					// ################################################################################################################################################################
					// Rotate the wheel around it's center to bring a new item to the front, if a rotation is going on. Rotations go either in + or - direction and we stop
					// the rotation when 0 is crossed to the other side
					// ################################################################################################################################################################
					if( 0.0f != mf_delta_wheel_rotation )
					{
						float			f_rotation_this_frame_radian	= 	std::chrono::duration_cast< std::chrono::milliseconds> (std::chrono::system_clock::now() - mc_last_item_rotation_time).count() * 0.001f * mf_main_wheel_rotation_speed_factor;
 
						// --- PATRIC 2013/05/09 ----
						// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
						// Determine the actual rotation angle this frame and wether this is the last step of the wheel rotation
						// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
						if( mf_delta_wheel_rotation > 0.0f )
						{
							f_rotation_this_frame_radian	= - f_rotation_this_frame_radian;
							if( mf_delta_wheel_rotation + f_rotation_this_frame_radian <= 0.0f )
							{
								f_rotation_this_frame_radian	= - mf_delta_wheel_rotation;
								mf_delta_wheel_rotation			= 0.0f;
							}else
								mf_delta_wheel_rotation += f_rotation_this_frame_radian;
						}else{
							if( mf_delta_wheel_rotation + f_rotation_this_frame_radian >= 0.0f )
							{
								f_rotation_this_frame_radian	= - mf_delta_wheel_rotation;
								mf_delta_wheel_rotation			= 0.0f;
							}else
								mf_delta_wheel_rotation += f_rotation_this_frame_radian;
						}
 
						// --- PATRIC 2013/05/09 ----
						// ----------------------------------------------------------------------------------------------------------------------------------------------------------------
						// Rotate the center wheel by the given delta angle around it's Z axis
						//
						C4::World				*pc_widget_world	= mpc_frustum_viewport_widget->GetViewportWorld();
						C4::Node				*pc_root_node		= pc_widget_world->GetRootNode();
						C4::Transform4D			c_transformation_rotation_around_z_axis;
						C4::Transform4D			c_transformation_rotation_this_frame;
 
						c_transformation_rotation_this_frame.SetRotationAboutZ( f_rotation_this_frame_radian );
						c_transformation_rotation_around_z_axis	= pc_root_node->GetNodeTransform() * c_transformation_rotation_this_frame;
 
						pc_root_node->SetNodeTransform( c_transformation_rotation_around_z_axis );
						pc_root_node->Invalidate();
 
					}
 
				}
				mc_last_item_rotation_time	= std::chrono::system_clock::now();
			}

			void Container_Inventory_Window::Drop_Selected_Item_On_Ground()
			{
				// --- PATRIC 2013/05/10 ----
				// ################################################################################################################################################################
				// If no object is selected, return
				// ################################################################################################################################################################
				if( MINUS_ONE == ms32_index_of_item_in_front )
					return;
 
				// --- PATRIC 2013/05/10 ----
				// ################################################################################################################################################################
				// Get the world position that is picked by the mouse from the world object.
                // This is a function that I added to my world class. I include the code later in a seperate code block
				// ################################################################################################################################################################
				C4::Point3D							c_point;
				CLIENT::WORLD::OBJECTS::Item		*pc_item;
				CLIENT::WORLD::OBJECTS::Character	*pc_character;
 
				switch( CLIENT::WORLD::Game_World::Get_Singleton().Detect_Mouse_Position_In_World( c_point, pc_item, pc_character ) )
				{
				case 0:
					// --- PATRIC 2013/05/10 ----
					// ################################################################################################################################################################
					// Nothing clicked
					// ################################################################################################################################################################
					return;
 
				case 1:
					{
 
						// --- PATRIC 2013/05/10 ----
						// ################################################################################################################################################################
						// Terrain clicked. Send an action to the server that drops the given item on the ground
						// ################################################################################################################################################################
						if( ( ms32_index_of_item_in_front < (S32) mcvps_items.size() ) &&  (nullptr != mcvps_items[ms32_index_of_item_in_front].mpc_item) )
						{
							COMMUNICATION::ACTIONS::DATA::WINDOW::SACTN_WINDOW_ACTION_ITEM_DROPPED_ON_GROUND_STRUCT				s_command;
 
							s_command.s.me_window_type				= Get_Window_Type();
							s_command.s.mu32_window_id				= Get_Window_ID();
							s_command.s.mu32_item_id				= mcvps_items[ms32_index_of_item_in_front].mpc_item->Get_Object_ID();
							s_command.s.f_position_x				= c_point.x;
							s_command.s.f_position_y				= c_point.y;
							s_command.s.f_position_z				= c_point.z;
 
							CLIENT::SYSTEM::Channel::Get_Singleton().Send_Action( s_command );
 
						}
 
						break;
					}
 
				case 2:
					// --- PATRIC 2013/05/10 ----
					// ################################################################################################################################################################
					// Item clicked
					// ################################################################################################################################################################
 
 
					break;
 
				case 3:
					// --- PATRIC 2013/05/10 ----
					// ################################################################################################################################################################
					// character clicked
					// ################################################################################################################################################################
 
 
					break;
 
				default:
					ASSERTION("Invalid case");
				}
 
 
			}

			NOGS::RETURN_TYPE Container_Inventory_Window::Receive_Open_Data( NOGS::Files::File_Memory &rc_parameters )
			{
				// --- PATRIC 2013/05/08 ----
				// ################################################################################################################################################################
				// This function receives the inventory content from the server. I leave it here to give an idea how to populate the window with it's first data. Of course
                // this will look much different in other applications
				// ################################################################################################################################################################
				rc_parameters.Set_Read_Not_Faile_Mode();
 
				U32					u32_nof_items;
				float				f_weight;
 
				rc_parameters.Read_32(u32_nof_items);
				rc_parameters.Read_Float(f_weight);
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Create each item in the object manager. Remove the objects from the object manager's control and hold the pointer here instead since we want the
				// local image of the item to exist only as long as the inventory is open
				// ################################################################################################################################################################
				S_ITEM_ENTRY						s_new_entry;
 
				for( S32 s32_index = 0; s32_index < static_cast<S32>(u32_nof_items) ; s32_index++ )
				{
					s_new_entry.mpc_item	= static_cast<CLIENT::WORLD::OBJECTS::Item *>(CLIENT::WORLD::OBJECTS::Object_Manager::Get_Singleton().Read_Object_From_Server_Data_And_Return(rc_parameters));
					ASSERT_1( nullptr != s_new_entry.mpc_item );
 
					mcvps_items.push_back( s_new_entry );
 
				}
 
 
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Now create each object as a model and attach it to the world's only node which is the center object. When we get a new model, we must determine it's size
				// so that we can scale the node up or down in order to unify all objects and make them appear roughly equal in size
				// ################################################################################################################################################################
				C4::World		*pc_widget_world	= mpc_frustum_viewport_widget->GetViewportWorld();
				C4::Node		*pc_root_node		= pc_widget_world->GetRootNode();
 
				ASSERT_1( nullptr != pc_root_node );
 
				for( S32 s32_index = 0; s32_index < (S32) mcvps_items.size() ; s32_index++ )
				{
					mcvps_items[s32_index].mpc_c4_model		= CLIENT::SYSTEM::Model_Register::Get_Singleton().Create_Model_For_Item( mcvps_items[s32_index].mpc_item->Get_Item_Type() );
					mcvps_items[s32_index].mf_size_factor	= _Make_Model_Standard_Size(mcvps_items[s32_index].mpc_c4_model);
 
					C4::Transform4D		c_transform;
					c_transform.SetTranslation(Zero3D);
					pc_root_node->AddNewSubnode( mcvps_items[s32_index].mpc_c4_model );
 
				}
 
 
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Perform an intial distribution of the objects around the center wheel
				// ################################################################################################################################################################
				_Distribute_Items_Around_Center();
 
 
				// --- PATRIC 2013/05/09 ----
				// ################################################################################################################################################################
				// Write the text of the first item into the text widget
				// ################################################################################################################################################################
				if( mcvps_items.size() > 0 )
					Write_Active_Items_Data_Into_Fields();
 
 
				// --- PATRIC 2013/05/13 ----
				// ################################################################################################################################################################
				// Write the weight into the weight text widget
				// ################################################################################################################################################################
				std::wstring		cwstr_weight;
				NOGS::Containers::String_Tools::WString_Format(cwstr_weight, mcstr_inventory_weight_pattern.c_str(), static_cast<U32>(f_weight) );
				mpc_inventory_weight->SetText( NOGS::Containers::String_Tools::To_UTF_8( cwstr_weight).c_str() );
 
 
				return RETURN_TYPE::OK;
			}
 
 
 
 
 
 
 
 
			void Container_Inventory_Window::Window_Command_Add_Item( NOGS::Files::File_Memory &rc_parameters, float f_new_inventory_weight )

				// --- PATRIC 2013/05/13 ----

				S_ITEM_ENTRY						s_new_entry;
 
				s_new_entry.mpc_item	= static_cast<CLIENT::WORLD::OBJECTS::Item *>(CLIENT::WORLD::OBJECTS::Object_Manager::Get_Singleton().Read_Object_From_Server_Data_And_Return(rc_parameters));
				ASSERT_1( nullptr != s_new_entry.mpc_item );
 
 
				// --- PATRIC 2013/05/12 ----
				// ################################################################################################################################################################
				// Get the Widget data 
				// ################################################################################################################################################################
				C4::World		*pc_widget_world	= mpc_frustum_viewport_widget->GetViewportWorld();
				C4::Node		*pc_root_node		= pc_widget_world->GetRootNode();
 
				ASSERT_1( nullptr != pc_root_node );
 
 
				// --- PATRIC 2013/05/12 ----
				// ################################################################################################################################################################
				// Find an unused entry in the array of items around the circle. This means that there is a visible gap around the circle from an item that was removed.
				// ################################################################################################################################################################
				for( S32 s32_index = 0; s32_index < (S32) mcvps_items.size() ; s32_index++ )
				{
					if( nullptr == mcvps_items[s32_index].mpc_item )
					{
						mcvps_items[s32_index].mpc_item			= s_new_entry.mpc_item;
						mcvps_items[s32_index].mpc_c4_model		= CLIENT::SYSTEM::Model_Register::Get_Singleton().Create_Model_For_Item( mcvps_items[s32_index].mpc_item->Get_Item_Type() );
						mcvps_items[s32_index].mf_size_factor	= _Make_Model_Standard_Size(mcvps_items[s32_index].mpc_c4_model);
						pc_root_node->AddNewSubnode( mcvps_items[s32_index].mpc_c4_model );
						_Place_One_Item_On_Position_Around_Circle(s32_index);
						Write_Active_Items_Data_Into_Fields();
						return;
					}
 
				}
 
				// --- PATRIC 2013/05/12 ----
				// ################################################################################################################################################################
				// Here the item must be added to the array. We assume that the server has already made sure that there ae not more items alltogether than an inventory can hold
				// ################################################################################################################################################################
				s_new_entry.mpc_c4_model		= CLIENT::SYSTEM::Model_Register::Get_Singleton().Create_Model_For_Item( s_new_entry.mpc_item->Get_Item_Type() );
				s_new_entry.mf_size_factor	= _Make_Model_Standard_Size(s_new_entry.mpc_c4_model);
				mcvps_items.push_back( s_new_entry );
				pc_root_node->AddNewSubnode(s_new_entry.mpc_c4_model );
				_Place_One_Item_On_Position_Around_Circle(mcvps_items.size() - 1);
 
				Write_Active_Items_Data_Into_Fields();
 
 
 
			}
 
 
 
 
 
 
			void Container_Inventory_Window::Window_Command_Remove_Item( U32 u32_object_id, float f_new_inventory_weight )
			{
 
 
				// --- PATRIC 2013/05/13 ----
				// ################################################################################################################################################################
				// Write the weight into the weight text widget
				// ################################################################################################################################################################
				std::wstring		cwstr_weight;
				NOGS::Containers::String_Tools::WString_Format(cwstr_weight, mcstr_inventory_weight_pattern.c_str(), static_cast<U32>(f_new_inventory_weight) );
				mpc_inventory_weight->SetText( NOGS::Containers::String_Tools::To_UTF_8( cwstr_weight).c_str() );
 
 
				// --- PATRIC 2013/05/12 ----
				// ################################################################################################################################################################
				// Find the item with the given ID and delete it. The item is not property of the object manager so we can simply delete them here
				// ################################################################################################################################################################
				for( S32 s32_index = 0; s32_index < (S32) mcvps_items.size() ; s32_index++ )
				{
					if( (nullptr != mcvps_items[s32_index].mpc_item) && (mcvps_items[s32_index].mpc_item->Get_Object_ID() == u32_object_id) )
					{
						delete mcvps_items[s32_index].mpc_c4_model;
						delete mcvps_items[s32_index].mpc_item;
						mcvps_items[s32_index].mpc_c4_model		= nullptr;
						mcvps_items[s32_index].mpc_item			= nullptr;
 
						Write_Active_Items_Data_Into_Fields();
						return;
					}
				}
 
				ASSERTION("No item with the ID found");
 
			}
 
 
 
 
 
 
 
			void Container_Inventory_Window::Update_Object_From_Server_Update_Data( const CLIENT::WORLD::OBJECTS::Object_Receiver &rc_receiver )
			{
 
				// --- PATRIC 2013/05/23 ----
				// ################################################################################################################################################################
				// Check for updates that are for the window itself
				// ################################################################################################################################################################
				if( rc_receiver.mu32_object_id == mu32_inventory_object_id )
				{
					if( rc_receiver.ms_general_inventory.mb_data_is_valid  )
					{
						std::wstring		cwstr_weight;
						NOGS::Containers::String_Tools::WString_Format(cwstr_weight, mcstr_inventory_weight_pattern.c_str(), static_cast<U32>(rc_receiver.ms_general_inventory.mf_total_weight) );
						mpc_inventory_weight->SetText( NOGS::Containers::String_Tools::To_UTF_8( cwstr_weight).c_str() );
					}
					return;
				}
 
				// ################################################################################################################################################################
				// Check all objects that are shown in this window
				// ################################################################################################################################################################
				for( auto & rs_entry : mcvps_items )
				{
					if( (rs_entry.mpc_item != nullptr) && (rs_entry.mpc_item->Get_Object_ID() == rc_receiver.mu32_object_id ))
					{
						// --- PATRIC 2013/05/21 ----
						// ################################################################################################################################################################
						// Item found. Let it update itself
						// ################################################################################################################################################################
						rs_entry.mpc_item->Update_Object_From_Server_Update_Data(rc_receiver);
 
						// --- PATRIC 2013/05/21 ----
						// ################################################################################################################################################################
						// Update any representation of the item data that may need updates
						// ################################################################################################################################################################
						Write_Active_Items_Data_Into_Fields();
 
 
					}
				}
 
 
			}
 
 
 
 
 
 
 
 
			void Container_Inventory_Window::Write_Active_Items_Data_Into_Fields()
			{
				if( (ms32_index_of_item_in_front < (S32)mcvps_items.size() ) && (nullptr != mcvps_items[ms32_index_of_item_in_front].mpc_item) )
				{
					std::wstring		cwstr_value;
					const char *pzstr_item_name = CLIENT::TOOLS::String_Tables::Get_Singleton().Get_Stringtable_Items().GetString( 
						C4::StringID( 
						'ITEM', 
						'NAME',
						STATIC::ITEMS::Items::Get_Item_Static_Ptr( mcvps_items[ms32_index_of_item_in_front].mpc_item->Get_Item_Type() )->u32_text_id));
 
					mpc_select_name->SetText(pzstr_item_name);
					mpc_select_name->Invalidate();
 
					NOGS::Containers::String_Tools::WString_Format(cwstr_value, mcstr_damage_pattern.c_str(), mcvps_items[ms32_index_of_item_in_front].mpc_item->Get_Damage() );
					mpc_damage->SetText( NOGS::Containers::String_Tools::To_UTF_8( cwstr_value).c_str() );
 
					NOGS::Containers::String_Tools::WString_Format(cwstr_value, mcstr_stack_pattern.c_str(), mcvps_items[ms32_index_of_item_in_front].mpc_item->Get_NOF_Stacked_Items() );
					mpc_stacked->SetText( NOGS::Containers::String_Tools::To_UTF_8( cwstr_value).c_str() );
 
					NOGS::Containers::String_Tools::WString_Format(cwstr_value, mcstr_weight_pattern.c_str(), static_cast<U32>(mcvps_items[ms32_index_of_item_in_front].mpc_item->Get_Weight()) );
					mpc_weight->SetText( NOGS::Containers::String_Tools::To_UTF_8( cwstr_value).c_str() );
 
 
				}else{
					mpc_select_name->SetText("");
					mpc_damage->SetText("");
					mpc_stacked->SetText("");
					mpc_weight->SetText("");
				}
 
			}

Finally here is the code that picks the world position from a click on the terrain in the main window. This should be somewhere in your derived World class: 

NOGS::U32 Game_World::Detect_Mouse_Position_In_World( C4::Point3D &rc_terrain_position,  CLIENT::WORLD::OBJECTS::Item *&rpc_clicked_item, CLIENT::WORLD::OBJECTS::Character *&rpc_clicked_character )
{
    const C4::Point3D			c_point			= TheInterfaceMgr->GetCursorPosition();
    C4::Ray						c_ray;
 
    rpc_clicked_item		= nullptr;
    rpc_clicked_character	= nullptr;
 
    // --- PATRIC 2013/05/14 ----
    // ################################################################################################################################################################
    // Get the viewport rect for the pc_camera and normalize the click coordinate
    // ################################################################################################################################################################
    const C4::Rect& c_view_rect = GetCamera()->GetObject()->GetViewRect();
 
    float x = c_point.x / (float) c_view_rect.Width();
    float y = c_point.y / (float) c_view_rect.Height();
 
    // --- PATRIC 2013/05/14 ----
    // ################################################################################################################################################################
    // Cast a local ray from the pc_camera and transform it into world space
    // ################################################################################################################################################################
    //
    GetCamera()->CastRay(x, y, &c_ray);
    const C4::Transform4D& cameraTransform = GetCamera()->GetWorldTransform();
    c_ray.origin = cameraTransform * c_ray.origin;
    c_ray.direction = (cameraTransform * c_ray.direction).Normalize();
 
//			DebugVectNL( Universal_Vector_3D(c_ray.origin + c_ray.direction ));
 
 
    // --- PATRIC 2013/05/14 ----
    // ################################################################################################################################################################
    // Perform the collision check with the scene
    // ################################################################################################################################################################
    c_ray.radius = 0.0F;
    c_ray.tmin = 0.0F;
    c_ray.tmax = 1000.0F;   // Set to max distance ray will go.
 
    C4::Point3D					origin = c_ray.origin;
    C4::Point3D					target = origin + (c_ray.direction * c_ray.tmax);
    C4::CollisionData			s_data;
    switch( QueryCollision(c_ray.origin, target, c_ray.radius, 0, &s_data))
    {
    case C4::kCollisionStateGeometry:
        {
            // --- PATRIC 2013/05/14 ----
            // ----------------------------------------------------------------------------------------------------------------------------------------------------------------
            // Collision with a static geometry object.
            // ----------------------------------------------------------------------------------------------------------------------------------------------------------------
            C4::Geometry						*pc_geometry_node	= s_data.geometry;
            rc_terrain_position	= s_data.position;
 
            // --- PATRIC 2013/05/17 ----
            // ----------------------------------------------------------------------------------------------------------------------------------------------------------------
            // Detect whether the collision object is an item or just a regular environment geometry by moving the chain from the clicked code and checking if we
            // reach a special item node.
            // All Items that characters can move are subnodes of a special C4::Node subclass with the Type 'Itmn'. Any geometry that is clicked can be identified as 
            // such an object by climbing up the chain of supernodes and checking if one of them is such a special node
            // ----------------------------------------------------------------------------------------------------------------------------------------------------------------
            U32			u32_node_type = pc_geometry_node->GetNodeType();
            C4::Node	*pc_testnode = (C4::Node *) pc_geometry_node;
            while( pc_testnode != nullptr )
            {
                pc_testnode	= pc_testnode->GetSuperNode();
                if( nullptr != pc_testnode)
                {
                    u32_node_type = pc_testnode->GetNodeType();
                    if( u32_node_type == 'Itmn' )
                    {
                        rpc_clicked_item	= static_cast<CLIENT::WORLD::OBJECTS::Item_Node *>(pc_testnode)->Get_Item_Ptr();
                        return 2;
                    }
                }
            }
 
            // --- PATRIC 2013/05/18 ----
            // ----------------------------------------------------------------------------------------------------------------------------------------------------------------
            // Nothing, so it is a terrain collision
            // ----------------------------------------------------------------------------------------------------------------------------------------------------------------
            return 1;
        }
 
    case C4::kCollisionStateRigidBody:
        {
            CLIENT::WORLD::OBJECTS::A_Controller	*pc_controller	= static_cast<CLIENT::WORLD::OBJECTS::A_Controller *>(s_data.rigidBody);
            ASSERT_1( pc_controller->Get_Owning_Object()->Get_Object_Type() == OBJECT::E_OBJECT_CLASS_TYPE::CHARACTER );
 
            rpc_clicked_character	= static_cast<CLIENT::WORLD::OBJECTS::Character *>(pc_controller->Get_Owning_Object() );
            rc_terrain_position		= s_data.position;
 
            return 3;
        }
 
    default:
        return 0;
    }
 
    return 0;
}
