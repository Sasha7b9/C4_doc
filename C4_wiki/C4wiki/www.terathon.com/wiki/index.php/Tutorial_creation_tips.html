Using alt-tab with C4

Don't run C4 in fullscreen mode - use windowed mode instead and you can run it at the desktop's resolution. If you use windowed mode you can easily switch between programs using alt-tab. If alt-tab is used when C4 is in fullscreen mode it minimizes the program and puts it all of the way to at the end of the alt-tab list.

Using non-picture attachments such as zips of tex & wld files

Go to the C4 forums and create a new thread and upload the attachment. Then add a link to the attachment in your tutorial. Note that if you put the attachment in a "Licensed User Area" forum and the user doesn't have access to that forum it will say "You are not authorized to download this attachment."
