Character Lighting Techniques

Here you have some tricks on how to improve your character lighting easily using a few processes in the shader editor. You can access the full resolution version of the images by clicking them.

Usually, when the character is under ambient conditions (no lights), it looks dark and flat, as if it wasn't part of the scene. A common technique is to use a pre-generated ambient occlusion texture, generated in an external 3D application as 3DS Max or Maya. This option is a general solution and it requires to have your character (or any other model) in a general-neutral pose as the classic T-pose. The next screenshot shows this technique:

The model on the right of the screenshot shows the pre-generated ambient occlusion texture. And the model on the left shows the diffuse texture with the ambient occlusion in the alpha channel.

By default, C4 applies this ambient occlusion texture if you add it to the alpha channel of the diffuse texture and import the diffuse texture with the option "Occlusion" in the alpha channel option. It doesn't require any changes in the shader on your part to have this texture working. This solution is very precise, as it has been generated in a high level application. The cons are that it is static, meaning that this ambient occlusion is not going to change as your character moves, and that it requires an artist or to learn how to generate the ambient occlusion texture on your part.

The next screenshot shows the character with ambient occlusion generated using the 'Generate ambient occlusion data' world editor tool (Geometry selected->Menu Geometry->Generate Ambient Occlusion Data. Remember to activate the Render vertex occlusion flag in the material of this geometry). As the first technique, the character should be in a standard-neutral pose like this one. However, it depends on the mesh density, while a rendered ambient occlusion texture is more precise:



The next screenshot shows a solution using the world-space normal process. With this process I add some amount of dark to the polygons oriented to the bottom. I'm using the multiply-add process to move the output of the world-space normal process from (1,0,-1) to (1.2,0.7,0.2). I do this to avoid too much darkness when there is a difference of 90 or more degress between the normals of the character and the z component of the world-space normal. I also add 0.2 to add some "light" to the darkest polygons. It is not a real ambient occlusion (look at the inner part of the legs), but it reduces the flatness of the character under ambient conditions, and more importantly, it is dynamic:




The next test shows a rim effect. It adds a light border, as if the character received light from everywhere. You can see in the shader that I only add this value to the ambient component. The first scalar value (3.0) controls the size of the border and the second value (0.25) controls the power or the amount of "light":



The last test shows the combination of both methods, world-space normal and rim effect:



And the in-game results:



As you can see, C4 provides easy solutions when there is no pre-generated ambient occlusion texture, or you, the programmer don't have an artist to do this for you. Anyway, there's nothing that stops you from mixing several or all of these techniques to achieve the results that your character needs.
