Creating a Model

From C4 Engine Wiki

Jump to: navigation, search

The C4 Engine stores information about a scene or a model in its own file format. A world containing all of the scene data for an entire level is stored in a file with the extension .wld, and the data for a single model is stored in a file with the extension .mdl. The formats of these two file types are nearly identical. The only difference between them is that a world's root node is an infinite zone, and a model's root node is a model. For more information about which of these should be used for objects in your game, see Models and Instanced Worlds.

Importing Scene Data

The C4 World Editor can import scene data stored in either the OpenGEX format or the Collada format. OpenGEX files have the extension .ogex, and Collada files have the extension .dae. These files should be placed somewhere inside a subdirectory of the Import directory (but not at the top level of the Import directory).they can be imported into the World Editor by choosing Import Scene from the World menu. In the selection dialog, the type of file to be imported can be selected from a popup menu at the bottom. After selecting a file, the imported geometry (as well as any lights and materials) will appear in the World Editor. At this point, you may make any changes that you need to.

During the import process, the World Editor will keep track of the materials used by the imported geometry, and it will assign material colors and texture maps as needed. Texture images can be imported by using the Texture Importer tool.

Saving Model Resources

A model (.mdl) resource is created by saving a scene as a model in the World Editor. Once the model has been prepared in the World Editor, it is exported by choosing Save to Model Resource from the World menu. A dialog will then appear that lets you name the exported model.

When a scene is saved as a model resource, the data used only by the World Editor is stripped out in order to minimize the resource size and optimize it for fast loading. Saving to a model resource is intended to be a one-way process, but it is possible to reload a model into the editor by choosing Load from Model Resource from the World menu. If you want to preserve the editor data, then you should save a copy of the original model as a world file so it can be edited later instead of reloading the model resource.

Step by Step Summary

The following steps can be followed to import a model from an external program and save it as a model resource.

  1. Export your model (with skinned info and animation) to either the OpenGEX format or Collada format from your favorite 3D authoring tool.
  2. Put the .ogex or .dae file in a subdirectory of the Import directory (not at the top level of the Import directory).
  3. Launch C4, and create a new world by choosing New World from the C4 menu (or use the shortcut Ctrl-N).
  4. Choose Import Scene from the World menu, and select the file you just exported from the 3D authoring tool.
  5. Now you should see your model in the World Editor.
  6. If you are making a character model that will use physics, you need to add a physics shape from the Physics Page to your model (e.g., a box shape), as a subnode of the infinite zone. Size it to approximate your character---it should just touch the ground. Be sure to open its Node Info window (Ctrl-I) and tick "Do not apply model animation" under the Node tab. Also under the Shape tab, set the shape density. This you can calculate by dividing the estimated body mass of your character (in tons) by the physics shape's volume (which is displayed as V=... m³) alongside the density for you.
  7. Fix up the materials, if necessary, and then choose Save as Model Resource from the World menu.
  8. Now open the Model Viewer by choosing Open Model from the C4 menu. Select the .mdl file you just saved in the previous step.
  9. To import animation, follow these additional steps:
    1. Click the Import button under the Animation list on the left side of the Model Viewer window.
    2. Select the same OpenGEX or Collada file you just used to import the model. This time the animation data will be imported instead.
    3. Select the new animation in the list, and click the Play button. Your animation should now play.
    4. Import additional animations by first saving them as separate OpenGEX or Collada files (from your 3D authoring tool) in the same subdirectory of the Import directory.
