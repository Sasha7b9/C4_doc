Collada Plugins

This page lists the locations where Collada plugins can be obtained for various content creation packages.

C4 Engine supports versions 1.3–1.5 of the Collada format.

There is an official page for latest plugin versions on the collada.org website.

  • Further information about various content creation programs can be found here: Content Creation Programs
  • Content creation programs that can export to FBX can use the Autodesk FBX Converter to convert to Collada.

Autodesk FBX Converter

If your modeling package doesn't support the Collada format, providing that it can export to FBX you can use the Autodesk FBX Converter to convert from an FBX file to Collada. The Autodesk FBX Converter is a free tool and does not require any additional programs to be installed, it is completely stand-alone.
