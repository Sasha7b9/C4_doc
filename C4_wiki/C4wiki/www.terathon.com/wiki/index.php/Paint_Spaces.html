Figure 1. The Paint Page in the C4 Engine World Editor. The image shown at the bottom is the paint space for the main platform in the Hell's Mouth demo level.

The Paint Page, shown in Figure 1, is a tool page in the C4 Engine World Editor that can be found under the Material tab. This page contains tools and special commands that are used to associate a paint space with one or more geometry nodes and paint details onto those geometries directly in any perspective viewport inside the World Editor.

Setting Up for Painting

A few things have to be done before it's possible to paint directly on a geometry and see the results in the World Editor. First, a paint space node needs to be created, and it covers the volume of space in which you would like to paint details onto one or more geometries. Once the paint space exists, it needs to be associated with the geometry nodes that it will affect. Finally, the materials used on the target geometries must be set up to sample the paint space texture map and do something with the data.

Creating a Paint Space

To create a paint space, select the Paint Space tool in the upper-left corner of the Paint Page and use it to draw a new paint space volume in the world. This is usually done in the top viewport because the paint space's texture map cover the extents of this volume in its local x and y directions. The extents of the paint space in the z direction are not used by the engine and can be anything you want.

The resolution of the paint space's texture map and number of channels it contains can be specified in the Node Info window for the paint space node.

Associating Geometries

To associate a paint space with one or more geometry nodes, select the paint space and the geometry nodes simultaneously using Shift-Click in the World Editor. Then select Associate Paint Space from the popup menu in the upper-right corner of the Paint Page. After this is done, the geometries are associated with the paint space that was selected. (If you select the Connect Tool, then you'll be able to see a %Paint connector on each geometry node that is connected to the paint space.)

Preparing a Material

In order for the data stored in a paint space's texture map to be visible in some way, the material applied to the associated geometry nodes must incorporate this information. This is done by using the Paint Texture and Paint Texcoord processes in the Shader Editor. The Paint Texture process samples the paint space's texture map at the location generated by the Paint Texcoord process.


Using the Painting Tools

The paintbrush tool in the upper-left corner of the Paint Page is used to paint directly onto geometry nodes in a perspective viewport inside the World Editor. All of the other settings in the Paint Page affect the way in which the paintbrush is applied. The image at the bottom of the Paint Page shows the actual contents of the texture image for the selected paint space or the paint space associated with the last geometry on which the paintbrush tool was used.

The Color setting specifies the color of the paintbrush. The Invert check box causes the actual color applied while painting to be inverted. This is useful for erasing areas that already have a color applied.

The R, G, B, and A buttons form a channel mask. Painting only occurs in the channels that are currently selected, and other channels are preserved.

Paint space texture maps can have 1, 2, or 4 channels. The color and channel mask are applied as follows for each type.

Channel Count

Description

1

The channel mask is ignored, and painting always occurs. The gray value painted into the texture map is the maximum of the red, green, and blue values specified by the current brush color.

2

Painting occurs in the first channel if any of the R, G, or B channels is enabled, and paint occurs in the second channel if the A channel is enabled. The value painted into the first channel of the texture map is the maximum of the red, green, and blue values specified by the current brush color. The value painted into the second channel of the texture map is the alpha value specified by the current brush color.

4

The channel mask is directly applied to the red, green, blue, and alpha channels of the texture map. The color painted into all four channels of the texture map is exactly the current brush color.

The Brush Strength setting controls the opacity of the paintbrush. When this is set to 100%, the paintbrush completely replaces the colors already in the texture map. For any lower values, the result is a blend between the paintbrush color and the colors already in the texture map, where the percentage specifies how much of the new color to use.

The Brush Radius setting controls the radius of the paintbrush, measured in texels belonging to the paint space's texture map.

The Brush Fuzziness setting controls how sharp or smooth the edge of the paintbrush is. A low fuzziness value corresponds to a sharp edge at the brush's full radius, and a high fuzziness value corresponds to a smooth drop-off in opacity from the center of the brush to its full radius.

If the Enable stylus pressure box is checked and a pressure-sensitive tablet is being used, then the pressure of the stylus controls the brush strength. The pressure causes the brush strength to range from zero at the lowest possible pressure to the maximum specified by the Brush Strength slider at the highest possible pressure.


Menu Commands

The popup menu in the upper-right corner of the Paint Page contains several commands pertaining to paint spaces. These commands are described in the following table.

Command

Description

Associate Paint Space

Associates the currently selected paint space with the currently selected geometry nodes.

Dissociate Paint Space

Breaks the association between the currently selected geometry nodes and any paint spaces to which they are associated.

Select Associated Paint Spaces

Selects all paint spaces that are associated with the currently selected geometry nodes.

Select Associated Geometries

Selects all geometries that are associated with the currently selected paint spaces.
