Introduction

This tutorial will show you the basics of creating an editor plug-in. Because these plug-ins are compiled into separate DLL files, they can be easily shared with other C4 users. Plug-ins also help keep your custom code separate from the engine code, making maintenance easier.

This particular example demonstrates several common editor plugin behaviors:

  • Adds a menu item to the C4 Tools Menu
  • Adds a console command
  • Adds an editor page

This tutorial was written with C4 version 2.9.1 and VisualStudio 2010.

Get The Files

Download the example project and unzip it into your base C4 directory. It will create source files in ToolCode/MyEditorPlugin and create a new VisualStudio project which can be added by right-clicking on the C4 Solution in VS and clicking Add->Existing Project. The project is in the VisualStudio2010/C4/MyEditorPlugin directory. In addition, it creates a folder in Import/Tools/MyEditorPlugin for the string table source file, as well as panels and the compiled string table in Data/Tools/MyEditorPlugin.

Build It

This has only been tested with VisualStudio 2010, but now you should be able to build the project without any errors or warnings.

Test It

Start C4, and now you should see a "My Editor Plugin..." option under the C4 Tools Menu. This should open up a simple panel when clicked. You should also be able to test the command the plugin has added to the console by opening the command console and typing "myplugin". You should get a message back indicating that the plugin received the command. Lastly, create or open a world. You should see "My Editor Page" under the Page menu. This should open a simple page with a single button on it.
