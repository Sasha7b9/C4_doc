Figure 1. The Lights Page contains tools for creating light sources and light-related space nodes.

The Lights Page is a tool page in the World Editor that can be found under the Object tab.

As shown in Figure 1, the Lights Page contains tools for creating light sources as well as shadow spaces and radiosity spaces.

Settings

Setting

Description

Illumination

Light color

The color of the light. Darker colors can be used to create a dimmer light.

Brightness scale

Values larger than 1.0 can be used to scale the brightness of a light beyond what can be done through its color, making it extra bright. Values smaller than 1.0 will simply reduce the brightness of the light color setting.

Minimum enabled detail level

Specifies the minimum light level of detail that must be set in order to render this light. If this is 0, then the light is always rendered. For a higher setting n, the light is rendered only if the current light detail level is n or higher.

Light Flags

Light is static

Indicates that the light will not move in the world. Checking this box allows the engine to enable optimizations that cannot be used for dynamic lights.

Light casts shadows

Indicates whether shadows are cast by this light.

Light shines through portals

Indicates that the light is able to flow through portals. This is enabled by default, but it can be disabled as a small optimization if it's known that the light will never need to shine through any portals.

Use shadow space in instancing world

For lights in instanced worlds, indicates that the light should use the shadow space in the world that includes it.

Illuminate only connecting zones

For infinite lights, causes the light's illumination tree to be rooted only in zones that connect to it and not its containing zone.

Start fade-out distance (m)

For point lights, specifies the distance from the camera at which the light starts to fade out.

Finish fade-out distance (m)

For point lights, specifies the distance from the camera at which the light finishes fading out. The light is not rendered beyond this distance.
