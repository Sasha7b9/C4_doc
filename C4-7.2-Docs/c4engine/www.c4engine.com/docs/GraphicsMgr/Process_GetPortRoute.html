Process::GetPortRoute

Defined in:  C4Processes.h
Returns the route connected to an input port.
Prototype

Route *GetPortRoute(int32 port) const;

Parameters
port The index of the input port.
Description
The GetPortRoute function returns a pointer to the route connected to the input port having the index specified by the port parameter. If the input port has no route connected to it, or the process does not have an input port with the given index, then the return value is nullptr.
