Packer::WriteData

Defined in:  C4Packing.h
Writes arbitrary data to the output stream.
Prototype

void WriteData(const void *data, uint32 size);

Parameters
data A pointer to the data to be written.
Description
The WriteData function writes size bytes of data to the output stream, reading them from memory starting at the pointer specified by the data parameter.

The value of the size parameter must be a multiple of four bytes.
