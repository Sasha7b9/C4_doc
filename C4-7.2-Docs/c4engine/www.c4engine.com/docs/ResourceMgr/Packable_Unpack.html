Packable::Unpack

Defined in:  C4Packing.h
Unpacks an object's data.
Prototype

virtual void Unpack(Unpacker& data, uint32 unpackFlags);

Parameters
data The Unpacker object from which the object data is read.
unpackFlags The unpacking flags.
Description
The Unpack function is called when the engine needs to unpack an object's data. The implementation of an override should first call the direct base class's Unpack function and then use the functions of the Unpacker object to unpack its own data.

If chunks were used to write the object data in the override of the Packable::Pack function, then the Unpack function should call the Packable::UnpackChunkList function to unpack its data.
