Description
The ConeVolume class encapsulates the physical dimensions of a generic conical volume and functionality that is used by various subclasses throughout the engine.

The center of the base coincides with the origin, and the two components of the size parameter correspond to the radii along the x and y axes. The height parameter specifies the physical height of the cone along the positive z axis.
