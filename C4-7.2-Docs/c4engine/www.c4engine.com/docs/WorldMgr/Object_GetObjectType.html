Object::GetObjectType

Defined in:  C4Objects.h
Returns the type of an object.
Prototype

ObjectType GetObjectType(void) const;

Description
The GetObjectType function returns the type of an object. The following table lists the built-in types that can be returned. Additional types may be defined by the application.
kObjectCamera Camera object
kObjectLight Light object
kObjectSpace Space object
kObjectSource Sound source object
kObjectGeometry Geometry object
kObjectTrigger Trigger object
kObjectEffect Effect object
kObjectEmitter Emitter object
kObjectPortal Portal object
kObjectZone Zone object
kObjectMaterial Material object
kObjectShape Physics shape object
kObjectJoint Physics joint object
