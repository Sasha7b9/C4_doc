Description
The TriggerObject class is the base class for all types of trigger objects, and it stores data that is common to all of them. Each specific type of trigger has an associated object that is a subclass of the TriggerObject class.

A trigger object can have one of the following types.
kTriggerBox Box trigger.
kTriggerCylinder Cylinder trigger.
kTriggerSphere Sphere trigger.
Base Classes
Object A TriggerObject is an object that can be shared by multiple trigger nodes.
VolumeObject Used internally by the engine for generic volume objects.
