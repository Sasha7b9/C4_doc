Description
The PyramidGeometryObject class encapsulates data pertaining to a pyramid primitive. In its local coordinate space, a pyramid primitive has one of the corners of its base at the origin, and the components of the size parameter define the extents of the base in the positive x and y directions. The height parameter defines the height of the pyramid's apex above the base in the positive z direction.
