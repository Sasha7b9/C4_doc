Node::GetNodeType

Defined in:  C4Node.h
Returns the type of a node.
Prototype

NodeType GetNodeType(void) const;

Description
The GetNodeType function returns the type of a node. The following table lists the built-in types that can be returned. Additional types may be defined by the application.
kNodeGeneric Generic node.
kNodeCamera Camera node.
kNodeLight Light node.
kNodeSource Sound source node.
kNodeGeometry Geometry node.
kNodeInstance Instanced world node.
kNodeModel Model node (character, projectile, etc.).
kNodeBone Bone node used in skeletal animation.
kNodeMarker Marker node.
kNodeTrigger Trigger node.
kNodeEffect Effect node.
kNodeEmitter Emitter node.
kNodeSpace Space node.
kNodePortal Portal node.
kNodeZone Zone node.
kNodeSkybox Skybox node.
kNodeImpostor Impostor node.
kNodePhysics Physics node.
kNodeShape Physics shape node.
kNodeJoint Physics joint node.
kNodeField Physics field node.
kNodeBlocker Physics blocker node.
