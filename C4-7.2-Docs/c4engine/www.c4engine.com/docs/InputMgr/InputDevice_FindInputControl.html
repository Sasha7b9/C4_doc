InputDevice::FindInputControl

Defined in:  C4Input.h
Returns the control having a given HID usage or name.
Prototype

InputControl *FindInputControl(uint32 usage) const;

InputControl *FindInputControl(const char *name) const;

Parameters
usage The 32-bit HID usage value of the control to find.
name The name of the control to find.
Description
The FindInputControl function searches for an input control having either the 32-bit HID usage value specified by the usage parameter or the name specified by the name parameter. If a matching input control is found, then a pointer to it is returned. Otherwise, the return value is nullptr.
