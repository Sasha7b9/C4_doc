class Compressor

Defined in:  C4Messages.h
Compresses data for a message.

Constructor

Compressor(char *ptr);

Compressor objects should be constructed only by the Message Manager.
Description
A Compressor object is passed to the Message::CompressMessage function before the Message Manager sends a message. The message object should use the << operator or the Compressor::WriteData function to store its data in the Compressor object's internal buffer. Data written by the << operator is always written in big endian order so that messages can be sent between machines having different native endians.
IMPORTANT. The total size of the data written to the Compressor object should not exceed kMaxMessageSize - 1 bytes.
