Description
The TreeWidget class is used to display a box that contains a hierarchical tree of other widgets shown in a scrollable list. The members of a tree widget are always widgets of the type TreeItemWidget.

The default widget color corresponds to the kWidgetColorBorder color type and determines the color of the tree's border. Other color types supported by the tree widget are kWidgetColorBackground and kWidgetColorHilite. If a highlight color has not been explicitly specified, then the Interface Manager's global highlight color is used.
