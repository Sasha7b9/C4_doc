Description
The Round3D class is used to store a three-dimensional round point with a five-dimensional vector representation in conformal geometric algebra.

The default constructor leaves the components of the round point undefined. If the initialization values are supplied, then they are assigned to the five coordinates of the round point.

If the p parameter is supplied, then its three coordinates are assigned to the x, y, and z coordinates of the round point. In this case, the w coordinate is set to 1.0, and the u coordinates is set to (x2 + y2 + z2) / 2.
