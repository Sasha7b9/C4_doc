File();

Description
The File class encapsulates the opening, closing, reading, and writing of disk files. Once a File object has been constructed, a file can be opened using the File::OpenFile function. A file is automatically closed when the File object is destroyed, but it's also possible to explicitly close a file using the File::CloseFile function.
