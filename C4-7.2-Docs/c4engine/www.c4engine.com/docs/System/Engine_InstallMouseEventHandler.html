Engine::InstallMouseEventHandler

Defined in:  C4Engine.h
Installs a mouse event handler.
Prototype

void InstallMouseEventHandler(MouseEventHandler *handler);

Parameters
handler The event handler to install.
Description
The InstallMouseEventHandler function installs a mouse event handler that is invoked whenever a mouse event occurs. Multiple mouse event handlers may be installed simultaneously, and each one is invoked when an event occurs.

A mouse event handler is uninstalled by destroying its associated class instance.
