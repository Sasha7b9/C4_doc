class Transformable

Defined in:  C4Types.h
The Transformable class encapsulates an object-to-world transform and its inverse.
Definition

Member Functions

Constructor

Transformable();

Description
The Transformable class encapsulates a transform from object space to world space and maintains the corresponding inverse transform from world space to object space.

The constructor leaves the transform undefined.
