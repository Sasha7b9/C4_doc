CameraWidget::SetMinGeometryDetailLevel

Defined in:  C4Panels.h
Sets the minimum geometry detail level rendered through a camera widget.
Prototype

void SetMinGeometryDetailLevel(int32 level);

Parameters
level The minimum level of detail. This must be greater than or equal to zero.
Description
The SetMinGeometryDetailLevel function sets the minimum geometry detail level that objects rendered through a camera widget are allowed to have. A value of zero represents the highest detail possible, and larger values represent successively lower levels of detail.

The initial value for the minimum geometry detail level is zero.
